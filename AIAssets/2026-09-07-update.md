### 변경

1. 적 기본공격과 스킬 없는 광역 fallback을 `TakeDamage(ATK, Physical, enemy)`로 연결했다. 기존 방어 QTE 결과는 유지하고 피해 알림에 최종 계산값을 전달한다. 명시적 순수 피해·상태 지속 피해·속성 피해 DEF 정책은 그대로다.
2. `CharacterBase.ClearBattleStatusEffects()`로 상태효과/임시 버프를 해제한다. `OnRemove`로 이벤트 구독·VFX를 정리하고 속박·기절·광폭화·방어·무적 플래그를 초기화한다. 영구 성장/장비와 남은 HP/AP는 유지하되 복구된 최대값을 초과하면 보정한다.
3. BattleManager의 정상 종료는 저장·보상·종료 이벤트 전에, 심리스 중단과 파괴는 공통 정리 시점에 전체 roster/후열/적의 효과를 해제한다. 전열 사망·비활성 여부와 관계없이 처리하며 3+3 웨이브 교체/모듈 변경에는 해제하지 않는다.
4. UIViewportService의 탐색 캐시와 마지막 적용 카메라를 분리했다. 씬 로드/언로드/활성 씬 변경에서 기존 안정화 루틴으로 숨겨진 Canvas까지 재연결한다. 카메라가 없는 동안 전체 검색을 0.25초 간격으로 제한한다.
5. RoomContainer의 `ApplyCurrentRoomAudio()`로 첫 입장/방 이동/저장 Room 복원을 통일했다. 실패한 후보는 BGM을 바꾸지 않는다. 곡이 있으면 CrossFade, 없고 KeepCurrentBgm=true면 유지, false면 FadeOut한다. 이미 복원된 Room을 Start가 다시 덮어쓰지 않는다.

## Z 시간제 방어 / 퍼펙트 패링 구현

- 후속 사용자 승인에 따라 웹 비교를 넘어 실제 Unity 기본 방어를 통합했다. Z 첫 입력부터 최대 0.4초 유지, 일반 방어 피해 배율 0.5, 기존 Perfect 구간 0.12초(난이도/스킬 timing 적용)는 피해 0 및 기존 AP 보상이다. 한 타격 한 시도이며 유지/연타로 갱신하지 않는다. 격자는 미래 특정 전투로 보류했다.

- 정적 Runtime+Editor 컴파일 오류 0 / 기존 ConfigPanelUI 경고 2. 관련 diff 검사와 UTF-8 확인. Unity Play/Refresh/테스트, 자산 변경, 커밋·푸시 없음. 브랜치 `codex/gameplayEdit`.
- 자세한 변경 파일, Inspector 조절 위치, 남은 모션 동기화/저프레임/밸런스 확인은 [구현 인계](../docs/superpowers/plans/2026-09-07-timed-guard.md)에 기록했다. CONTEXT, 전투 규칙, 기존 설계/상담 문서와 프로젝트 시나리오 스킬의 실제 계약을 함께 갱신했다.

## 스킬 구성·제작 절차 상담

- SkillData/실행 블록/스킬 트리·장착/메뉴·카탈로그 경로와 기존 위젤 샘플을 읽고 [기존 전투 논의](yjlim/feedback/2026-09-07-combat-design-discussion.md)에 구성 제안과 제작 순서를 추가했다. 초반 3~4개에서 역할 검증, 기존 장착 최대 6개 유지 권고는 미확정 제안이다.
- AP는 캐릭터별이며 공용 Host의 턴 회복 5 / 퍼펙트 20을 확인했다. 스킬 가격은 일반 방어 기준 순환 가능 여부와 함께 설계하도록 명시했다. 별도 스킬 메이커와 범용 회복/조건부 효과 블록이 이미 완성됐다고 안내하지 않는다.
- Sleep 기본값 미등록, QTE 배율의 첫 피해 후 소비, 빈 장착 목록의 샘플 fallback, 직전 방어의 타격 이후 해제가 이전 타격에 반영될 수 있는 경계를 미수정 주의점으로 기록했다. Host 샘플 목록은 비어 있고 방어 경계는 실제 재현 없이 소스로 확인한 위험임을 구분했다.
- 변경은 상담 문서/일일 기록뿐. 읽기 검토와 문서 UTF-8/diff 확인. 코드·자산 변경, Unity/테스트 실행, 커밋·푸시 없음. 브랜치 `codex/gameplayEdit`.

- 공용 UIManager.prefab EventSystem의 Point/좌·중·우Click/Scroll/Tracked 참조를 비우고 배경 클릭 선택 해제를 껐다. ActionsAsset/Move/Submit/Cancel은 원본 그대로다. 타이틀·설정뿐 아니라 공용 EventSystem의 게임 UI에 적용되며 직접 터치/펜도 현재 경로로는 조작하지 않는다. Editor 마우스는 영향 없다.
- ConfigPanelScrollTests와 ConfigPanelLayoutAssetTests에 행/입력 계약 검사 소스를 추가했다. 별도 런타임 서비스·Update·패키지 변경은 없다. docs/ui-policy, core 규칙과 기존 설계/계획/인계를 갱신했다.
- 정적 Editor 컴파일 오류 0 / 기존 ConfigPanelUI 경고 2. prefab 로컬 참조·유지 액션·UTF-8/diff 검증 및 독립 기본 액션 재할당/Submit usage 경로 리뷰 완료. Unity 실행/자동 테스트/Refresh/커밋/푸시 없음. 브랜치 `codex/gameplayEdit`.

### 후속: 설정창 현지화와 플랫폼별 표시

- 설정창만 대상으로 한국어/영어/일본어/중국어 번역 누락을 보완했다. LocalizationTable.csv에 38개 키 추가, ConfigPanelUI에서 실제 사용 59개 키의 네 언어 값·5열·중복·placeholder와 비설정 행 보존을 확인했다. 원래 CSV UTF-8 BOM 유지.
- 언어 자칭, 짧은 키캡·방향 화살표, 입력 대기/중복/Esc 취소, 번역된 효과 미리보기와 기기 안내를 연결했다. 언어/카테고리 변경 시 이전 미리보기 루틴을 중단한다. 잘못된 저장 키 enum 값은 미지정으로 표시한다.
- 모바일/콘솔에서는 PC 창 설정을 회색으로 표시하고 키보드 없는 환경의 키 재지정을 막는다. 입력 시스템·모바일 가상 패드·콘솔 SDK·GameConfigManager 전역 화면 정책은 변경하지 않았다. 전체 플랫폼 호환 완료로 표현하지 않는다.
- 수정: ConfigPanelUI.cs, LocalizationTable.csv, 기존 ConfigPanelLayoutAssetTests.cs/ConfigPanelScrollTests.cs와 UI 정책/설계/계획/인계. 기존 Silver 폰트 원본이 네 언어 문자를 지원함을 읽기 확인해 폰트·전역 fallback·씬·프리팹 변경은 하지 않았다.
- 실제 Unity/테스트/모바일·닌텐도 실행, Refresh, 커밋/푸시 없음. 브랜치 `codex/gameplayEdit`. 상세 내용과 플랫폼 입력·폰트 atlas 실기 검증 경계는 [기존 인계](yjlim/feedback/2026-09-07-title-options-polish.md)에 기록했다.
- 최종 정적 Runtime+Editor 빌드 오류 0 / 기존 ConfigPanelUI Inspector 경고 2. 독립 리뷰 지적(잘못된 저장 Key의 indexer 예외)을 수정하고 소스/문서 UTF-8·diff 검사를 완료했다.

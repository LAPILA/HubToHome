# 2026-07-13 Merge Conflict Resolution

## 작업

- `main`의 지하철 시네마틱 및 Sequence Maker 완성 변경을 `feature/cinematic-camera-presentation`에 병합하면서 발생한 충돌 12개를 해소했다.
- 충돌 판단은 선배 `main` 변경을 기준으로 했다. 사용이 끝난 ZEV 아키텍처 복제 Scenario, Runtime Asset, Sample Builder, Probe, 전용 테스트 삭제를 그대로 반영했다.

- `ActionExecutionHandle`은 선배의 `Changed` 상태 알림을 유지하고, 현재 브랜치의 중복 취소 방지만 함께 보존했다.
- 시나리오 파이프라인 Skill은 선배의 Sequence Maker, Action/Trigger Library, Safe Preview, 저장·복구 계약을 기준으로 하고 전투 Cinemachine 카메라 계약을 추가로 유지했다.
- 기존 `2026-07-12-update.md`의 양쪽 추가 충돌은 선배 문서를 기준본으로 선택했다.

## 호환 보강

- 현재 브랜치의 `battle.camera.shake`가 선배의 중앙 Registry Factory에서도 등록되게 했다.
- 공식 `camera.actions.yaml`에 `battle.camera.shake` 계약을 추가하고 Action Library를 29개 항목으로 재생성했다.
- 전투 카메라 기본 중심, 데이터 기반 도주 확률, `BattleTurnQueueProjection`, `StatusEffectFactory` 사용은 병합 중 회귀하지 않도록 유지했다.
- Unity가 삭제된 ZEV Probe를 계속 참조하던 생성 `.csproj`를 프로젝트 재임포트로 갱신했다.

# 2026-07-23 Update

## HUBTOHOME-45 적 공격 예고·타이밍 제작 구조

### 변경 사항

- 기존 `SkillData.ActionTimeline`을 유지하면서 블록별 시작 시각, 종료 시각, 지속 시간을 계산하는 `EnemyAttackAuthoringAnalyzer`를 추가했다.
- EnemyOnly 스킬 Inspector에서 실시간 시간축과 오류·경고 요약을 확인할 수 있다.
- 빈 EnemyOnly 스킬에는 상대 기준 접근, 공격 전조와 방어 판정, 피해, 원위치 복귀로 구성된 샘플 공격을 생성할 수 있다.
- `TelegraphThenWindow`를 전조 표시, 준비 지연, 방어 판정창 순서로 실행하도록 수정했다.
- 방어 실패 카메라 흔들림의 강도, 지속 시간, 안전 등급을 공격 데이터에서 설정할 수 있다.
- `Action_Move.AttackStaging`은 절대 좌표 대신 `PositionManager`가 계산한 공격자·대상 상대 위치를 사용한다.
- VFX·투사체·전조 참조 누락, 잘못된 판정 시간, 과도한 카메라 효과를 Odin Inspector와 Project Content Validation이 같은 규칙으로 검사한다.
- Custom Skill Action Block은 `GetAuthoringTiming()`을 재정의해 시간축 분석에 참여할 수 있다.

### 호환성과 영향 범위

- 기존 enum 직렬화 값을 유지하고 새 값은 뒤에 추가했다.
- 기존 공격이 사용하는 `ImmediateReaction` 동작은 유지했다.
- 기존 ZEV 스킬 자산을 읽기 전용으로 검사했으며 새 카메라 기본값과 검증 결과가 정상임을 확인했다.
- Scene, Prefab, ScriptableObject는 수정하지 않았다.
- 사용자가 수정 중인 `TestMap.unity`는 수정하거나 스테이징하지 않았다.

### 검증

- Unity 전체 EditMode: 716/716 통과
- TestMap 심리스 전투 회귀: 6/6 통과
- Project Content Validation: 오류 0건, 기존 선택 아트 경고 10건
- `Assets/_Game` Prefab 59개: Missing Script 0건

### 후속 범위

- 공격자와 대상을 자동으로 한 화면에 담는 줌·프레이밍은 `ICameraPresentationService`의 별도 기능으로 구현한다.
- 공격 데이터에는 화면 좌표나 Cinemachine 카메라 Transform을 직접 저장하지 않는다.

## HUBTOHOME-75 카메라 프레이밍·소유권 통합

### 변경 사항

- `CameraController`가 런타임 Cinemachine Target Group과 Group Framing을 소유하도록 확장했다.
- `CameraFramingSettings`에서 최소·최대 Lens, 화면 점유율, 감쇠, 대상 반경, 중심 오프셋, 추적 스타일을 Inspector로 조정할 수 있다.
- 토큰 기반 `BattleCameraActionScope`를 추가해 자신이 시작한 프레이밍만 종료하도록 했다.
- 플레이어 기본 공격·스킬과 적 근접 QTE·광역 공격·시퀀스 스킬에 공격자/살아 있는 대상 프레이밍을 연결했다.
- QTE 모듈 종료, 코루틴 폐기, 도주, 전투 종료, 심리스 정리, BattleManager 파괴 시 활성 프레이밍을 복구한다.
- Timeline lease가 활성화된 동안 일반 Focus·Reset·Lens tween을 차단하되 가산 Impulse는 유지한다.
- hit stop은 Controller가 소유한 경우에만 시작 전 `Time.timeScale`로 복구한다.
- `MapSettings`와 `RoomInstance`가 공통 `OverworldCameraBinding`을 사용해 `CameraController.VirtualCamera`만 설정하도록 통합했다.

### 호환성과 영향 범위

- 기존 공개 카메라 메서드와 직렬화 enum 값을 유지했다.
- 기존 작성된 Group Framing, Follow, 사용자 지정 LookAt, Confiner 설정은 프레이밍 종료 시 복원한다.
- 프로필이 없는 기본 직교 Lens는 4를 유지한다.
- Scene, Prefab, ScriptableObject는 수정하지 않았다.
- 사용자가 수정 중인 `TestMap.unity`는 수정하거나 스테이징하지 않았다.

## HUBTOHOME-28 Area Marker 작업창·검사 통합

### 변경 사항

- 현재 Room Prefab Stage 또는 로드된 Scene의 Area Marker를 검색·필터링하는 Editor 전용 작업창을 추가했다.
- Room, Marker 타입, 문제 상태, 오류·경고 필터와 Hierarchy 선택·Scene View 이동 기능을 제공한다.
- Marker ID, Room Bounds, SpawnPoint, Door와 Area Connection의 이동 대상을 구조화된 보고서로 검사한다.
- Room 전환은 연결된 `RoomDefinition.RoomPrefab` 내부 대상 SpawnPoint까지 확인한다.
- 기존 Console 검사 메뉴를 공용 `RoomMapValidationScanner`의 출력 어댑터로 변경해 검증 규칙 중복을 제거했다.
- Hierarchy, Project, Undo 변경은 지연 갱신하고 `OnGUI`에서는 자산 검색이나 전체 Scan을 실행하지 않는다.

### 호환성과 영향 범위

- 런타임 Marker API와 직렬화 필드는 변경하지 않았다.
- 작업창은 기존 Odin Inspector 편집 흐름을 유지하며 Scan은 자산을 자동 수정하지 않는다.
- 현재 `TestMap`에서는 Room 미지정 Marker 13개와 `RoomContainer` 누락 1개가 실제 저작 상태로 표시된다.
- Scene, Prefab, ScriptableObject는 수정하지 않았다.
- 사용자가 수정 중인 `TestMap.unity`는 수정하거나 스테이징하지 않았다.

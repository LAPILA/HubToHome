# 2026-06-18 업데이트

> 작업 단계: implement / verify
> 목적: 시나리오 저작 에디터를 사람이 읽고 편집하기 쉬운 플로우 보드형 도구로 개선

## [변경]

- `ScenarioAuthoringWindow`를 3패널 보드형 UI로 재구성했습니다.
  - 왼쪽: 개요, 규칙, 시퀀스 목록, 검증 요약
  - 가운데: 선택된 시퀀스의 액션 타임라인
  - 오른쪽: 선택된 액션 인스펙터, YAML 미리보기, 동기화 상태
- 액션 row 클릭 선택을 추가했습니다.
  - 선택된 액션은 오른쪽 인스펙터에서 한국어 이름, ID, 카테고리, 설명, 검증 메시지를 확인할 수 있습니다.
- 액션 파라미터 편집기를 추가했습니다.
  - `ActionCatalogEntry.Parameters`가 있으면 한국어 라벨/설명/필수 여부/타입/기본값을 사용합니다.
  - 카탈로그 metadata가 부족하면 현재 `ParametersJson`의 키를 읽어 fallback 편집 필드를 표시합니다.
  - raw JSON은 `고급 JSON` foldout 아래로 숨겼습니다.
- `저장 및 반영` 버튼을 추가했습니다.
  - source YAML export
  - metadata sync
  - safe runtime asset reimport
  - 순서로 실행합니다.
  - export 실패 시 reimport를 실행하지 않습니다.
- `ZevArchitectureCloneSampleBuilder`가 샘플 `ActionCatalogAsset`에 기본 파라미터 metadata를 생성하도록 보강했습니다.
- `ScenarioActionCatalog_ZEV_ArchitectureClone.asset`을 재생성해 파라미터 metadata를 실제 에셋에 반영했습니다.
- 시나리오 에디터 UX 설계/구현 계획을 추가했습니다.
  - `docs/plans/2026-06-18-scenario-authoring-editor-ux-design.md`
  - `docs/plans/2026-06-18-scenario-authoring-editor-ux-implementation.md`
- `.agents/skills/hubtohome-scenario-authoring/`의 에디터/동기화 지침을 최신화했습니다.

## [의도]

- 아키텍처는 조건 이벤트, Action Sequence, 대사/BGM/fade/module 전환까지 검증됐지만, 실제 콘텐츠 제작은 사람이 에디터에서 읽고 다듬을 수 있어야 합니다.
- 기존 창은 기능은 있었지만 action ID와 JSON 파라미터를 아는 사람에게 유리했습니다.
- 이번 변경은 YAML source of truth와 safe reimport 흐름을 유지하면서, 사람이 액션을 선택하고 파라미터를 직접 편집할 수 있는 표면을 만드는 1차 UX 개선입니다.

## [위험 / 후속]

- 현재 파라미터 입력은 1차 버전입니다.
  - string / float / integer / bool / string array 정도를 우선 지원합니다.
  - DialogueData, AudioClip, Module ID를 실제 asset picker나 registry picker로 고르는 기능은 후속입니다.
- 시퀀스 reorder는 기존 위/아래 버튼 방식입니다.
  - drag-and-drop timeline은 후속입니다.
- 규칙 `when` 편집기는 아직 목록/요약 중심입니다.
  - HP threshold, timing, once, outcome 같은 rule field inspector는 다음 UX 단계입니다.
- raw JSON은 숨겼지만 아직 완전히 제거한 것은 아닙니다.
  - 카탈로그 metadata가 충분히 채워질수록 raw JSON 의존을 더 줄일 수 있습니다.

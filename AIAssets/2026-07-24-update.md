# 2026-07-24 Update

## HUBTOHOME-90 전투 결과 확인 입력 흐름

### 변경 사항

- 전투 결과 화면이 자동으로 닫히지 않고 플레이어 확인 입력을 기다리도록 변경했다.
- 첫 페이지는 EXP, 골드, 드롭을 표시한다.
- 레벨업한 파티원은 한 명당 한 페이지로 분리해 레벨 변화와 실제 상승한 능력치를 표시한다.
- 확인, 전투 확인, 대화 진행 입력을 `GameInput` 기반 단일 공급자로 연결했다.
- 테스트에서 입력을 대체할 수 있는 좁은 인터페이스를 추가했다.
- 각 페이지에 최소 입력 지연을 두어 전투 마지막 입력이 결과 페이지까지 넘어가는 것을 막았다.
- 최소 입력 지연이 0이어도 한 프레임 경계를 보장해 같은 입력이 여러 페이지를 넘지 못하게 했다.
- 표시 세대 토큰으로 외부 비활성화와 중복 실행을 취소해 오래된 코루틴이 남지 않게 했다.
- 양수 입력 지연도 프레임 단위로 취소를 확인해 비활성화 시 불필요한 대기가 남지 않는다.
- 교체된 Fade 코루틴이 최신 Tween 참조를 지우지 않도록 Tween 소유권을 확인한다.
- 기존 결과 UI의 완료, 강제 중단, 비활성화, 파괴 정리 경로를 유지했다.

### 호환성과 영향 범위

- 보상 계산과 지급, 성장 계산, 전투 종료, 저장 데이터는 변경하지 않았다.
- 기존 `_holdDuration` 직렬화 값은 `FormerlySerializedAs`를 통해 최소 입력 지연 값으로 이전된다.
- TestMap 승리 통합 테스트는 결과 화면이 실제로 표시되고 확인 전 유지된 뒤 전투 정리가 이어지는지 검증한다.

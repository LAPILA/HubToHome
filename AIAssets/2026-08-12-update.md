# 2026-08-12 Update

## Chapter 01 Windmill 맵 제작 기반

### 변경 이유

- `Assets/_Game/Content/Maps/Regions/Chapter01`에서 실제 챕터 1 맵 제작을 시작할 수 있도록 Region Scene 1개와 예시 Room 2개가 필요했다.
- 사용자가 먼저 만든 빈 `Windmill.unity`의 GUID를 보존하면서 기존 Room 기반 맵 구조에 맞게 정리했다.

### 변경 내용

- `Windmill.unity`를 `Region_Chapter01_Windmill.unity`로 이동하고 기존 GUID를 유지했다.
- Region Scene에 공용 Gameplay Camera Rig, `Sample Player`, `RoomContainer`, `MapTransitionService`를 배치했다.
- 시작 Room을 `chapter01.windmill.exterior`로 연결했다.
- 회색 블록아웃 Room Prefab 두 개를 추가했다.
  - `Room_Chapter01_WindmillExterior.prefab`
  - `Room_Chapter01_WindmillInterior.prefab`
- Room마다 대응하는 `RoomDefinition`과 `AreaDefinition`을 추가했다.
- 외부와 내부에 Camera Bounds, `default` 포함 SpawnPoint 2개, 상대 Room으로 이동하는 `AreaConnectionMarker` 1개를 구성했다.
- 외부 ↔ 내부 이동 대상 Room과 도착 SpawnPoint를 양방향으로 연결했다.
- Chapter 01 제작 README를 실제 Windmill 자산과 ID 기준으로 갱신했다.

### Inspector 참조

- Scene `RoomContainer._initialRoom` → Windmill Exterior Definition
- Exterior Definition ↔ Exterior Prefab / Exterior Area
- Interior Definition ↔ Interior Prefab / Interior Area
- Exterior Connection → Interior Definition / `from_exterior`
- Interior Connection → Exterior Definition / `from_interior`

### 검증

- Unity 6000.3.8f1 Editor에서 생성과 Domain Reload 완료, C# 컴파일 오류 0개.
- 기존 `Windmill.unity` Scene GUID `9b07fd33843811a4d9f78e94174ee460` 보존 확인.
- Chapter01 내부 `.meta` 14개와 GUID 14개가 모두 고유함을 확인.
- 생성 자산의 참조 GUID와 Room/Area/Marker ID를 정적으로 교차검증했다.
- 실제 Unity 메뉴 `Hub To Home > 오버월드 > 맵 검사 > 현재 열린 룸 맵 검사` 결과:
  - Windmill Exterior Prefab: Errors 0, Warnings 0
  - Windmill Interior Prefab: Errors 0, Warnings 0
  - Windmill Region Scene: Errors 0, Warnings 0
- 마지막 Editor 상태는 Windmill Region Scene 활성, Scene dirty=false, Prefab Stage 없음이다.

### 남은 작업과 위험

- 두 Room은 제작 시작용 회색 블록아웃이며 실제 Windmill 아트, 충돌, 마커와 연출은 아직 없다.
- Region Scene의 `Sample Player`는 템플릿 테스트용이다. 실제 게임 진입 흐름을 붙일 때 정식 Player/Bootstrap 계약을 확인해야 한다.
- Scene은 아직 Build Settings에 자동 추가하지 않았다.
- 파일명은 Unity Project 창에서 바꿀 수 있지만, Room ID는 저장 데이터가 배포된 뒤에는 마이그레이션 없이 변경하면 안 된다.

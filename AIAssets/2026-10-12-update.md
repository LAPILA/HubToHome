# 2026-10-12 개발 학습실 심화 해설

## 범위

사용자가 선택한 2번, 기능별 실제 코드를 따라 읽는 심화 해설을 진행했다. 게임 기능 구현이나 모든 C# 줄에 대한 정밀 감사를 수행한 작업은 아니다.

- [코드 따라 읽기](../docs/study/deep/README.md): 색인 1개 + 해설 10개.
- 실제 C# 파일 22개에서 37곳을 발췌하고 경로·줄 범위·파일/발췌 SHA-256을 기록했다.
- 저장·설정, 전투·방어·후열, 스킬·QTE·속성, 스탯·장비·상점, 상호작용·방 교체, 대사·시나리오, 제작 도구, UI·카메라, 풀·줄바꿈을 다룬다.
- 각 장은 호출 흐름, 실제 코드 해석, 상태 추적, 자료구조와 비용, 실패·취소 경계, 미실행 실습, 면접 질문으로 구성했다.
- [사용자가 지정한 Notion 학습실](https://app.notion.com/p/3f6641f6190180bb8567ff9caf83e5a9) 아래에 [새 심화 색인](https://app.notion.com/p/3f7641f619018140b840faafd0b4128c)을 추가했다. 기존 62개 Markdown·4개 CSV 자료를 재가져오거나 삭제하지 않았다.

## 근거와 검증

`node docs/study/build-deep-import.cjs --check`: 11페이지, 37발췌, 22소스 파일, 본문 60,699자 검증. UTF-8, 소스 범위·해시, 미해결 마커, 코드 펜스, 로컬/게시용 링크와 생성물 일치를 확인한다.

검토 중 시퀀스 저장의 round-trip이 모든 필드의 의미 보존을 보장한다는 인상을 제거했다. 실제 파서의 알 수 없는 최상위 키 건너뛰기를 확인하고, 재가져오기 성공과 구조적 동등성 검증의 차이를 로컬·Notion에 명시했다.

원격 게시 결과와 확인 범위는 [게시 기록](../docs/study/notion-publication.json), 작업 중 교훈은 [상세 기록](yjlim/feedback/2026-10-12-code-walkthrough.md)에 보존한다. 원격 전체 블록의 바이트 단위 일치를 주장하지 않는다.

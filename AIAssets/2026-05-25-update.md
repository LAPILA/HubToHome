## [UIManager] PPC Safe Area Pillarbox 계산 보정

### 원인
- 이전 safe area 계산은 `640x480`의 단순 4:3 비율을 Canvas 안에 맞추는 방식이었습니다.
- 하지만 URP `PixelPerfectCamera`의 `Pillarbox`는 화면 안의 4:3 영역을 그대로 쓰지 않고, `zoom = min(Screen.width/refX, Screen.height/refY)` 정수 배율을 먼저 구한 뒤 `refX * zoom`을 실제 출력 폭으로 사용합니다.
- 예: `1920x1080`, `ref=640x480`이면 단순 4:3 폭은 `1440px`이지만, PPC pillarbox 실제 출력 폭은 `640 * 2 = 1280px`입니다.
- CanvasScaler가 적용된 UI 좌표계에서는 이 값이 `1280 / canvas.scaleFactor`로 환산되어야 합니다. 사용자가 수동으로 `570` 근처로 맞췄을 때 딱 맞아 보인 이유가 이 환산값과 거의 일치했기 때문입니다.

### 수정
- `Assets/_Game/Core/Scripts/UIManager.cs`
  - `UIPixelPerfectSafeAreaFitter`가 `PixelPerfectCamera.cropFrame`을 읽어 crop mode별 실제 출력 pixel size를 계산하도록 수정했습니다.
  - `Pillarbox`: `refX * zoom`, `Screen.height`
  - `Letterbox`: `Screen.width`, `refY * zoom`
  - `Windowbox`: `refX * zoom`, `refY * zoom`
  - `StretchFill`: 화면 안에 reference aspect를 맞추는 기존 방식
  - 계산된 pixel size를 `Canvas.scaleFactor`로 나눠 overlay Canvas UI 단위로 변환합니다.

### 검증
- `dotnet build .\HubToHome.sln --no-restore` 통과.
- `git diff --check -- Assets/_Game/Core/Scripts/UIManager.cs` 통과.
- 기존 경고만 남음: `System.Net.Http`/`System.IO.Compression` assembly conflict, `PlayerController._defenseReactionLocked` unused.

## [UIManager] OverWorldPanel PPC Safe Area 대응

### 원인
- `OverworldMenuUI`는 `UIManager`가 들고 있는 overlay Canvas 기반 패널입니다.
- 게임 카메라 `PPC`는 reference resolution `640x480`과 pillarbox crop을 사용하므로 실제로 안전하게 보이는 영역은 4:3입니다.
- 하지만 `OverworldMenuUI`의 Top/Bottom/CategoryWindow 계열 UI는 overlay Canvas 전체 폭을 기준으로 stretch되어, 16:9/4K 같은 넓은 화면에서 PPC 안전 영역 밖까지 UI가 벌어질 수 있었습니다.

### 수정
- `Assets/_Game/Core/Scripts/UIManager.cs`
  - 패널별 opt-in 구조로 PPC safe area 대응을 추가했습니다.
  - 현재는 `OverWorldPanel`만 `_fitOverworldPanelToPixelPerfectSafeArea = true`로 처리합니다.
  - `UIManager`가 `OverWorldPanel` 등록/오픈 시 `UIPixelPerfectSafeAreaFitter`를 보장합니다.
  - fitter는 런타임에 `[PPC Safe Area]` RectTransform을 만들고, 패널의 직접 자식 UI를 그 아래로 이동시킵니다.
  - `[PPC Safe Area]`는 활성 `PixelPerfectCamera` 중 이름이 `PPC`인 카메라의 reference resolution을 우선 사용하고, 없으면 `640x480` fallback을 사용합니다.
  - 화면 비율이 변하면 Canvas 내부에서 640:480 비율의 중앙 안전 영역을 다시 계산합니다.

### 범위
- Battle UI는 변경하지 않았습니다.
- 씬 파일은 수정하지 않았습니다.
- `UIRuntimeGuard.NormalizeCanvas()`를 전역으로 재사용하지 않고, UIManager opt-in safe area로 분리했습니다.

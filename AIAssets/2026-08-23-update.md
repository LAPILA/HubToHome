# 2026-08-23 Update

## Windmill Wizzel-ZEV 필수 심리스 전투

### 변경 이유

- Chapter 01 Windmill 외부에서 Wizzel과 ZEV의 대화, 짧은 충돌 연출, 심리스 전투를 한 흐름으로 재생할 필요가 있었다.
- 이 조우는 필수 전투이므로 도주 버튼을 숨기지 않고 회색 비활성 상태로 보여야 했다.
- Dialogue Choice Root가 런타임마다 Y 120으로 돌아가는 배치 문제를 Y 0으로 통일해야 했다.

### 변경 내용

- Dialogue Canvas의 Cinematic/Overworld Choice Root 위치를 모두 `(0, 0)`으로 통일했다.
- `DialogueUI`의 런타임 기본 재배치 값도 `Vector2.zero`로 변경했다.
- `SpeakerData`의 표정 사전을 Odin 직렬화 대상으로 전환하고 `Confused` 표정을 기존 enum 뒤에 추가했다.
- Wizzel의 Normal, Happy, Confused, Angry 얼굴 4종을 픽셀 아트 Sprite 설정으로 정리했다.
- Wizzel/ZEV SpeakerData와 다음 DialogueData를 추가했다.
  - `Dialogue_Wizzel_ZEV_PreClash.asset`: 전투 전 6문장
  - `Dialogue_Wizzel_ZEV_PostClash.asset`: 공격 연출 뒤 2문장
- `DialogueBattleNPC`에 기본 비활성인 staged encounter 흐름을 추가했다.
  1. 전투 전 대화
  2. 플레이어와 NPC가 서로 접근
  3. 서로를 바라보고 일반 공격 애니메이션/VFX 재생
  4. 전투 직전 대화
  5. 준비된 SeamlessBattleHost로 전투 시작
- 중단·비활성화·전투 진입 실패 시 위치, 표시 상태, 입력 상태를 복구하도록 했다.
- 승리한 조우는 안정 ID `chapter01.windmill.zev_duel`로 기록하고 재진입 시 ZEV 조우를 다시 노출하지 않도록 했다.
- 조우별 `AllowEscape` 값을 전투 진입 문맥까지 전달했다.
- 도주 불가 조우에서는 Run 버튼을 계속 표시하되 `interactable=false`로 회색 처리하고, UI 이외의 직접 Run 요청도 전투 로직에서 거부한다.
- Windmill Exterior Room Prefab의 ZEV 인스턴스에 두 대화, staged encounter, 필수 심리스 Host, 도주 금지 설정을 연결했다.

## Windmill Initial Room 로드 오류 복구

### 원인

- 브랜치 이동 과정에서 `Room_Chapter01_WindmillExterior.prefab`에 Git 충돌 마커 5블록이 남았다.
- Unity가 해당 Prefab을 import하지 못해 Exterior `RoomDefinition._roomPrefab` 참조가 런타임에서 null로 해석됐고, `RoomContainer.Start()`에서 `RoomDefinition.IsValid`가 실패했다.

### 수정

- 기존 Windmill Room 내용과 Wizzel-ZEV staged encounter, `SeamlessBattleHost`를 모두 포함한 사용자 작업본으로 Prefab 충돌을 해소했다.
- Prefab의 GUID와 `RoomInstance` fileID는 유지했다.
- 열린 Unity Editor에서는 Exterior Prefab과 Definition만 지정 재임포트하고, import 실패 때 파괴된 세션 내 참조를 같은 Prefab의 `RoomInstance`로 복구했다. Scene과 Definition 자산은 저장하거나 재작성하지 않았다.

### 검증

- Prefab 내부 Git 충돌 마커 0건.
- Git unmerged path 0건.
- Scene `RoomContainer.InitialRoom` 참조 유지.
- Exterior Definition의 Room ID, Room Prefab, `IsValid` 모두 정상.
- Exterior Prefab의 `RoomInstance` GUID/fileID가 Definition 참조와 일치.
- Unity Test Runner와 Play Mode 자동 실행은 하지 않았다.

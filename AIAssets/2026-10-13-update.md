# 2026-10-13 본편 기능 기획 후보 점검

사용자가 기획할 미완성 기능을 요청하여 현행 소스와 제작 데이터를 점검했다. [기능별 현재 상태와 기획 질문](yjlim/feedback/2026-10-13-design-priorities.md)을 남겼다.

핵심은 동료별 역할·자원, 성장/스킬 구성, 장비 고유 효과, 전투 밖 편성, 보상/회복 경제다. 장비 패시브 ID는 실제로 실행되지 않는 예약 필드이며, 성장·스킬 트리·보상은 이미 있어 본편 규칙 확인과 콘텐츠 기획으로 분류했다. 오래된 TODO의 Continue 미구현 표기를 현재 상태로 취급하지 않았다.

변경 파일은 이 기록, 분석 기록, AIAssets/index.md뿐이다. 기존 미커밋 게임 변경은 보존했다. 게임 코드·자산 변경, Unity 실행, 빌드, 커밋, push, 원격 문서 갱신은 하지 않았다. 문자열·파일 목록·소스 경로를 통한 정적 점검이며 기능 완전성이나 실기기 동작을 보증하지 않는다.

## 하네스 교훈

Windows PowerShell에서 `rg docs/study/0*.md`처럼 경로 자체에 와일드카드를 전달하는 첫 검색이 경로 구문 오류로 실패했다. `rg docs/study -g '0*.md' -g '1*.md'`로 바꾸자 정상 검색됐다. 이전 교훈에 이미 있는 실패를 반복했으므로, 다음 작업은 먼저 고유 경로와 `-g` 패턴을 사용한다. 검색 출력이 실제 문서 경로와 일치함을 확인했다. 전역 yjlim 메모리 경로가 없는 현 환경에서는 프로젝트의 이전 [하네스 기록](yjlim/feedback/2026-10-12-code-walkthrough.md)과 이 기록에 남긴다.

## 후속: 챕터 1 전체 기능 목록, 우선순위 제거

사용자의 후속 범위는 챕터 1, 위젤과 동료 2명의 총 3인이다. 이전 우선순위 문서는 과거 기록으로 보존하고 [챕터 1 미완성 기능·기획 결정 목록](yjlim/feedback/2026-10-13-chapter01-feature-inventory.md)을 추가했다. 기능별로 구현 보강/기획·데이터/통합 검증/선택 확장을 구분했다. 후열용 인원 추가와 편성 확장은 필수에서 제외했다.

추가 확인: 본편 동료 합류 경로 부족, 일반 아이템과 장비의 획득 경로 분리, 부활·정화 아이템 액션 부재, 저장 지점의 회복 미연결, 화자명·선택지 번역 미연결. 성장·보상·저장을 통째로 미구현으로 분류하지 않았다. 모바일/정보 열람/챕터 마감과 콘텐츠 규칙까지 기획 질문으로 남겼다.

이번 후속 변경은 새 분석 문서와 이 기록, AIAssets/index.md에 한정한다. 앞서 확인한 사용자 게임 변경은 그대로 유지했다. 읽기 대상 자체 코드와 관련 데이터/학습 문서 760개의 UTF-8 유효성을 확인했고 잘못된 UTF-8은 없었다. 새 문서의 UTF-8 without BOM, 로컬 링크 23개(누락 없음), 기획 항목 ID 49개(중복 없음)를 확인했다. 대상 파일 git diff --check에 공백 오류는 없었다. 게임 실행 검증은 하지 않았다.

### 추가 하네스 교훈

클래스 이름만으로 `Localization/Runtime`, `Dialogue/Runtime/DialogueUI.cs`, `Battle/Runtime/BattleRunPolicy.cs`를 추정한 읽기가 실패했다. `rg --files`와 파일명 필터로 실제 위치(Core/Runtime, UI/Runtime, Battle/Runtime/Services)를 확인한 뒤 읽기/검색에 성공했다. 프로젝트가 기능별 폴더라고 해도 클래스의 역할만으로 경로를 추정하지 않는다. 또한 넓은 `Quest` 부분문자열 검색은 `Request`까지 매칭해 출력이 잘렸다. 전용 기능 탐색은 파일명이나 단어 경계로 제한하고, 큰 파일은 작은 구간으로 읽는다. 검증은 확인된 파일 경로와 실제 선언/호출자 출력으로 한다.

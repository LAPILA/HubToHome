# 2026-05-10 업데이트

> 기준 데이터: 현재 작업 트리 변경분, 최신 푸시 기준일(2026-05-09) 이후 수정 스크립트  
> 참고: 2026-05-10에는 아직 신규 커밋/푸시가 없어 작업 트리 기준으로 정리했습니다.

## [구현된 기능]

- `GameConfigManager`가 새로 추가되어 마스터/BGM/SFX 볼륨, 전체화면, 언어, 키 바인딩을 `PlayerPrefs`에 저장하는 공용 설정 저장소 역할을 맡기 시작했습니다.
- `ConfigPanelUI`가 추가되어 타이틀 화면에서 실제로 열 수 있는 설정 패널이 생겼습니다.
- `TitleMenuManager`의 `Settings` 버튼이 더 이상 빈 동작이 아니라 설정 패널을 띄우는 흐름으로 연결됐습니다.
- `PlayerController`, `UIManager`, `IntroManager`, `NameInputUI` 일부 입력이 `ConfigurableAction` 기반으로 이동해 향후 키 리매핑을 받을 준비가 됐습니다.

## [수정된 버그]

- `LocalizationManager.ChangeLanguage(...)`가 선택 언어를 즉시 저장하도록 바뀌어 언어 설정이 세션 간 유지됩니다.
- `AudioManager`에 마스터 볼륨 경로가 추가됐고, 믹서 참조가 없을 때도 바로 예외로 이어지지 않도록 방어 로직이 들어갔습니다.
- `NameInputUI`가 입력 길이(2~10자)를 제한하고 공백을 trim한 뒤 확정하도록 바뀌어 이름 입력의 흔들림이 줄었습니다.
- 설정 패널이 열려 있는 동안 타이틀 메뉴 입력이 겹치지 않도록 차단 로직이 추가됐습니다.

## [남은 기술적 부채]

- `TitleMenuManager.OnClickContinue(...)`는 아직 실제 저장 데이터 로드나 씬 이동으로 연결되지 않았습니다.
- `ConfigPanelUI`는 내부 이동 키를 여전히 하드코딩된 화살표/WASD/Z/X에 의존하고 있어, 새 키 설정 시스템과 완전히 일치하지 않습니다.
- `IntroManager`와 `NameInputUI`가 언어 단축키를 각각 따로 처리하고 있어 설정 책임이 분산돼 있습니다.
- `ConfigPanelUI`의 텍스트가 대부분 영어 하드코딩이며, 기존 `LocalizationManager`와 연결되지 않았습니다.
- `AudioManager`는 Voice 볼륨 API를 갖고 있지만, `GameConfigManager`와 `ConfigPanelUI`에는 아직 Voice 설정 항목이 없습니다.

## [구현된 기능]

- `GameConfigManager`가 공용 설정 저장소로 자리 잡으면서 볼륨, 언어, 텍스트 속도, 자동 진행, 화면 흔들림, 전체화면, VSync, 목표 FPS, 조작키 리바인딩을 한 경로에서 저장하고 즉시 적용하게 됐습니다.
- `ConfigPanelUI`가 카테고리 기반 런타임 설정 패널로 확장됐습니다. 오디오, 게임플레이, 조작키, 시스템 옵션을 한 화면에서 바꿀 수 있고, 키 입력 캡처와 기본값 복구도 지원합니다.
- `GameInput`가 `Player / UI / Battle / Dialogue / Config` 액션맵을 하나의 파사드로 감싸며, 설정에서 바꾼 키가 실제 이동, UI 선택, 전투 입력, 대사 입력에 다시 반영되도록 연결됐습니다.
- `DialogueManager`가 다시 선택지 분기와 선택지 기반 전투 시작을 처리합니다. `ChoiceData.StartBattleEncounter`와 `DialogueEncounterContext`를 통해 대화에서 전투로 넘어가는 수직 흐름이 생겼습니다.
- `BattleEncounterService`가 추가되어 오버월드 접촉 전투와 대화 선택 전투가 같은 진입 파이프라인을 사용하게 됐습니다. 이 서비스가 적 목록, BGM, 복귀 씬 정보, 전용 배틀 씬 사용 여부를 공통 처리합니다.
- `OverworldEnemy`가 델타룬식 순찰 적으로 확장됐습니다. 순찰, 접촉 시 전투 진입, 전투 후 재등장 쿨다운, 승리 시 영구 제거 같은 상태를 `GlobalDataManager`와 함께 관리합니다.
- `DialogueBattleNPC`가 추가되어 접촉형 적과 별도로 "대화 후 선택지 전투" NPC를 만들 수 있게 됐습니다.

## [수정된 버그]

- `DialogueUI`가 타입라이터 출력 직후와 다음 프레임에도 텍스트 속도를 다시 적용하도록 바뀌어, 설정한 텍스트 속도가 외부 타입라이터 기본값에 덮이는 문제를 완화했습니다.
- `ConfigPanelUI`가 `ScrollRect`의 `content`와 `viewport`가 비정상적으로 연결된 프리팹 상태를 런타임에 자동 보정하도록 바뀌어, 긴 설정 목록에서 스크롤이 깨지는 문제를 방어합니다.
- `GameInput`가 설정 모달에서 `Submit`과 좌우 조절 입력에 fallback 경로를 추가해, 액션 바인딩이 비어 있거나 프리팹 연결이 불완전할 때 설정 패널이 먹통처럼 보이는 상황을 줄였습니다.
- `BattleManager`와 `GlobalDataManager`가 전투 종료 시 조우 결과를 명시적으로 기록하도록 바뀌어, 오버월드 적의 승리/도주 후 상태를 복구할 기반이 생겼습니다.
- `OverworldEnemy`가 전투 시작 직전에 트리거 잠금, 이동 정지, 콜라이더 비활성화를 먼저 수행하도록 바뀌어 연속 접촉으로 전투가 중복 시작되는 문제를 부분 완화했습니다.

## [남은 기술적 부채]

- `TitleMenuManager.OnClickContinue(...)`는 아직 실제 `SaveManager.Load(...)`와 연결되지 않았습니다. 저장/이어하기 수직 흐름은 여전히 비어 있습니다.
- `OverworldEnemy_v1` 커밋 메시지에 남아 있듯, 도주 후 적 콜라이더와 이동 상태가 완전히 안정화됐는지는 추가 플레이테스트가 필요합니다.
- `ChoiceData`는 아직 `ChoiceText` 원문 문자열 중심입니다. 선택지 자체를 `LocalizationKey` 기반으로 옮기지 않아 다국어 대사 파이프라인과 분리돼 있습니다.
- 상태이상 적용 로직이 `BattleManager.ExecuteItemEffect(...)`와 `InventoryManager`에 문자열 분기 형태로 남아 있어, 공용 `StatusFactory` 또는 레지스트리로 합쳐야 합니다.
- 설정 패널은 언어 fallback을 일부 내장하고 있지만, 설정 문구 전체가 `LocalizationTable.csv`로 완전히 이관된 상태는 아니며 Voice 전용 볼륨도 아직 스펙에 없습니다.

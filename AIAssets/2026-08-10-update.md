# 2026-08-10 Update

## 640×480 전투 UI 클리핑·말풍선 크기 회귀 수정

### 증상과 원인

- `TurnQueuePanel`의 좌표는 공용 Battle Host 이관 전과 같았지만, `RectMask2D`의 확장 padding과 softness가 0으로 바뀌어 50×50 초상화가 잘렸다.
- 현재 작업 브랜치에 `f547ba59`의 640×480 말풍선 보정이 포함되지 않아, WorldSpace 말풍선 스케일이 0.01로 남고 Box 상한도 720×540이었다.

### 변경 사항

- `TurnQueuePanel`의 기존 clip padding `(-100, -130, 0, -100)`과 softness `(10, 10)`을 복원했다.
- Player, Enemy Base, ZEV, BunnySlime 캐릭터 프리팹의 말풍선 스케일을 0.005로 통일했다.
- Player/Enemy 공용 말풍선의 최대 Box 크기를 480×240으로 제한했다.
- 텍스트 기반 크기 계산이 가로뿐 아니라 세로 상한도 적용하도록 `ClampBoxSize`를 사용한다.
- 말풍선 크기 계산 테스트 3개와 실제 Prefab 설정을 검사하는 Editor 테스트를 추가했다.

### 검증

- 수정 전 자산 계약 검사에서 말풍선 스케일 4건, 최대 크기 2건, TurnQueue mask 1건의 실패를 재현했다.
- 수정 후 같은 자산 계약 검사 전체를 통과했다.
- 말풍선 관련 9개 기존 파일이 `f547ba59`의 검증된 결과와 일치함을 확인했다.
- Unity Roslyn 입력으로 `Assembly-CSharp`와 신규 Editor 테스트를 포함한 `Assembly-CSharp-Editor` 컴파일을 통과했다.
- `git diff --check`를 통과했다.

### 미검증 및 주의점

- Play Mode와 640×480 최종 시각 확인은 수행하지 않았다.
- `SeamlessBattleHost.prefab`에 작업 시작 전부터 존재하던 TMP material, Canvas scale, 기타 RectTransform 직렬화 변경은 되돌리지 않고 보존했다.
- BattleScene에는 TurnQueue 관련 Prefab override가 없어 공용 Host 수정이 자동 반영되며, 별도 씬 저장이나 동기화는 필요하지 않다.

## 640×480 Config 패널 레이아웃 복구

### 증상과 원인

- 1920×1080용 자식 오프셋이 640×480 크기로 축소된 `BackGround`에 남아 `SettingsCategories`와 `SettingsDetailViews`의 실제 높이가 약 39.68px까지 줄어 있었다.
- 상세 행은 100×100 루트 안에 200px 이름 열, 150px 간격, 200px 값 열을 두어 100px짜리 상세 영역을 구조적으로 넘었다.
- `ScrollRect.viewport`와 `content`가 비어 있고 런타임이 Content만 추론해 만들었으므로, 행이 상세 영역에서 잘리지 않고 카테고리와 미리보기 위로 흘러나왔다.
- 상단 pivot Content에 중앙 pivot용 스크롤 수식을 사용해 선택 행 이동과 카테고리 전환 후 위치도 잘못 계산됐다.

### 변경 사항

- 공용 `UIManager.prefab/SettingPanel`을 640×480 논리 좌표로 정렬하고, 외곽 프레임 안에 제목·카테고리·상세·미리보기 영역을 다시 배치했다.
- 상세 영역에 명시적인 `Viewport → Content → Row` 구조와 `RectMask2D`, `VerticalLayoutGroup`, `ContentSizeFitter` 연결을 직렬화했다.
- 설정 행을 340×44 한 줄 2열로 바꾸고 이름/값 열의 폭, 자동 글자 크기, 말줄임을 고정했다.
- `ConfigPanelUI`가 잘못된 Scroll/Row 계약을 조용히 추론하지 않고 구체적인 진단 코드로 거절하도록 바꿨다.
- 상단 pivot 기준 스크롤 수식, 카테고리 전환 시 top 복원, 파괴 대기 행 즉시 비활성화를 적용했다.
- Prefab 계약, 스크롤 수학, 실제 행 가시성, Controls→Audio 전환 회귀 테스트를 추가했다.

### 검증

- Unity 스크립트 컴파일 오류 0개를 확인했다.
- `ConfigPanelLayoutAssetTests` 6/6, `ConfigPanelScrollTests` 7/7, `UIManagerStackTests` 7/7, `UIRuntimeGuardTests` 1/1을 통과했다.
- 전체 EditMode는 1048개 중 1038개가 통과했다. 실패 10개는 TurnQueue projection, 캐릭터 시각 접근성, 장비/전투력, 복구 흐름, 오버월드 적 저장·파티 체력, Production Action Library 등 Config 범위 밖 테스트다.
- 640×480 Play Mode에서 Config 창의 화면 이탈과 글자 겹침이 사라진 것을 사용자가 직접 확인했다.
- 전체 테스트가 다시 생성한 ShowcaseStation/TravelTrain 런타임 자산 변경은 제거했고, 작업 전부터 존재한 `SeamlessBattleHost.prefab`과 `TestMap.unity` 변경은 해시가 같은 상태로 보존했다.

### 미검증 및 주의점

- 사용자가 640×480 결과를 승인해 1280×960 및 KR/EN/JP/CN 조합별 수동 순회는 생략했다.
- Config 범위 밖의 기존 `SeamlessBattleHost.prefab`과 `TestMap.unity` 변경은 이번 Config 커밋에 포함하지 않는다.

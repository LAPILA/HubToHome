## AreaSystem / Map Marker 기획자 배치 구조 정리

### 변경 내용

- AreaSystem 마커 공통 기반을 `AreaMarkerBase` 중심으로 정리했다.
  - Odin 기반 기본 정보/런타임 규칙/에디터 표시/검증 섹션 추가
  - 공통 `Validate Marker` 버튼 및 `CollectValidationIssues(List<string>)` 추가
  - 타입별 색상/축약 라벨/SceneView Gizmo 아이콘 규칙을 `AreaMarkerDefaults`로 통합
- 마커가 직접 대화/전투/아이템/맵 이동을 하드코딩하지 않도록 `AreaMarkerRuntimeService`를 추가했다.
  - dialogue 시작
  - Room/Scene 연결 요청
  - 전투 시작 요청
  - 아이템 지급
  - 상점/저장/퍼즐/하자드/내부 서브로케이션 요청
- `AreaConnectionMarker`, `OverworldEnemyMarker`, `SublocationMarker`, `ItemPickupMarker`, `VendorMarker`, `SavePointMarker`, `HazardMarker`, `PuzzleMarker` 등은 위 runtime service seam을 통해 실제 실행을 위임하도록 정리했다.
- 각 마커 타입은 개별 `CollectValidationIssues(...)`를 통해 누락 참조를 보고하도록 보강했다.
  - connection: `MapTransition` 또는 `targetSceneName`
  - enemy: `EnemyData`, battle scene

## TimelineCutsceneRunner waitForComplete 비동기 수명 버그 수정

### 변경 내용

- `TimelineCutsceneRunner.PlayCutscene(...)`의 `waitForComplete=false` 경로를 수정했다.
- 기존에는 `director.Play()` 직후 코루틴이 종료되면서 `finally`에서 `director.Stop()` / `Destroy()`가 즉시 실행되어, 비동기 재생 옵션이 사실상 동작하지 않았다.
- 이를 해결하기 위해 `TimelineCutscenePlaybackLifetime` 컴포넌트를 추가했다.
  - director `stopped` 이벤트 구독
  - 비동기 재생 중 cleanup 책임 소유
  - `lockInput=true`일 때 이전 `GameState` 복구
  - `restoreCamera=true`일 때 카메라 복구
  - cancellation 감지 시 stop 요청 및 cleanup
  - stopped 이벤트 구독 해제 보장
- `waitForComplete=true` 경로도 lifetime 기반 cleanup을 사용하도록 정리해 종료/취소 시 정리 경로가 한 군데로 수렴되게 했다.
- `TimelinePlayActionAdapter`의 failure message에 `cutsceneId`를 포함하도록 보강했다.
- EditMode 테스트 `TimelineCutsceneRunnerTests`를 추가했다.
  - `waitForComplete=false`일 때 director가 즉시 Destroy되지 않는지 검증
  - `waitForComplete=true`일 때 stopped 후 cleanup되는지 검증
  - 대기 경로에서 cancellation 시 cleanup되는지 검증

## 도구 기록

- Unity 생성 솔루션의 임시 `project.assets.json`이 없어 일반 `dotnet build --no-restore`는 기준 검증으로 사용할 수 없었다. 열린 Unity Editor의 컴파일 상태와 Unity Test Runner를 권위 있는 결과로 사용했다.
- Windows 샌드박스가 기존 `Assets` 파일의 `apply_patch`를 차단했다. 신규 파일은 `apply_patch`, 기존 파일은 동일 unified diff를 `git apply --recount`로 적용했으며 `git diff --check`로 결과를 검증했다.

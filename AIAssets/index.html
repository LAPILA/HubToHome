시스템 아키텍처 지도

architecture.md의 핵심 책임과 의존 관계를 카드로 재정리

Architecture

설정/입력 계층

GameConfigManager가 저장과 적용을 담당하고, GameInput이 입력 액션에 반영합니다. ConfigPanelUI는 프런트엔드입니다.

전투 진입 계층

BattleEncounterService가 오버월드 접촉, 이벤트, 대화 선택지 전투를 공통 진입 파이프라인으로 묶습니다.

영속 오버월드 적

OverworldEnemy는 순찰, 접촉, 승리 제거, 도주 쿨다운 등 월드 상태를 가진 엔티티로 확장 중입니다.

클래스역할주요 의존
GameConfigManager설정 저장, 즉시 적용, 키 리바인딩 저장AudioManager, LocalizationManager, Screen, PlayerPrefs, GameInput
GameInputPlayer/UI/Battle/Dialogue/Config 액션맵 파사드InputSystem_Actions, GameConfigManager

BattleManager전투 유닛 세팅, 심리스/전용 씬 전투, 조우 결과 기록GlobalDataManager, AudioManager, PositionManager, SceneLoader

주요 플레이 루프

현재 플레이 가능한 루프를 기획/개발이 함께 보기 쉽게 정리

Game Loop
1Title / Intro타이틀 → 인트로 → 이름 입력 → 대화 흐름은 구현됨.
2Overworld플레이어 이동, 상호작용, 적 접촉, 룸 기반 맵 전환 구조가 동작.
3Dialogue → Battle대화 선택지에서 전투 컨텍스트를 만들고 공통 조우 서비스로 전달.
4Battle Return심리스/전용 배틀 씬 전투 후 결과를 기록하고 월드 상태로 복귀.

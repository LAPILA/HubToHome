## Area Marker 상호작용 키 정리

### 변경 내용
- `OverworldEnemyMarker`에서 `IPreemptiveAttackTarget` 구현과 `canPreemptiveAttack` 필드를 제거해 Area Marker Enemy가 F 선공 공격 탐색에 잡히지 않게 했다.
- Area Marker 상호작용은 기존 오버월드 규칙과 동일하게 `PlayerController` → `GameInput.ConfirmPressed` → `InteractionSystem.TryInteract()` 경로의 Z 확인 입력만 사용한다.
- 기존 실제 순찰/접촉 적인 `OverworldEnemy`의 F 선공 공격 기능은 유지했다.
- `InteractionSystem`이 매 프레임 `FindFirstObjectByType<PlayerController>()`를 호출하던 구조를 `_player` 캐시로 정리했다. 플레이어가 없거나 재생성된 경우에만 다시 찾는다.
- `AreaInteractionPrompt` 주석을 Area Marker가 F 선공 공격 경로를 쓰지 않는다는 현재 정책에 맞게 수정했다.
- `Room_AreaMarker_AllGizmos.prefab` 샘플 안의 12개 마커 레이어가 `Default`로 남아 `InteractionSystem`에 감지되지 않던 문제를 수정했다. 샘플 마커 GameObject 12개를 `Interactable` 레이어로 변경했다.
- 샘플 생성 메뉴 `HubToHome/오버월드/Area 마커/샘플/전체 마커 Room Prefab 생성`을 `AreaMarkerPrefabGenerator`에 복구/보강했다. 재생성 시 각 샘플 마커가 `Interactable` 레이어, Trigger Collider, Z 상호작용용 샘플 데이터로 구성된다.
- 샘플 Hazard는 자동 접촉 발동 대신 Z 테스트가 가능하도록 `triggerOnEnter=false`로 조정했다.
- 샘플 PlotPoint는 Z 테스트가 가능하도록 `triggerMode=OnInteract`로 조정했다.
- 샘플 Sign/Enemy 설명의 F 문구를 Z 상호작용 문구로 수정했다.

## Area Marker 대사 반복/아이템 획득 표시 정책 정리

### 변경 내용
- 대화 종료 Z 입력이 같은 프레임의 오버월드 Z 상호작용으로 다시 소비되어 NPC/표지판 대화가 즉시 재시작될 수 있던 경로를 막았다.
  - `DialogueManager.EndDialogue()`에서 `GameInput.SuppressPlayerConfirmForCurrentFrame()`를 호출한다.
  - `GameInput.ConfirmPressed`는 해당 프레임 동안 오버월드 확인 입력을 무시한다.
- `AreaMarkerBase.CanInteract(...)`가 `isOneShot` + `setFlagOnComplete` 조합일 때 `GlobalDataManager` 플래그를 확인하도록 했다.
  - 같은 씬 런타임에서는 `_completed`로 막고, 저장/로드나 재입장 후에는 완료 플래그로 막는 정책이다.
- `NPCMarker`, `SignMarker`의 새 마커 기본값을 `isOneShot=true`로 바꿨다.
  - 단, 인스펙터에서 `isOneShot=false`로 바꾸면 같은 대사를 계속 반복할 수 있다.
  - `setFlagOnComplete`와 다른 `DialogueData`/문구를 조합하면 “한 번만”, “나중에 대사 변경”, “항상 같은 대사 반복”을 모두 만들 수 있다.
- `ItemPickupMarker`가 아이템 지급 후 대화창을 띄우도록 보강했다.
  - `pickupDialogueData`가 있으면 해당 대화를 실행한다.
  - 없으면 `pickupMessage` 또는 자동 생성 문구(`* itemId을(를) 얻었다.`)를 1노드 대화로 표시한다.
  - 아이템 one-shot 완료는 획득 대화 종료 시점에 처리하고, 대화 시작 실패 시에는 즉시 완료 처리한다.
- `AreaMarkerPrefabGenerator` 샘플 생성 값에 NPC/Sign one-shot 완료 플래그와 Item 획득 메시지를 추가했다.
- 기존 `Marker_NPC`, `Marker_Sign`, `Marker_Item`, `Room_AreaMarker_AllGizmos.prefab` 샘플 직렬화 값을 현재 정책에 맞게 보강했다.

### 의도

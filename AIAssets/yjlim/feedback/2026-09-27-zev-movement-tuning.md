# ZEV 스킬 이동 — 데이터만 미세 조정

요청 범위에 따라 `Assets/_Game/Content/Skills/Enemy/ZEV`의 5개 SkillData만 조정했습니다. C#·씬·프리팹·적 편성·피해량·타격 수·방어창 시간/조건은 변경하지 않았습니다. 본편과 실험실이 이 스킬을 공유하므로 양쪽에 적용됩니다.

| 스킬 | 수정 |
|---|---|
| 강한 참격 `Skil_Zev` | 클로즈업 뒤 추가 준비 0.65 → 0.22초. 중앙 이동과 C 대응은 그대로 |
| 연참 `Skill_ComboSlash` | 뒤쪽 이동 0.01 → 0.12초, 마무리 전 간격 0.2 → 0.1초 |
| 내려치기 `Skill_Crash` | 공격 위치 정렬을 방어창 앞으로 이동, 자동 공격 위치/0.16초 사용. 기존 끝의 중복 복귀·재접근 블록 비활성 |
| 고속참 `Skill_BlinkSlash` | 지상 접근 0.08 → 0.12초. 머리 위 이동·중복 VFX/공격 트리거·끝의 뒤쪽 이탈 비활성 |
| 환영호참 `Skill_PhantomArc` | 중간 중앙 이동 0.08 → 0.14초. 2타 구성 유지 |

비활성 블록은 삭제하지 않고 스킬 메이커에서 이유를 읽을 수 있도록 라벨을 붙였습니다. 최종 원위치 복귀는 기존 공통 교전 정리(`SkillContext.ReturnDefender`)가 담당합니다. `Action_Move`는 이동할 때 Move/Idle을 재생하므로 방어 결과와 피해 사이에 끼우지 않았습니다. 현재 중앙 교전에서 TargetFront/AttackStaging/OriginalPos는 공통 교전 위치로 해석됩니다. 임의의 새 이동 코드나 점프를 추가하지 않았습니다.

검증: 수정 전 연참의 0.05초 미만 이동, 내려치기의 방어→이동→피해 순서를 데이터로 확인했습니다. 수정 후 활성 블록에는 두 패턴이 없고, 5개 스킬의 타격 8개/방어창 8개 및 모든 RID 참조를 확인했습니다. 방어창/피해 블록은 원본 값과 대조해 그대로임을 확인했습니다. 기존 회귀 검사도 비활성 블록을 제외하는 구조입니다. Unity 실행/테스트/강제 Refresh는 하지 않았으므로 실제 애니메이션 체감은 미검증입니다.

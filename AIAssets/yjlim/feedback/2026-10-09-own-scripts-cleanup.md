# 자체 스크립트 정리 결과

게임 사용법이나 프리팹 연결을 바꾸지 않고, 사용하지 않는 파일과 중복 구현을 정리했습니다. 외부 플러그인·패키지·씬·프리팹·콘텐츠 자산은 수정하지 않았습니다.

## 달라진 점

- C# 691개를 정적으로 조사하고 미사용 파일 6개와 해당 meta를 제거했습니다. 현재 685개입니다.
- YAML 읽기·쓰기, 전투 연출 위치 계산, 설정 입력 조회의 중복 구현을 기존 공통 처리로 모았습니다.
- 호출되지 않는 내부 함수 7개를 제거했습니다. 테스트 보강을 포함해 499줄 줄었습니다.

삭제 파일은 빈 AreaMarkerIconGenerator, AreaMarkerDialogueRunner, DeltaruneRoomMapSampleBuilder와 임시 CodexTemporaryEditModeTestRunner, 구현 없는 AllyCharacter, 미사용 EventFlags입니다. 실제 아군은 기존 PlayerCharacter 경로를 그대로 사용합니다. 이벤트 플래그 저장 방식도 그대로입니다.

## 그대로 사용하는 것

콘텐츠 메이커·스킬 메이커·시퀀스 메이커, Odin 버튼, 기존 전투·대사·세이브 기능은 유지합니다. 별도로 다시 연결하거나 데이터를 변환할 필요는 없습니다. 자산에 연결된 배경·메뉴·VFX 코드와 공식 호환 경로는 삭제하지 않았습니다.

Accepted spine

Encounter Definition / Battle Scenario Data owns Battle Event Rules. Battle Event Rules decide When. Action Sequences execute Do. Game Modules share Battle Session State. Encounter Memory is save-bound; in-progress Battle Session State is not.

Save Scope: outside battle only
AI authoring model: human describes flow, AI writes rules and actions
Risk to avoid: `BattleManager` becoming the scenario authoring surface
Strong in-process top recommendation

Top recommendation

Start with Battle Scenario Data

It creates the deepest interface first: one authoring surface for When rules, Do sequences, module switching, save-bound Encounter Memory, and battle outcomes. Without it, Action Director and GameModuleHost become powerful tools with no stable scenario owner.

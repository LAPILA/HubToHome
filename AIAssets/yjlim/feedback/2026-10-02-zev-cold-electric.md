# 제브 — 냉기·감전 고난도 패턴

기존 `BunnySlimeBattleLab`의 ZEV 전투에 연결했습니다. 새 Play로 확인하며 씬 재생성이나 Inspector 재연결은 필요 없습니다. 3색 위젤3 대 제브1, 기존 대사·진입·복귀는 유지합니다.

## 다섯 가지 공격

| 스킬 / 기존 파일 | 변화 | 대응 |
| --- | --- | --- |
| 빙섬 / `Skill_BlinkSlash` | 이동0.07초, 피해×1.65, 냉기4 | Z/X, 방어창0.40초 |
| 뇌광 순회 / `Skill_ComboSlash` | 전열을 섞어 한 명씩 직접 접근. 대상당1타×1.15, 감전35. 이동0.08초/타격 후 간격0.06초 | 대상별 별도 Z/X, 방어창0.42초 |
| 동결 낙인 / `Skill_Crash` | 짧은 도약·추가 대기0.22초 뒤 강타×2.25, 냉기6 | Z/X, 방어창0.68초 |
| 잔뢰 이연 / `Skill_PhantomArc` | ×1.05 → 멈춤0.16초 → 측면 이동 → ×1.8. 타격마다 감전25 | Z/X 두 번, 방어창0.40/0.52초 |
| 극성 단죄 / `Skil_Zev` | 중앙 특수 참격×4.2, 냉기4+감전60 | Z 불가. X 회피/C 반격, 방어창0.65초 |

실험실은 위 순서대로 반복합니다. 패턴은 익힐 수 있도록 유지하고 공격 대상은 고정 순번이 아닙니다. 방어창 수치는 데이터 시간이며 기존 입력 보정·국소 감속·후입력 유예가 유지됩니다. 냉기10 빙결, 감전 타격 반응, 가드의 부여량 감소와 완전 방어의 부여0도 그대로입니다.

실험실 제브: **HP3,600 / ATK34 / DEF6 / SPD20**(이전2,200/28/6/15). 실험용 시작값이며 실제 승률·체감으로 검증한 최종 밸런스는 아닙니다. 본편 `Enemy_ZEV.asset` 능력치는 보존했지만 같은5스킬을 공유하므로 스킬 변경은 본편에도 적용됩니다.

## 공통 적 타깃

- 일반 공격/단일 스킬은 **가중 랜덤**. 최근4회와 직전 대상 확률을 낮추고, 낮은 HP 우선도는 최대25%만 높입니다.
- 유효 대상이 둘 이상이면 같은 대상3연속 금지. 혼자 살아 있으면 계속 그 대상을 선택합니다. 이름 대신 인스턴스로 구분하므로 샘플 위젤3명도 독립적입니다.
- 여러 적이 전투 이력을 공유합니다. 한 스킬의 연타 대상은 유지하고 전체공격·대기·예약 준비는 이력을 소비하지 않습니다. 플레이어 입력/예고 행동은 읽지 않으며 명시적 시나리오 대상도 덮지 않습니다.
- 뇌광 순회는 전체 대상의 중복 없는 무작위 순서를 만든 뒤 각 생존 아군을 한 번씩 공격합니다. 동시 광역 피해가 아닙니다.

## 조절 위치와 소유권

- 스킬 메이커에서 `Assets/_Game/Content/Skills/Enemy/ZEV/`의 기존5개를 편집합니다. ID/GUID는 유지했습니다. **기본 정보 → 명중 시 상태 부여**와 실행 블록에서 수치를 바꿉니다.
- 순회: **전체 대상 선택 → 방어 대응 → 연쇄 근접**, **적: 각 대상 앞으로 직접 접근** 켬. **대상 간 이동 시간**, **타격 후 간격**으로 속도를 조절합니다. 타격을 포함하므로 별도 피해 블록을 추가하지 않습니다.
- 순회 준비 중 임의의 첫 아군을 중앙에 부르지 않습니다. 실제 대상 표시 → 아군 전진/임시 방어 기준점 → 적 돌진 → 대상별 전조/판정/피해 → 아군 복귀 → 다음 대상으로 이어집니다. 마지막 적 복귀는 기존 스킬 루트가 담당합니다.
- `BattleEnemyTargetSelector<T>`는 전투당 최근 이력/가중치만 소유합니다. Turn QTE 서비스가 생존·활성과 HP 비율을 전달합니다. 프레임별 검색이나 데이터 자산의 런타임 변경은 없습니다.
- 개별 접근은 기본값false. 기존 중앙 교전은 그대로입니다. 취소 시 블록이 적의 시작 위치·Idle을 복원하고 기존 방어 scope가 아군 위치/입력 기준점을 해제합니다. 잔상은 이동에만 사용합니다.

## 검증과 남은 확인

- 실제 정책 소스로9,000회 실행: 2,939/3,154/2,907회, 고정 다음 순번이 아닌 선택4,900회, 같은 대상3연속0회. 단독 생존/null/빈 목록/랜덤 경계값도 통과.
- 5스킬의 ID·GUID·블록 RID 연결, 냉기/감전, 전조Center, 방어창≥0.40초, 적 QTE/투사체 없음 검사. 새 정책 스크립트는 메타 포함, generated csproj가 아직 포함하지 않으면 ignored Temp MSBuild include로 컴파일합니다.
- 공통 선택 공유 이력·광역 비소비·연타 고정, 개별 준비의 중앙 배치 생략 및 기존 중앙 배치 기본값을 NUnit 검사로 추가/갱신했습니다. Runtime/Editor 컴파일 확인. NUnit·Unity Play·Refresh·씬 저장은 실행하지 않았습니다.
- 실제 대상별 접근, 카메라·피격 리듬, 냉기/감전 난도는 수동 확인 대상입니다. 새 전투 모드, 제브 이름 하드코딩, 투사체, 적 공격용 아군 QTE는 추가하지 않았습니다.

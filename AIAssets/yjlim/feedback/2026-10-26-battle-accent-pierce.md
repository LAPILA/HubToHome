## 변경 결과

| 항목 | 현재 동작 |
| --- | --- |
| 컷인 | Lab8개 완전 제거. 옛 enum0은 호환용 무재생 값이며 그림/음향/대기도 없음 |
| 실루엣 | 실제 배우의 현재 Sprite/피벗/PPU/부모 배율/flip을 그대로 복제. 자동 확대·초상 대체·전체 암전 없음 |

| 재준비 표시 | 캐릭터 왼쪽 작은 게이지: 회색으로 차오른 뒤 준비되면 노랑. 재준비 중에도 Z 홀드 일반 방어 가능 |
| 관통 | 증기 찌르기/임계압 돌파는 화면 좌우 끝1회, 역류 참격은 왕복2회. 실제 대상X 통과 시 피해 |

일반 방어는 기존65% 피해 감소, 저스트는0피해/AP·압력 보상이다. X/C와 아군 스킬 QTE에는 Z 재준비를 적용하지 않는다. 이미 확정된 저스트 성공을 이후 연타가 취소하지 않는다. 재준비보다 느린 규칙적인 입력은 계속 허용하며, 모든 반복 입력을 임의로 실패시키거나 확률 실패를 넣지 않는다.

## 제작자가 바꾸는 곳

- `QTEManager → Z / X / C 방어 → 반복 Z 재준비 (초)` 기본0.18초. 0으로 설정하면 이 제한만 끈다. 실제 상한은 각 공격 길이의 절반이다.
- 스킬 메이커 **실루엣 · 명중 점멸**: 실루엣은 현재 배우 크기로 고정. 점멸은 다음 피해 앞, 적은 **방어 대응 앞**에 예약한다. 방어 대응과 피해 사이에는 넣지 않는다. 난무50타/광역도 예약1개당 점멸1회다.
- **화면 가로 관통**: 횟수1~3, 화면 끝 접근/준비/돌파/정지/복귀 시간, 여백, 관통당 피해·속성을 설정한다. 자체 피해이므로 Damage 블록을 중복하지 않는다. 현재3종의 기존 총 배율은 보존했다.
- 기존 Lab15개 SkillID/GUID, DB/Catalog/Scenario 연결은 동일하다. 원본15개 스킬을 덮어쓰지 않았다. 옛 일회용 `ShowcaseAuthoring/BuildPatch.ps1`은 컷인을 재작성하므로 다시 실행하지 않는다.

## 코드와 소유권

- `ParryRearmState`는 대상별 실제 press를 기록한다. 같은 timestamp의 Player.Update/QTE 관찰은 중복이 아니다. 막힌 Z도 기록해 연타가 재준비를 연장하지만 홀드 가드는 별도다. 모달/일시정지/비적행동/배우 종료는 입력·표시를 비운다. 게이지는 필요할 때 한 번 만들고 재사용한다.
- `BattleSkillAccentSpriteView`는 활성 중에만 실제 Renderer 프레임/가시성/정렬을 맞춘다. `SkillAccentImpactRequest`는 유효 명중 전에 예약을 소비하므로 연타·동시 대상에 중복되지 않는다. 살상타도 생존 검사보다 먼저 통지한다. 정상 완료만 짧은 점멸 꼬리를 허용하고 취소는 즉시 정리한다.
- `Action_ScreenPassSlash`와 `BattleScreenPassGeometry`는 실제 HUD 안전영역·배우 반폭·여백·픽셀 격자에서 끝점과 교차 비율을 계산한다. 자기 프레이밍 범위로 카메라를 보존하고 새 카메라/Timeline 제어권은 빼앗지 않는다. DOTween의 자기 Tween만 진행/정리하며 이동 때만 잔상, 정상·취소 모두 자기 home/flip을 복구한다. 렌즈/PP/Dutch0/HUD는 유지한다.

- 전체 C# CLI Runtime473/Editor386소스, 오류0/0, 기존 경고226/0.
- Z 실제 정책 관리형479단언+소스 통합8계약.0.05/0.10/0.15초 간격의60개 빠른 연타 trace는 기존 정책에서60/60저스트였고 재준비 적용 시0/60저스트·홀드 일반 방어였다. 첫 전조 입력/X/C/짧은 공격 상한도 확인했다.

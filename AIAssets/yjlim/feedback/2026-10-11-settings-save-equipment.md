# 설정과 저장 지점 및 장비 사용법

설정은 즉시 적용되며 진행도 저장과 분리됩니다. 진행도는 저장 오브젝트에서 수동으로 저장하거나 지정한 대사·컷씬·보스 승리에서 자동 저장을 요청합니다. 씬과 프리팹은 이번 작업에서 변경하지 않았습니다.

## 수동 저장

기존 `SavePoint` 또는 `SavePointMarker`를 그대로 사용합니다. 상호작용하면 수동 저장 1~3 중 하나를 선택하며, 기존 기록에는 덮어쓰기 안내가 붙습니다. X 또는 취소 항목으로 빠져나옵니다. 기록 성공 후에만 완료를 표시합니다.

`quickSaveSlot`은 처음 선택할 칸의 우선순위입니다. 내부 값은 0~2입니다. 저장 지점은 반복 사용하도록 `1회성`을 끄세요. 기존 `DialogueManager`의 오버월드 대화 패널 연결이 필요합니다. 패널이 없는 씬에서는 확인창을 열 수 없으며 자동으로 확인 없이 저장하지 않습니다.

접촉 자동 저장은 기본적으로 꺼 두세요. 필요할 때만 켜며, 예전 자동 슬롯 필드 값과 무관하게 자동 전용 99번 칸을 사용합니다.

## 대사와 컷씬 자동 저장

1. 연출 중에도 활성 상태인 관리 오브젝트에 `ProgressSaveTrigger`를 추가합니다.
2. 대사라면 `자동 저장 요청 이벤트 ID`에 고유 이름을 넣고, 마지막 대사 노드의 `EventTriggerID`에도 같은 이름을 넣습니다.
3. UnityEvent 기반 컷씬이라면 완료 이벤트에 해당 컴포넌트의 `RequestAutoSave()`를 연결합니다. 코드에서는 `SaveManager.RequestAutoSave()`를 호출합니다.

스토리 플래그와 보상 반영 후 요청하는 것이 원칙입니다. 대사 노드 시작에 요청되더라도 실제 기록은 대화창 닫기까지 기다립니다. 임의의 `save.*` 시퀀스 액션을 새로 추가한 것은 아닙니다.

## 보스 승리 자동 저장

같은 컴포넌트에서 `전투 호스트`를 연결하고 `승리 시 자동 저장`을 켠 뒤 `대상 조우 ID`를 넣습니다. 이 값은 해당 전투의 `GlobalDataManager.CurrentEncounterEnemyId`와 일치해야 합니다. 캐릭터 DB의 표시 이름이나 스킬 ID가 아닙니다.

컴포넌트는 승리 이벤트를 받을 때 활성 상태여야 합니다. 전투 중 꺼지는 필드 적 오브젝트 대신 관리 오브젝트에 두세요. 전투 결과 콜백은 저장 요청만 보내며 실제 파일 기록은 보상 UI 종료와 필드 복귀 뒤 수행합니다. 빈 ID나 다른 적 승리, 도주, 패배는 자동 저장하지 않습니다. 전용 전투 씬에서는 그 씬의 호스트를 연결합니다.

중복 요청은 합쳐지며 항상 자동 슬롯 99에 기록합니다. 수동 기록은 덮어쓰지 않습니다. 새 게임이나 다른 기록을 불러오면 이전 자동 요청은 취소됩니다. `AutoSaveCompleted` 결과 이벤트로 별도 저장 표시 UI를 붙일 수 있습니다.

## 불러오기

타이틀의 기본 `이어하기`에서 최근 기록, 수동 기록, 자동 기록을 구분합니다. 빈 칸/읽기 불가 표기가 있으며 실패 이유는 확인창으로 안내합니다. 기존 `_continueSlot`을 0 이상으로 지정한 타이틀은 해당 칸을 바로 읽는 동작을 유지합니다. 타이틀에 오버월드 대화 패널이 없으면 기존 최근 기록 로드로 동작합니다.

손상 시 본 파일 → 백업 → 임시 파일 순으로 복구합니다. 더 새로운 게임 버전의 본 파일은 현재 버전으로 덮어쓰지 않습니다. 필요한 경우 다른 수동 칸을 사용하세요. 기록 확인은 `Hub To Home > 도구 > 저장 데이터 진단`에서 할 수 있습니다.

## 설정과 장비

- 설정 변경은 즉시 적용, 마지막 변경 0.5초 뒤 디스크 기록입니다. 닫기·앱 일시 중지·종료에서도 기록합니다. X는 적용 취소가 아닙니다.
- 640×480 기준, 마우스 입력 차단, VSync/FPS 항목 미노출은 유지합니다. 모바일·콘솔에는 PC 창 크기 설정을 적용하지 않습니다.
- 설정 이름과 값은 독립 너비/자동 글자 크기/말줄임으로 겹침을 방지합니다. 실제 각 언어·기기 화면 확인은 필요합니다.
- 장비 인벤토리 수량은 장착 중인 물건까지 포함한 총수량입니다. 착용분은 제거할 수 없고 여분만 제거할 수 있습니다.
- 장비 조회/목록 열기로 저장 데이터를 바꾸지 않습니다. 교체 시 자동 회복이나 부활은 없으며 HP/AP 상한이 낮아지면 현재량을 자릅니다.
- 무기·장신구1·장신구2·머리·몸·신발과 기존 배율 계산을 유지합니다. 예약 패시브/장착 대사 ID는 여전히 실행 기능이 아닙니다.

## 검증 범위

CLI 런타임/에디터 컴파일과 순수 관리형 검사를 사용했습니다. 실제 Unity Play/EditMode, 설정창 화면/타이틀 선택창 배치, 모바일 앱 중단, 콘솔 저장 API는 실행 검증하지 않았습니다. 이벤트를 지정하지 않은 기존 보스/컷씬에는 자동 저장이 임의로 추가되지 않습니다.

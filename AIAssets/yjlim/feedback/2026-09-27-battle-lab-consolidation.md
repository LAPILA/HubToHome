# 토끼 슬라임 / ZEV — 통합 전투 실험실·대사 보정

최종 정리: ZEV는 `Content/Skills/Enemy/ZEV` 원본 5개를 직접 사용합니다. 4개 임시 대체 스킬은 참조 해제 후 제거했습니다. 아군 실습 스킬 15개는 `Content/Skills/Ally/BattleLab`, 토끼 실습 스킬 11개는 `Content/Skills/Enemy/BunnySlime`로 `.meta`와 함께 이동했습니다. 기존 파티·적·카탈로그 연결은 유지됩니다.

후속 수정: 토끼 대사 5개의 배경/초상이 없는 Cinematic 패널 연결을 Overworld로 변경했습니다. ZEV까지 대사 9개 모두 기존 공용 파란 배경을 그대로 사용하며 색·알파·공용 프리팹은 변경하지 않았습니다. 위젤 실습 화자에는 준비된 4개 표정을 연결했고, 말랑 감독관은 기존 초상을 사용합니다. ZEV 원거리 샘플과 적/카탈로그 참조는 제거했습니다. 실제 화면은 Play 미검증입니다.

## 바로 확인

**Hub To Home → 테스트 → 전투 실험실 열기 → Play → ↑↓ → Z**.

기존 씬을 그대로 엽니다. 삭제·재생성할 필요 없습니다. 전투 중 **F8**은 실험실 메뉴 복귀입니다.

| 선택 | 내용 |
| --- | --- |
| 토끼 슬라임 · 통합 | 기존 종합/가드·회피/C를 하나로 합침. 근접·투사체·C·X·연타·상태·광역 순환. 오프닝/HP 단계/종료 대사·BGM 포함 |
| ZEV · 연출 전투 | 클로즈업 → 공격 준비 → 줌아웃 → 기존 전조·방어·타격. 연참 → 강한 참격(C) → 내려치기 → 고속참 → 환영호참. 위젤과 시작·HP65%·HP30%·종료 대화 |
| 3+3 · 후열 확인 | 기존 전멸 실습 유지. 전열 HP1, 후열 정상 HP, 광역 공격 하나 |

파티·아이템·장비는 기존 실험실 데이터를 공유합니다. 저장 파일을 읽거나 쓰지 않고, 종료/패배/F8 후 회복해 메뉴로 돌아옵니다. 수동 교대와 별도 적 QTE는 추가하지 않았습니다.

## 어디서 수정하나요?

공통 폴더: `Assets/_Game/Content/Maps/Development/BunnySlimeBattleLab`.

| 바꿀 것 | 위치 |
| --- | --- |
| 전투 메뉴·적·시나리오 | `Data/BunnySlimeBattleLab.asset > 전투 목록` |
| 체력·스킬 순서 | `Data/Enemy/BunnySlime_Lab.asset` / `ZEV_Lab.asset > SkillList` |
| 준비 줌·시간 | `Assets/_Game/Content/Skills/Enemy/ZEV`의 각 스킬 > 적 공격 준비 · 클로즈업 |
| Z/X/C 시간·피해 | 같은 스킬의 기존 방어 대응 / 피해 블록. 전조는 ImpactCuePrefab, Center 사용 |
| 대사 내용·화자·표정 | `Data/Scenario/Dialogue_ZEVLab_*.asset` |
| 대화 발생 조건·카메라 순서 | 시퀀스 메이커 + `Content/Scenarios/Source/Battle/BunnySlimeBattleLab/zev_lab.scenario.yaml` |

적 패턴은 `EnemyData.스킬 목록 순서대로 사용`을 켜면 목록의 빈 칸을 건너뛰고 반복합니다. 꺼진 본편 적의 AI는 바뀌지 않습니다. ZEV의 프리팹과 스킬은 본편 자산을 공유하며 실험 능력치·편성 순서만 별도 데이터입니다. 따라서 이번 원본 스킬 전조 보정은 본편에도 적용됩니다. 원본 피해량·이동 수치·참격 VFX는 유지했습니다. 고속참의 상승은 방어창 앞으로 옮겨 판정 뒤 피해 지연을 없앴습니다.

## 구조와 같이 고친 문제

- 메뉴 번호에 따른 임시 EnemyData 복제/스킬 덮어쓰기를 제거했습니다. 세션은 진입·복귀만 담당하고, 전투 내용은 데이터에서 읽습니다.
- 준비 블록은 기존 CameraController의 행동 토큰을 사용합니다. 새 카메라나 임의의 전역 리셋을 만들지 않았습니다. 방어창은 줌아웃이 끝난 뒤 열립니다.
- 토끼 시나리오의 parallel 자식과 뒤 대사가 누락되던 YAML 파서를 수정하고 원본에서 복구했습니다. 이는 연출이 저장되어 보이면서 실제 내용은 빈 상태였던 문제입니다.
- 기존 오버월드 대화창을 사용하고 창이 닫힐 때까지 기다립니다. 대화 중 전투 HUD는 Canvas만 숨겨 대사를 가리지 않게 했습니다. F8은 해당 실행 소유 대화를 정리합니다.

## 검증과 남은 확인

최종 CLI 런타임·에디터 증분 컴파일 오류/경고 0. ZEV 8회 타격의 방어창·Center 전조와 GUID/RID를 정적으로 검사했습니다. 추가 회귀 테스트는 아직 Unity에서 실행하지 않았습니다. **Play 화면, 실제 줌 배율·타격 모션·대화 표시와 모바일 성능은 미검증**입니다. 기존 14개 스킬의 삭제된 아이콘 참조는 빈 값으로 정리했습니다. 스킬 메이커에서 새 아이콘을 연결할 수 있습니다.

사용자 수정 `Player_Base.prefab` 및 `Art/Battle/`는 보존했습니다. 커밋/푸시하지 않았습니다. 브랜치 `codex/gameplayEdit`.

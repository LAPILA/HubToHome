# 필드 메뉴 · 작은 창과 방향키/클릭 조작

2026-10-19 · `gameplayEdit` · 커밋/푸시 없음

## 변경 결과

기준 출력은 640×480 그대로이며 실제 메뉴만 **592×416**으로 재배치했다. 외곽 좌우24/상하32 기준 픽셀의 여유가 생긴다. 글자까지 0.9배로 줄이지 않아 기존 폰트 크기와 정수 출력 정책을 유지한다. 목록·스킬 트리·긴 설명·능력치 마지막 행은 스크롤한다.

배경은 창을 그리기 전에 한 번 캡처하고, 가로320px 이하로 줄인 뒤 가로/세로 두 번의 5탭 필터로 흐리게 한다. 어두운 막은 별도로 겹친다. 메뉴와 텍스트는 흐려지지 않는다. 새 카메라·상시 Volume·매 프레임 캡처는 없다. ScreenCapture 때문에 화면 크기 임시 RT 한 장이 잠시 필요하며 4K 초과 출력, 미지원 그래픽 환경, 셰이더/자원 실패에서는 어두운 막만 표시한다. 리사이즈 시 낡은 캡처는 버리고 열린 메뉴를 다시 캡처하지 않는다.

## 조작

| 입력 | 동작 |
|---|---|
| 방향키/패드 방향 | 금색 포커스 이동. 탭·분류·동료·목록·트리·편집·적용·초기화·설정·뒤로에 접근 |
| Z / 기존 패드 확인 | 포커스 항목 실행. 능력치 행에서는 수량 입력 시작, 편집 중 다시 확인하면 편집 종료 |
| X / 기존 패드 취소 | 숫자 편집 종료 → 대상/읽기/확인창 취소 → 상단 탭 → 메뉴 닫기 |
| 클릭/터치 | 해당 탭·목록·동료·버튼 선택, 숫자 입력, ± 길게 누르기 |
| 휠/밀기 | 목록·트리·설명 스크롤. 설명에는 방향키로 접근할 수 있는 ↑/↓ 버튼도 제공 |

Q/E/C/R과 패드 보조 버튼은 기존 단축키로 남지만 필수 조작은 아니다. 화면 안내는 네 언어에서 방향키·확인·취소 중심으로 갱신했다. 키 변경 중에도 현재 취소 키로 빠져나올 수 있다.

설정은 메뉴를 닫지 않고 **위에 모달로 연다**. 돌아오면 이전 페이지·동료·포커스와 미적용 배분이 유지된다. 설정 카테고리·행·값 ±·뒤로도 클릭/터치를 지원한다. 설정의 기존 저장·볼륨·언어·키 변경 서비스는 유지한다. 전투 중에는 기존 열람 전용 제한을 우회하지 않는다.

## 모바일과 수명

- 인벤토리 또는 설정이 열려 있는 동안 기존 가상패드를 숨기고 눌림을 해제한다. 공용 EventSystem의 다른 게임 화면 클릭은 켜지 않는다.
- 메뉴 전용 브리지만 실제 Mouse/Touch를 받는다. 모바일 터치와 에뮬레이션 마우스의 중복 클릭을 방지한다. 다른 모달·닫기 중·동일 프레임의 키/포인터 명령을 중복 실행하지 않는다.
- OS 숫자 키보드는 안전 영역과 별개다. 편집 필드와 키보드가 겹치면 배율은 유지한 채 창 위치를 올리고 편집 후 복구한다. 플랫폼이 키보드 영역을 보고하지 않는 동안만 하단45%를 보수적 장애 영역으로 취급한다. 이 대체값은 실제 기기에서 조정할 수 있는 후속 확인 대상이다.
- 닫기/disable/destroy는 캡처 코루틴·RT·자체 Material만 해제한다. 메뉴가 자신이 연 설정을 먼저 즉시 닫고 pause 상태를 복원하므로 CloseAll/씬 이탈 때 설정의 늦은 종료가 timeScale0을 남기지 않도록 했다.
- 능력치·스킬·아이템·장비 변경과 저장 데이터 소유자는 기존 서비스다. 배경·포커스는 저장하지 않는다.

## 파일 위치

메뉴 전용 C#10개와 기존 meta는 `Assets/_Game/Scripts/UI/Runtime/FieldMenu/`로 모았다. `README.md`의 수정 위치 표를 시작점으로 사용한다. 기존8개 스크립트와 신규2개를 이동했으며 이동 전후 meta10개의 SHA256이 모두 같다. 타입명·GUID·직렬화 필드·기존 Prefab 참조는 유지했다.

- 배치: `FieldMenuView.cs`의 `FrameSize`와 `Build`, `FieldMenuGrowthView.cs`.
- 입력/설정 진입: `OverworldMenuUI.cs`, `FieldMenuNavigation.cs`, `FieldMenuTouchInput.cs`.
- 설정 자체: 상위 `UI/Runtime/ConfigPanelUI.cs`.
- 흐림: `Presentation/UI/Shaders/MenuBackdropBlur.shader`, `_Game/Resources/HubToHome/FieldMenuBackdropBlur.mat`.
- 게임 규칙: 기존 Core/Characters/Items. 개발용 샘플: 기존 `Content/Maps/Development`. 공통 코드·아트·플러그인은 이동하지 않았다.

임시·본편 구분은 용도 기준이며 파일명으로 AI 제작 여부를 판정하지 않는다. 출처나 개발 기록을 삭제·위장하지 않았고, 이번 UI 코드가 수작업 아트의 출처 증명을 대신하지도 않는다.

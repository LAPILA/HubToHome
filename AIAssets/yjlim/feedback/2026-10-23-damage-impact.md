# 모든 명중의 짧은 충격감

후속 사용자 피드백으로 아래 초기 정지 수치는 대체했다. **현재는 캐릭터 정지 기본0과 준비–명중 카메라 컷을 사용한다.** [최신 적용·조정 안내](2026-10-23-battle-impact-cuts.md)를 우선 본다. 아래 내용은 초기 구현/검증 기록이다.

별도 씬 연결 없이 기존 아군·적의 공통 피해 처리에 적용된다. HP/피해 숫자/기존 효과음은 즉시 확정하고 백색 실루엣과 기존 `CharacterVFX.Hit_Effect`도 그 순간 재생한다. 잠깐 잡힌 피격 자세가 풀리면 기존 Hurt/반동으로 이어진다. 새 음원이나 VFX 자산을 생성한 것은 아니다.

| 상황 | 대상 Animator 정지 | 표시 원칙 |
| --- | --- | --- |
| 일반 직접 명중 | 0.045초 | 즉시 백색·기존 타격 VFX |
| 최대 HP의 10% 이상 피해 | 0.065초 | 조금 더 무겁게 잡힘 |
| 직전 명중 후 0.12초 이내 | 0.016초 | 백색 점멸 상한0.045초, 타격 사이 원색 복귀 |
| 같은 갱신 사이 여러 피해 | 남은 정지 연장 없음 | VFX 요청은 한 번, 피해 횟수·합계는 그대로 |
| 상태 지속 피해 | 추가 정지 없음 | 진행 중 직접 명중의 표시/반동을 취소하지 않음 |
| 치명 피해 | 추가 정지 없음 | 타격 VFX 후 기존 사망 연출 우선 |

회복·MISS·무적/완전 방어·순수 피해0/음수에는 새 정지를 만들지 않는다. 공격자·전조/방어/QTE 시계와 카메라·HUD·음악·전역 시간 배율은 바꾸지 않는다. 강한 타격 기준은 연출 강도만 선택하며 데미지를 증폭하지 않는다.

## 나중에 수치 조정하기

캐릭터 루트의 `CharacterHitFeedback` → **명중 피드백**에서 한글 Odin 필드를 조정한다. 첫 직접 피격에 자동 추가되므로 기본 적용을 위해 수동 배치할 필요는 없다. 값을 영구적으로 캐릭터별 조정하려면 Play 밖에서 해당 캐릭터 Prefab 루트에 이 컴포넌트를 미리 추가하고 저장한다. Play 중 자동 추가된 컴포넌트의 수정값은 종료 후 보존되지 않는다.

- **기본 정지 / 강한 타격 정지**: 위 표의 시간. 0이면 Animator를 멈추거나 한 프레임 지연하지 않는다.
- **강한 타격 기준**: 최대 HP 대비 한 번의 직접 피해 비율.
- **연타 구분 간격 / 연타 정지 / 연타 점멸 상한**: 연속 공격의 멈칫거림·백색 유지가 과해지지 않게 조정한다.
- 타격 그림·음원은 기존 `CharacterVFX`의 **Hit_Effect**와 전투 효과음 경로를 그대로 사용한다. 미할당 이펙트는 생성하지 않는다.
- 백색 강도는 기존 설정의 플래시 강도를 따른다. 0이면 흰색 재질을 연결하지 않는다.

새 카메라·전체 화면 효과·추가 Renderer를 만들지 않는다. 백색 재질은 캐릭터별 최초 생성 후 재사용하며 원본 공유 재질·Y정렬·flip을 수정하지 않는다. 반동 Tween은 기존 소유 범위 내에서만 정리한다. 새 모션·disable/destroy·외부 Animator/재질 제어권 교체 시 지연 Hurt가 남지 않는다.

- Runtime436/Editor362소스 CLI 컴파일 오류0, 경고225/0. 기존 경고를 없다고 보고하지 않는다.
- 실제 `CharacterHitFeedback` 수명 코드를 관리형 Unity/DOTween 대체 타입으로 실행해196단언 통과: 일반/큰타격·50타/10Hz·같은 갱신 다중 명중·점멸 사이 복귀·모달 정지·속도/재질 소유권·취소·0초 설정.
- Editor 회귀 소스에는 실제 Enemy 감전 추가 피해와 HP/상태 이벤트 보존, 순수0/음수 피해, contact 중복 방지, disable 후 재시작을 추가하고 컴파일했다. 엔진 NUnit 실행 결과는 아니다.

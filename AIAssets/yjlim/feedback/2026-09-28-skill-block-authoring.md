# 스킬 만들기 — 복제부터 전투 연결까지

화면 연출 추가(2026-10-19): 토끼 실험실 첫 위젤의 **7번째 `단층 베기`(AP 12)**는 별도 `Action_Damage` 뒤에 **사선 화면 절단** 블록을 둡니다. 약 0.3초간 게임 화면만 갈라 비틀고 Overlay HUD는 유지합니다. 블록 추가 위치는 **공통 · 흐름과 연출 → 사선 화면 절단**입니다. [실행 순서·조절값·원리·성능 한계](2026-10-19-diagonal-screen-slash.md). 실험실 전용 Renderer 연결이며 본편 DB/저장은 바꾸지 않습니다. GPU/Unity Play는 미검증입니다.

설명 작성 기준(2026-10-07): 플레이어가 읽는 설명은 효과 중심으로 한두 문장만 씁니다. 예: “뜨거운 검으로 적을 베어 화상을 남긴다.” 타수·연타·Z/X/C·QTE·카메라 순서·테스트 안내는 설명란에 넣지 않고 블록 제작 메모에 적습니다. 상태 키워드 색상은 유지하고, AP·대상·자원 조건은 기존 전용 표시를 활용합니다. 이번에 샘플 설명 61개와 생성 문구를 정리했으며 실제 동작·수치는 변경하지 않았습니다. CLI 컴파일 오류 0개, 기존 경고 2개. Unity 재생 검사는 하지 않았습니다.

전조 기준 추가 갱신(2026-10-07): 기본은 매 타격 직전의 공통 성공 구간에 전조/핑을 내는 방식입니다. 새 방어 블록의 **추가 예고 연출 사용**은 기본 꺼짐이며 **타격 직전 전조 프리팹**을 연결합니다. 추가 예고/다음 턴 예약은 고급 연출로 남지만, 그 준비 구간을 방어 성공 신호처럼 디자인하지 마세요. 준비 자세 뒤 → 타격 신호와 공격 모션 → 접촉/판정 순서를 사용합니다. 기존 Z/X/C 여유 수치는 유지했습니다.

현재 코드 기준 갱신: **2026-10-02**. 처음에는 아래 순서대로 기존 샘플을 복제하세요. 스킬은 독립 `.asset` 데이터이고 캐릭터 프리팹에 대사처럼 하나씩 작성하는 구조가 아닙니다.

## 바로 사용하기

1. Unity 상단 **Hub To Home → 제작 → 스킬 메이커**를 엽니다.
2. 왼쪽에서 비슷한 스킬을 선택하고 원본의 변경을 먼저 저장한 뒤 **스킬 복제**를 누릅니다. 새 ID를 가진 독립 자산이 만들어집니다.
3. 저장 위치는 아군 `Assets/_Game/Content/Skills/Ally/<캐릭터>/`, 적 `Assets/_Game/Content/Skills/Enemy/<적 이름>/`입니다. 실험실 예제는 아래 표의 기존 폴더를 사용합니다.
4. **기본 정보**에서 이름·설명·아이콘·사용 범위·AP·대상을 바꿉니다. 아군 공격은 대상 **적**, 회복은 **아군**입니다. 광역은 **전체 대상 선택**을 켭니다.
5. **실행 블록**에서 위에서 아래로 실행 순서를 편집합니다. 블록 선택 → 아래 설정 편집. **목록 표시 이름**은 알아보기 쉬운 이름, **제작 메모**는 작업 설명입니다.
6. **블록 추가**, ↑↓ 이동, 복제를 사용합니다. 실수는 Ctrl+Z로 되돌리고, **검사 · 시간축**에서 오류·경고를 확인한 뒤 상단 **변경 저장**을 누릅니다.
7. 아래 **캐릭터에 넣기**에 따라 캐릭터/적 DB와 카탈로그를 연결합니다. 스킬 파일만 만들면 전투 메뉴에 자동으로 추가되지는 않습니다.

완전히 새로 만들려면 **새 스킬 → 빈 스킬**입니다. 적은 **새 스킬 → 적 공격 → 일반 공격 (Z · X)** 또는 **연계 반격 공격 (X · C)**에서 시작하면 됩니다. Play 중에는 편집이 잠깁니다. 파일명과 표시 이름을 바꾸더라도 이미 저장에 사용한 `SkillID`는 임의로 바꾸지 마세요.

## 방어 대응 편집 순서

- **대응 · 판정**: 공격 대응 방식, C 반격 ATK 배율, 판정 시간, 실패 피해 배율.
- **공격 모션 · 전조**: 공격 트리거, 타격까지 시간, 타격 직전 전조 프리팹·피벗, 준비 자세·판정 후 대기.
- **실패 연출 / 고급 · 개별 판정 / 추가 전조 · 예약 공격 / 구형 호환 설정**은 필요할 때 펼칩니다. 접어도 기존 설정은 계속 적용됩니다.
- 타격 직전 전조와 추가 전조는 서로 다른 설정입니다. 이번 정리는 표시만 묶으며 어느 쪽도 자동 해제하지 않습니다.

## 제작 시 주의

- 이동·애니메이션·이펙트만으로 피해가 생기지 않습니다. 별도 **피해 적용**을 연결합니다.
- 투사체·연쇄 근접·고속 연격·공중 회전은 피해를 포함하므로 같은 타격의 피해 블록을 중복 추가하지 않습니다.
- 아군 QTE와 적 Z/X/C 대응은 별개입니다. 적 입력에는 **방어 대응**을 사용합니다.
- C 반격 배율은 공격받은 아군 한 명의 ATK 기준입니다. 전열 전체가 반격한다는 기존 안내를 정정했습니다.
- 시간은 초, 피해 배율 1은 기본값입니다. 연쇄 근접의 기존 `DashSpeed`는 실제로 이동 **시간**이므로 표시 이름만 바로잡았습니다.

### 아군 QTE와 적 방어 대응

- 아군 **실시간 입력(QTE)**는 다음 이동·애니메이션과 병행됩니다. 일반 **피해 적용**은 적용 직전에 진행 중 QTE 결과를 확정하므로, QTE 제한 시간과 공격 모션의 타격 시점을 맞춥니다. 5초 내내 별도 입력을 받으며 반복 타격하려면 일반 QTE를 계속 복제하지 말고 **고속 연격 · 독립 QTE**를 사용합니다.
- 적 일반 템플릿은 **이동 → 방어 대응 → 피해 적용 → 복귀**입니다. 적 Animator의 실제 준비/공격 Trigger 이름과 방어 대응의 이름을 맞춥니다. 템플릿의 예시 Trigger 이름이 모든 적에 존재한다고 가정하지 마세요.
- 적 투사체는 **방어 대응 → 투사체**를 인접하게 둡니다. 투사체가 피해를 포함하므로 뒤에 같은 타격의 피해 적용을 추가하지 않습니다. 적 스킬에는 아군 QTE 블록을 넣지 않습니다.
- 적 단일 공격은 **최근 집중 완화 보정 랜덤**입니다. 생존·활성 전열만 포함, 낮은 HP 우선도 최대25%, 다른 대상이 있으면 동일3연속 금지입니다. 여러 적이 이력을 공유하며 한 스킬의 연타는 같은 대상을 유지합니다. 전체 공격·대기·예약 준비는 이력을 소비하지 않습니다. 캐릭터 이름/인덱스 하드코딩이나 플레이어 입력 읽기는 없고 시나리오 명시 대상은 별개입니다.
- **한 스킬 안에서 전열을 각각 공격**하려면 제브 `Skill_ComboSlash`를 복제합니다. **전체 대상 선택**, **방어 대응 → 연쇄 근접**을 연결하고 **적: 각 대상 앞으로 직접 접근**을 켭니다. 섞인 순서로 생존 아군에 한 번씩 접근·전조·판정·타격합니다. **대상 간 이동 시간**, **타격 후 간격**으로 속도를 조절하고 별도 피해 블록은 중복 추가하지 않습니다. [제브5스킬 설정](2026-10-02-zev-cold-electric.md).

## 화상·냉기·감전·출혈·중독 붙이기

**공격 명중으로 쌓는 값**은 `기본 정보 → 누적 상태 → 명중 시 상태 부여`에 추가합니다.

1. 항목 추가 → **누적 상태** 선택 → **부여량** 입력.
2. **부여 주기**를 선택합니다. `스킬당 대상별 1회`는 3타여도 대상마다 한 번, `명중할 때마다`는 유효한 타격마다 적용합니다.
3. 실제 피해가 들어가야 부여됩니다. 완전 방어·회피는 0, 일반 가드는 부여량도 감소합니다. 추가 저항 배율은 대상의 누적 상태 규칙을 따릅니다.
4. 연타의 **감전 타격 발동 계수**와 **감전 부여량**은 서로 다른 값입니다. 예제 50타는 발동 계수 `0.1`, 부여량 `0.2`, 주기 `명중할 때마다`입니다. 소수 부여량은 내부에 누적됩니다.

예: 불씨 베기의 상태를 **화상 / 6 / 스킬당 대상별 1회**로 두면 여러 타격으로 늘려도 해당 스킬은 한 대상에게 화상6을 한 번 부여합니다. 세 타격마다 화상3을 넣고 싶으면 **화상 / 3 / 명중할 때마다**로 바꿉니다. 피해 속성만 변경한다고 누적 상태가 생기지는 않습니다.

설명에는 `<color=#FF9856>화상</color> +6`처럼 색상 태그를 사용할 수 있습니다. **설명은 효과를 실행하지 않으며 수치를 자동 갱신하지 않습니다.** 데이터와 함께 수정하세요. 전투 피해 숫자는 글자 약자 없이 색으로만 표시하고, 적 발밑에 별도 상태 아이콘과 수치가 나타납니다.

### 상태를 소비하거나 회복하는 기술

`실행 블록 → 블록 추가 → 공통 · 피해와 효과 → 누적 상태 · 소비 / 정화 / 회복`을 추가합니다.

| 처리 | 설정 방법 | 주의 |
| --- | --- | --- |
| 상태 소비 피해 | 상태 종류, 소비량, 소비 1당 피해 | 소비량0은 전부. 지정량보다 적으면 현재 보유량만 소비 |
| 5종 상태 정화 | 대상 아군, 전체 대상 여부 | 5종 누적 상태와 빙결 정화. 일반 기간제 버프 전체 삭제가 아님 |
| HP 회복 | 대상 아군, HP 회복량 | 부활 기능이 아님 |
| 즉시 상태 피해 | 발동할 상태 종류 | 현재 값으로 피해만 즉시 발생. 값 소비·자연 감소·중독 성장 없음. 냉기는 피해 없음 |
| 상태 소비 기절 | 상태 종류, 기절 필요/소비량 | 충분한 값 + 기절 허용 대상일 때만 소비·1회 행동 기절 |

본인만 회복하려면 **선택 대상 대신 시전자**를 켤 수 있습니다. 일반 공격의 상태는 위의 **명중 시 상태 부여**로 설정하고, 별도 `상태 부여` 블록으로 같은 수치를 다시 넣지 마세요. **상태 효과 부여** 블록은 구형 N턴 상태/일반 버프용으로 남아 있으며, 새 5종 누적 상태와 같은 시스템이 아닙니다.

| 적 일반 스킬 | 해당 `EnemyData → SkillList` |
| 적 예약 강공격 | 해당 `EnemyData → StrongSkillList`, `TelegraphStrongSkill` 및 예고 턴 수 |
| 저장/장착 복원 | `Assets/_Game/Resources/HubToHome/GameContentCatalog.asset`의 스킬 목록 |

실험실 토끼의 적 DB는 `Content/Maps/Development/BunnySlimeBattleLab/Data/Enemy/BunnySlime_Lab.asset`입니다. **스킬 목록 순서대로 사용**을 켜면 일반 스킬 목록을 반복하므로 샘플 검증에 적합합니다. 이 모드에서는 확률/예약 강공격 선택보다 일반 목록을 우선합니다. ZEV는 기존 ZEV 적 DB가 참조하는 스킬을 편집합니다.

캐릭터 연결과 카탈로그 등록은 메이커의 복제/저장만으로 자동 처리되지 않습니다. **검사 · 시간축 → ID · 저장 복원용 카탈로그 → 참조 목록 다시 검사**에서 누락·중복을 확인합니다. 경고를 없애려고 기존 ID를 재사용하지 마세요.

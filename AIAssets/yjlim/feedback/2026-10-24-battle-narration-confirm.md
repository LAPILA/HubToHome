# 전투 중앙 상단 안내 · Z로 전체 표시와 즉시 넘기기

브랜치 `gameplayEdit` · 커밋/푸시 없음 · [당일 검증 기록](../../2026-10-24-update.md)

## 조작

| 현재 표시 | Z / 기존 확인 액션 |
| --- | --- |
| 글자가 나오는 중 | 문장 전체 표시 |
| 문장이 모두 보임 | 즉시 닫고 다음 안내/전투 진행 |
| 다른 설정·대화·후열 선택 모달 표시 중 | 뒤의 안내창은 입력을 가로채지 않음 |

한 번 누른 입력으로 전체 표시와 닫기를 동시에 처리하지 않는다. 큐에 다음 문장이 있으면 현재 문장만 끝내며, 다음 문장이나 메뉴·대상 선택·방어에 같은 입력을 다시 사용하지 않는다. 기존 패드/모바일 확인 액션도 같은 경로를 사용하며 키 바인딩은 변경하지 않는다.

자동 종료 안내는 입력하지 않아도 원래 설정된 유지 시간 후 닫힌다. 확인 필수 안내는 자동 종료하지 않지만 본문이 보인 뒤 바로 확인할 수 있다. 기존 유지 시간 설정을 삭제하거나 프리팹을 재저장할 필요는 없다.

## 원인과 수정 위치

`BattleNarrationUI.ShowMessage`가 글자마다 `WaitForSecondsRealtime`로 쉬는 동안에는 새 Z를 읽지 않았다. 타이핑 후 유지 시간을 먼저 기다리고 자동 종료 분기에서 다시 기다렸으며, 확인 필수 분기는 확인 후에도 유지 시간의25%를 추가 대기했다. 실제 DialogueCanvas 프리팹의 기본 유지 시간은1초이므로 자동 안내가 본문 표시 후2초를 기다릴 수 있었다.

기존 클래스 안에서 시간 누적형 타이핑과 프레임별 입력 확인으로 교체했다. 프레임이 느려도 경과 시간에 맞춰 여러 글자를 표시한다. 유지 시간은 자동 종료 안내에 한 번만 적용하고, 확인 필수 안내의 전후 고정 대기는 제거했다. 시작 프레임·같은 확인 프레임·공용 입력 소비와 모달 보호를 유지/추가한다. 유지 시간0/즉시 출력 조합도 최소 한 프레임을 표시해 큐가 동기 완료되는 경계를 피한다.

변경 파일은 `Assets/_Game/Scripts/UI/Runtime/BattleNarrationUI.cs`와 기존 `UI/Tests/Editor/BattleHudPresentationTests.cs`다. 파란 주 대화 `DialogueManager/DialogueUI`, 캐릭터 위 짧은 `BattleSpeechBubble`, 전투 계산·판정·시나리오·저장·프리팹은 변경하지 않는다.

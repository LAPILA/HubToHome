# 실행 세션과 병렬 블록

## 이번 작업

- 시퀀스 실행 상태를 에디터가 실시간으로 읽을 수 있는 `ActionExecutionSession` 추가
- 실행 시작, 완료, 실패, 취소, 건너뜀을 Block ID 단위로 기록
- 재생, 일시정지, 재개, 한 블록 실행, 중지, 선택 블록부터 실행 지원
- 다른 시퀀스 호출과 병렬 자식의 부모 블록 관계 보존
- 병렬 블록 완료 규칙 `all`, `any`, `race` 지원

## 병렬 완료 규칙

| 규칙 | 동작 | 사용 예 |
| --- | --- | --- |
| `all` | 활성 자식이 모두 끝나야 완료 | 여러 캐릭터 이동과 화면 전환을 전부 기다림 |
| `any` | 첫 성공이 나오면 완료하고 나머지 취소 | 여러 조건 중 하나의 성공만 필요한 연출 |
| `race` | 가장 먼저 끝난 자식의 성공/실패/취소 결과를 사용 | 시간 제한과 플레이 동작 경쟁 |

기존 병렬 블록은 `policy`가 없으면 `all`로 작동해 호환성이 유지된다.

## 시퀀스 메이커 연결 기준

- 블록 실행 강조와 하단 실행 기록은 `ActionExecutionSession` 이벤트를 그대로 사용
- 에디터가 코루틴 진행 상태를 따로 추측하지 않음
- 선택 블록 재생은 `ActionPlayRequest.StartBlockId`를 사용
- 선택 블록 이전 상태 준비는 다음 단계인 Preparation Run이 담당

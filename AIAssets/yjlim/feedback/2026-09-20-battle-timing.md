# 토끼 슬라임 전투 타이밍 수정 인수인계

## 최종 위치 수정: 중앙 궁극기와 대상 전진

- 토끼 C와 스킬 메이커 C 템플릿은 전투 중앙에서 궁극기를 준비합니다. 다른 아군은 이동하지 않으며 성공한 대상 1명이 접근·패링·공격 후 적과 동시에 원래 자리로 돌아옵니다.
- 기본 적 공격·적 스킬·시나리오 스킬 모두 피격 대상을 아이템처럼 1유닛/0.20초 전진시킵니다. 회피·피격의 복귀 기준도 잠시 그 위치로 옮깁니다. 정상 종료/취소/모듈 종료/비활성화에 원래 기준을 복구합니다. 광역기는 기존 대표 대응자만 전진합니다.
- 아군 기본 공격의 점프 복귀를 일반 이동으로 변경했습니다. 토끼 접근에는 작은 DOTween 상하 이동(일반 0.25 / C 0.45)을 넣었습니다. 기존 스킬은 새 필드 기본값 0이므로 지상 이동을 유지합니다.
- Runtime/Editor 최종 컴파일 오류 0, 기존 ConfigPanelUI 경고 2(최초 의존성 빌드에는 기존 TextAnimator 패키지 경고 1 추가). 이동 데이터/원위치 전달/참조 정적 검사 12건 통과. 회귀 테스트는 추가·컴파일만 했으며 Unity 실행/Refresh/씬 저장은 하지 않았습니다. 아래 108건 검증은 이전 판정 정책 작업의 결과로, 이번 이동 변경의 실제 재생 검증은 아닙니다.

기존 BunnySlimeBattleLab 씬을 그대로 사용합니다. 확인할 항목은 대상 전진 → Z/X 후 전진 위치 유지 → 원위치 복귀, C 중앙 접근/동시 복귀, 아군 기본 공격의 지상 복귀입니다.

## 최신 후속: 투사체·연타 보호·피격 대상 1인 C

사용자 답변으로 C는 공격받은 한 명만 수행하도록 확정했습니다. 적 접근 → 전조 → C 성공 → 해당 아군 접근 → 패링 → 공격 → 양쪽 복귀이며 다른 아군은 움직이지 않습니다. 이 항목이 아래 이전 변경 이력의 반격/판정 숫자를 대체합니다.

- 입력 수집은 유지하되 선택된 대상만 방어 미리보기를 열고, 진행 중인 회피·피격·확정된 대응은 연타로 재시작하지 않도록 수정했습니다.
- 최소 여유는 Z 0.24 / X 0.34 / C 0.28초. 아직 대응이 확정되지 않은 타격만 0.06초 미만의 늦은 입력을 받아줍니다. 실제 피해는 한 번만 확정하며 롤백하지 않습니다.
- Lab에 단발탄, 엇박자 2연발, X 전용탄을 등록했습니다. 종합 전투 및 가드·회피 연습에서 사용합니다. 실험실 재생성은 필요 없습니다.
- 스킬 메이커/실험 메뉴/C 안내 대사도 1인 기준으로 정리했습니다. 스킬·대사 ID와 원본 토끼/아군 스킬/카메라 자산은 유지했습니다.
- 독립 C# 108건 통과, 자산 연결 검사 통과, Runtime/Editor 컴파일 오류 0(기존 ConfigPanelUI 경고 2). C 위치 복구/참가자 제한/샘플 연결 Unity 회귀 테스트는 코드 추가·컴파일만 했습니다. 실제 Unity Play/Edit 테스트는 실행하지 않았습니다.

브랜치 `codex/gameplayEdit`, 커밋·푸시 없음. [현재 사용법](../../../docs/bunny-slime-battle-lab.md), [구현/검증 기록](../../2026-09-20-update.md).

## 이전에 고친 것

- 토끼 모션 시작이 피해보다 0.65~0.85초 늦던 순서를 수정했습니다.
- 위젤 공격·피격·저스트가드의 Animator 진입 지연, 긴 피격 복귀 블렌드를 제거했습니다.
- 공격 중 방어 키가 아군 모션을 덮는 경로와 회피 복귀 지점이 밀리는 경로를 수정했습니다.
- C 반격은 이제 적 앞 도착 → 준비 자세 → 제자리 공격 → 복귀 순서입니다.

씬 재생성이나 수동 참조 연결은 필요 없습니다. 스킬 메이커에서 방어 대응의 **공격 모션 시작 → 타격 시간**을 조절하면 됩니다. 토끼 단타/광역은 0.85초, 연타는 0.65초입니다.

## 최종 적용: 고정 구도·후한 판정·공격자 감속

- 기본 전투 카메라 자동 이동/줌/흔들림을 끄고 기존 Pixel Perfect 32 PPU / 640×480을 보존했습니다. 명시적인 시나리오 연출은 그대로 가능합니다.
- 전열 슬롯은 유지하며 회피 12픽셀, 피격 최대 6픽셀 정도의 수평 이동 후 돌아옵니다. Z는 제자리입니다. 공격 대상은 파티 슬롯으로 강조합니다.
- 실시간 적 대응은 Z 저스트가드 0.20초 / X 회피 0.30초 / C 반격 0.24초를 최소 여유로 사용합니다. 더 후한 자산은 유지하고 짧은 공격은 길이로 제한합니다. 흐린 준비 신호부터 X, 강한 팝/핑부터 정밀 대응을 받습니다.
- 각 키의 성공 구간보다 이른 입력은 나중의 정확한 입력을 막지 않습니다. 실제 입력 이벤트 시각을 사용하며 성공 입력의 재사용은 막습니다. 유지 Z 일반 방어, C 특수공격 전용 규칙은 유지합니다.
- 적만 실제 0.10초 동안 0.5배속으로 감속합니다. 전역 시간·UI·BGM은 그대로입니다. 방어 시계/모션/투사체를 함께 늦추므로 판정만 따로 밀리지 않습니다. 일반적인 타격은 원래보다 0.05초 늦습니다.
- 인접한 `방어 대응 → 투사체`는 비행 중 방어를, `방어 대응 → 연쇄 근접`은 각 대상별 방어를 실행합니다. 스킬 자산은 실행 중 수정하지 않습니다. 일반 전투와 시나리오 호출 모두 연결했습니다.
- 취소/씬 정리/공격자 파괴 시 자신의 방어 실행·전조·감속을 복구합니다. 기본 Telegraph는 SeamlessBattleHost에 연결했습니다.
- 독립 순수 C# 검증: 기존/추가 NUnit 판정 103건 + 입력/시간 조합 55,944건 통과. Unity 런타임/에디터 코드는 별도 컴파일 검증이며 **Unity Play/Edit 테스트는 실행하지 않았습니다**. 카메라/애니메이션/풀링 체감은 실제 플레이 확인이 필요합니다.

아래 회피·전조 항목은 앞선 변경 이력입니다. 판정 숫자와 X 구간은 위 최종 적용 및 [제작 문서](../../../docs/bunny-slime-battle-lab.md)를 우선합니다.

## 앞선 수정 이력: 회피와 전조

- X 회피가 정상 복귀하면 즉시 Idle로 돌아갑니다. 도중에 피격/다른 포즈가 시작됐다면 그 포즈를 덮어쓰지 않습니다.
- 토끼 실험실 8타에 Telegraph 전조를 연결했습니다. 실제 성공 구간이 열리면 작게 나타나 확대·정착·반짝임을 보여주고, 타격/취소 때 제거합니다. 기존의 독립적인 0.3초 표시는 실제 판정보다 빨라 제거했습니다.
- 전조 전 입력은 무시하고 전조 후 새로 누른 첫 입력을 받습니다. 미리 누르고 있던 Z는 일반 방어이며, 전조 후 새 Z는 저스트가드 판정입니다. X도 전조 후 새 입력이 필요합니다. 일반/회피 전용/반격 가능 공격의 기본 표시는 각각 0.12/0.22/0.18초이며 실제 난이도와 판정 설정을 따라갑니다.
- **음원은 미정이라 무음입니다.** 이후 Telegraph 프리팹의 `BattleTelegraphCue > Ping Clip`에 음원 하나만 지정하면 연결된 공격에서 재생합니다.
- 표시 시간은 실제 판정에서 자동 계산하고, 모양은 Telegraph 프리팹에서 바꿉니다. 새 스킬은 방어 대응 `타격 직전 전조 프리팹`을 연결합니다. 기존 저장값 `ImpactCueLeadTime`은 호환용으로만 남아 무시됩니다.
- 컴파일/정적 연결 검사 통과. 실제 Play 검증은 하지 않았습니다. [자세한 사용법](../../../docs/bunny-slime-battle-lab.md).

## 아직 답이 필요한 것 (아군 QTE)

아군 QTE의 입력이 늦더라도 공격은 계속 진행하고 **타격 순간까지의 결과만 반영**할지 결정이 필요합니다. 현재는 결과를 기다리는 기존 경로를 유지했습니다. 따라서 아군 스킬 타격 지연까지 모두 해결한 상태는 아닙니다.

## 확인 범위

런타임/에디터 컴파일 오류 0, 자산 시간값 정적 검사 통과. Unity 플레이는 실행하지 않았습니다. 사용자가 확인할 순서는 **토끼 단타 → 3연타 → Z 저스트가드 → X 회피 → C 반격**입니다.

변경 파일·위험 범위·빌드 절차·작업 환경 교훈은 [당일 작업 기록](../../2026-09-20-update.md)에 있습니다. 현재 브랜치는 `codex/gameplayEdit`이며 커밋·푸시는 하지 않았습니다.

# 전투 하단 메인 대화

2026-10-16 후속 시안 반영: 중앙 명령+상세 전체를 대화로 교체하며 파티·자원·턴 큐는 유지합니다.

전투 중 캐릭터끼리 나누는 메인 대화는 **ATTACK/SKILL/ITEM/RUN + 스킬·아이템 목록·설명창을 합친 중앙 영역**에 표시합니다. 화면 전체의 중앙이 아니라, 하단 HUD에서 파티와 오른쪽 자원 사이입니다. 머리 위 짧은 말풍선은 수정하지 않았습니다.

## 동작

| 상황 | 화면·입력 |
|---|---|
| 메인 대화 시작 | 명령/상세 두 패널이 0.3초 동안 아래로 이동·페이드아웃. 이동 전 합집합 위치에 기존 파란 대사창을 0.1초 페이드인 |
| 대화 중 | 파티/턴 큐/오른쪽 자원/하단 배경 유지. 중앙 명령·상세는 보이지 않으며 입력 차단 |
| Z | 타이핑 완료 → 긴 본문의 다음 페이지 → 다음 대사 |
| 선택지가 있을 때 | 방향키로 선택, Z로 확정. 선택지는 표시 공간에 맞춰 스크롤 |
| 대화 종료 | 중앙 메뉴가 원래 위치로 복귀. 선택 위치·원래 대사창 배치 복원. 시나리오가 메뉴를 소유 중이면 gate 해제 후 복귀 |
| 외부 전투 종료·모듈 변경 | 이전 메뉴 상태를 강제로 복원하지 않음. 사라진 표시 대상의 대화는 취소 |

X는 기존 선형 대화 스킵을 사용하며 선택지·이름 입력에서는 멈춥니다. 기존 전투 입력·턴·HP/AP·후열 승계 규칙은 바꾸지 않았습니다. 파란 배경과 레터박스 앞 표시 순서도 유지합니다. 대화 뒤에도 계속되는 시나리오 연출은 기존 소유권을 따릅니다.

## 대사 만들기

1. **Hub To Home → 제작 → 콘텐츠 메이커 → 대사 · 화자**를 엽니다.
2. 화자·표정에서 SpeakerData의 이름과 표정별 이미지를 연결합니다. 초상이 없는 화자는 본문 영역을 더 넓게 사용합니다.
3. 대사에서 DialogueData를 만들고 각 노드의 화자, 표정, 기본 문장, 번역 키를 작성합니다. 기존 분기·선택지도 사용할 수 있습니다.
4. 기존 시퀀스 메이커에서 해당 BattleScenarioData의 대화 매핑에 대사 ID와 DialogueData를 연결합니다.
5. 전투 시작 / 행동 종료 후 / 전투 결과 처리 전 시퀀스에 기존 **dialogue.wait**를 넣습니다. 이 액션이 닫기 연출까지 기다렸다가 다음 작업을 진행합니다.

이 표시 변경에는 새 대사 관리자나 새 프리팹을 추가할 필요가 없습니다. 전투 중에는 기존 Overworld/Cinematic 스타일 대사도 초상 지원 패널을 통해 하단에 표시합니다. 전투 밖에서는 원래 스타일·배치로 돌아갑니다.

주의: 공격 도중 임의로 StartDialogue를 호출해서 공격 코루틴까지 멈추는 기능은 아닙니다. 메인 대화는 기존 시나리오의 안전한 지점, 특히 **after_current_action**에 넣으세요. 짧은 공격 대사는 기존 BattleSpeechRule을 그대로 사용합니다. 본문/화자/선택지의 기존 번역 키를 사용하며 이번 표시 변경에는 시나리오 문법이나 대본 변경이 없습니다.

**OverworldPanel → DialogueUI → 전투 하단 대화**에서 조절합니다.

| Odin 항목 | 기본값 | 용도 |
|---|---:|---|
| 안쪽 여백 | 8 | 배경과 본문 사이 간격 |
| 초상 크기 | 64 | 화자 표정 이미지 크기. 원본 종횡비 유지 |
| 본문 크기 | 14 | 640×480 기준 글자 크기 |
| 화자 이름 크기 | 14 | 이름 글자 크기 |
| 선택지 행 높이 | 18 | 선택지 간격. 최대 3행, 실제 공간에 따라 감소 |

표시 위치는 BattleMenuUI에 이미 연결된 **명령 메뉴와 BattleSubMenu의 이동 전 합집합**입니다. 공용 프리팹의 기준640×480 좌하단 기준 x177..539/y24..154, 크기362×130입니다. 메뉴 이동 중에는 이 영역이 고정되고 화면 배율 변환만 반영합니다. 전역 대화 Canvas를 유지하므로 대사창을 메뉴 아래로 직접 재배치하지 마세요.

전환은 **BattleMenu → BattleMenuUI → 대화 전환**에서 `전환 시간(초)=0.3`, `아래 이동 거리=164`를 조절합니다. 기본164는 메뉴 상단154가 화면 밑으로 완전히 내려가는 값입니다. 파티/자원을 포함한 HudDecoration은 이동 대상이 아닙니다. 새 Inspector 참조나 프리팹 재연결은 필요 없습니다.

## 2026-10-16 후속 · 입력 정지와 하단 가림

- 스킬/아이템 확정은 먼저 재입력을 잠근 뒤 기존 대상 선택으로 전달합니다. 확정 콜백에서 `CommandsEnabled`를 다시 검사하면 자체 입력 잠금 때문에 요청을 버립니다. 입력 수신 가능 여부와 이미 수락한 요청의 전달 가능 여부를 분리하고 대화/전환/모듈 정지/전역 모달 차단은 유지했습니다.
- 4:3보다 세로가 긴 출력에서 중앙 정렬된 640×480 HUD 아래 남는 띠는 검정 배경으로 채웁니다. HUD 좌표, 크기, 카메라 크롭 설정은 옮기지 않습니다.
- 도킹 대화 중 하단 레터박스만 HUD 아래 여백 + 기준20px까지 제한합니다. 안내 줄(y2..18)은 가리되 세 번째 파티 행(y24..66)은 보존합니다. 상단 레터박스와 일반 컷씬의 원래 두께는 유지합니다. 대본의 thickness 값은 바꾸지 않습니다.
- 레터박스 표시 애니메이션이 끝난 뒤 대화가 시작되어도, 또는 해상도가 바뀌어도 표시 높이를 다시 반영합니다.

추가 확인: 스킬/아이템 선택 → 대상 변경 → X 취소 → 다른 항목 선택, 대화 종료 후 입력 재개, 화면이 세로로 긴 Game View에서 하단 맵 띠가 없는지 확인합니다. Unity 자동 실행은 하지 않습니다.

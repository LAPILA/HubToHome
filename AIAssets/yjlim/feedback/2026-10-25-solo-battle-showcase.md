# 위젤1인 · 토끼/제브 연출 실험실

브랜치 `gameplayEdit` · 커밋/푸시 없음 · [실행·재사용 순서](../../../docs/bunny-slime-battle-lab.md)

## 변경 결과

- Play 직후부터 흰 기본 외형의 위젤1명이다. 토끼 통합/제브 연출 두 입구 모두1대1이다.
- 동료 미리보기와 후열 실습 입구를 제거했다. 미리보기 C#/meta 두 추적 파일은 Git으로 복구 가능하다. 기존 동료·원소·후열 샘플 데이터와 본편3+3 기능은 삭제하지 않았다.
- 위젤10스킬·제브5스킬은 Lab 전용 사본이며, 본편 원본 DB/스킬/Scene/Prefab은 보존했다. 현재 세션만 임시 파티를 만들고 실제 저장 파일은 읽거나 기록하지 않는다.

| 위젤 | 제브 |
| --- | --- |
| 압력 베기 · 쌍압 절단 · 증기 찌르기 · 역류 참격 | 빙섬 · 잔뢰 이연 |
| 터빈 연격: 약5초의 고속 연격 | 뇌광 순회: 단독 대상3연쇄 |
| 증기 횡단: 공중 교차 / 과열 강하: 급강하 | 동결 낙인: 회피 대응 내려찍기 |
| 보일러 파열: 증기 투사체 | 극성 단죄: 중앙 특수공격·X/C 대응 |
| 임계압 돌파 · 압력 해방: 사선 분할 결정타 | 모든 제브 스킬은 근접이며 적 QTE/원거리는 없음 |

원본보다 냉기/감전 부담을 낮춘 제브 Lab 사본을 사용한다. 피해·저항·방어의 공용 계산은 그대로이며, 압력 강화와 실시간 아군 QTE도 기존 경로다. 원본 이미지/애니메이션을 재사용하므로 최종 아트 완성을 의미하지 않는다.

## 다른 스킬에서도 사용하는 방법

- 스킬 자산: `Content/Skills/Ally/BattleLab/Showcase`, `Content/Skills/Enemy/BattleLab/ZEV`.
- 스킬 메이커에서 **컷인 · 실루엣 강조**를 추가한다. `Action_PresentationAccent`의 종류/시간/강도/색/그림/효과음/슬라이드 거리를 바꾼다.
- 준비 앞이나 피해 뒤에 배치한다. **적 방어 대응과 피해 소비 사이에는 넣지 않는다.** 검사기가 잘못된 순서를 지적한다.
- 큰 그림은 비정수 축소하지 않고 안전 영역에서 잘린다. 원본 높이236px 이하를 권장한다. 고유 자원 아이콘이 아니라 기본 초상/현재 배우 스프라이트를 기본 그림으로 쓴다.
- 새 SkillID는 카탈로그에 등록하고 실험실 front/ZEV_Lab 목록에 연결한다. 실행 중 모드 번호나 캐릭터 이름으로 스킬을 덮어쓰는 구조가 아니다.

공용 표시 서비스는 HUD/QTE 뒤의 정수640×480 안에서 전투 영역만 사용한다. Canvas/그림/재질을 재사용하고 숨기면 viewport·마스크도 휴면 처리한다. 추가 카메라/RenderTexture/상시 블러는 없다. 엄격 Pixel Perfect의 고정 렌즈와 Dutch0은 유지하며 카메라 회전을 몰래 복구하지 않았다. 이동 잔상은 이동 중에만 나온다.

## 검증과 남은 확인

- 전체 C# CLI Runtime466/Editor384소스 오류0/0, 기존 경고226/0.
- 실제 Session 메서드10사례25단언:1명 구성/검증/복원, 동일 ID의 외부 파티 교체도 보존.
- 실제15자산의 독립 검사1,780단언, 관리형 YAML 파서 기반760단언:15고유ID/143RID/66GUID참조/카탈로그/DB/실제 필드/방어-피해 순서/전조Center/단독 연쇄/ResourceEffect/두 Source와 Runtime 해시.
- 공용 연출의 실제 수학/설정14,561단언과 셰이더 소스/휴면 계약 검사. 토큰·취소·장면/모듈 수명은 독립 소스 검토도 수행했다.
- 새 번역30키·120문구, 새 meta GUID 유일성·UTF-8·diff 확인. 보호한 원본20파일 해시 일치. 삭제한 미리보기 script GUID를 참조하는 Scene/Prefab/자산0개.

관리형 검사에서는 Unity/TMP/배우 저장소 등 엔진 경계를 대역으로 둔다. **Unity Play·실제 셰이더 GPU 컴파일·애니메이션 박자·긴 번역의 줄바꿈·실기기 발열/프레임은 미검증**이다. 강제 Refresh/전체 생성기/실제 저장 I/O도 실행하지 않았다. 실제 화면은 새로 Play해15개 스킬의 순서와 초상 교체를 확인해야 한다.

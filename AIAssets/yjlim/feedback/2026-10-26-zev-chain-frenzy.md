# 제브 · 사슬 광란

브랜치 `gameplayEdit` · 커밋/푸시 없음 · 실험실 전용

현재는 [전체 적 공격 기본 정책](2026-10-26-global-enemy-attack-flow.md)이 우선합니다. 이 문서의 선택적 연속 토글/별도 C 준비 대기는 과거 구현 기록입니다. 이제 일반·투사체·연쇄·C/광역 모두 공격 진행 중 대응하며 제브 단계 속도는 그대로 유지합니다.

## 최신 변경 — 끊김 없는 연속 이동

Lab의 연속 공격 블록에서 **끊김 없는 연속 이동(ContinuousMotion)**을 켰습니다. 최초 준비는 한 번만 하고,20타 사이의 준비 자세·방어창 앞 정지·공격자 감속·접점 정지·피격/회피 완료 대기는 반복하지 않습니다. 판정 시각은 실제 이동 접점에서 계산하며, 늦은 입력 유예0.06초에도 제브가 계속 관통합니다. 유예 중의 위치를 결과 시점에 접점으로 되감지 않습니다.

일반 공격은 기존 모드 그대로입니다. 난무는 고정된 방어 배치를 목표로 사용해 진행 중인 회피 좌표를 쫓지 않습니다. 매타 전조/피해1회·방어 감소·저스트 보상·입력 유예·재준비 규칙은 유지하며, 방어자의 반응 완료/정리는 난무 끝으로 미룹니다. 마지막 C검격은 별도 준비/전조를 유지합니다. 관통 뒤 이동은 입력 유예와 프레임 여유보다 짧아지지 않게 보정하므로 아래 관통 값이 최종 전체 타격 간격과 동일하지는 않습니다.

## 바로 확인하기

새 Play로 **Hub To Home → 테스트 → 전투 실험실 열기 → ZEV**를 시작합니다. 제브HP를50%아래로 내려 사슬2페이즈에 진입하면 다음 순서로 진행합니다.

```text
2페이즈 진입 → 제브 일반 공격1회 완료 → 다음 제브 행동: 사슬 광란1회
→ 가속 왕복10회 → 공중2회 → 무작위 지상·공중8타 → C 전용 대검격
→ 다음 제브 자기 차례1회 탈진 → 기존5종 순환으로 복귀
```

혼합8타의 이동 종류는 타격마다 무작위입니다. 이동 시간은 시작값에서 끝값으로 보간되며, 기존 매 타격 전조와 Z/X 대응을 사용합니다. 광란의 일반 타격은 가드 성공 뒤에도 제브가 끝까지 관통하지만 피해 감소·저스트 AP/압력 보상은 그대로입니다. 최종 공격은 **C만 가능**하며 기존 일반 특수공격의 X/C 규칙은 바뀌지 않습니다. C성공으로 마지막 공격이 끊겨도 탈진1턴은 적용합니다. 중간 취소/도주/사망은 정상 완료로 기록하지 않습니다.

횟수가 최초 제안보다 늘어 총 연출은10초로 강제하지 않습니다. 실제 길이는 방어/이동·리액션 시간에 따릅니다. 새 플레이어 QTE나 상시 카메라 회전/배율 변경은 없습니다.

## 수정 위치

### 가속 조정값 — 후속 수정

| 단계 | 타수 | 관통 기준 시간 | 일반 모드 판정 대기 | 일반 모드 준비 자세 |
| --- | --- | --- | --- | --- |
| 지상 왕복 | 10 | 0.60 → 0.34초 | 0.65 → 0.30초 | 0.08 → 0.025초 |
| 공중 강하 | 2 | 0.34 → 0.30초 | 0.30 → 0.28초 | 0.025 → 0.02초 |
| 혼합 난무 | 8 | 0.30 → 0.24초 | 0.28 → 0.20초 | 0.02 → 0.01초 |

관통 시간이 줄수록 접근 이동은 빨라집니다. 최신 사용자 피드백으로 마지막 기준을0.08초에서0.24초로 늦춰 처음/마지막 접근 속도 비율은2.5배입니다. 공중 단계에서도 속도를 되돌리지 않습니다. 현재 Lab 연속 모드는 실제 접점에서 판정하므로 표의 일반 모드 판정/준비 대기는 사용하지 않습니다. 일반 모드의 준비 시간을0으로 두면 기존 호환 규칙이0.08초로 복원하므로 짧은 양수로 조정합니다. 공중 진입 시간은 상승 연출을 위해 따로 둡니다. [최신 UI/오류/반응 속도 수정](2026-10-26-battle-feedback-polish.md).

기존에는 가속 폭이1.67배였고 공중 시작에 다시 느려졌습니다. 또한 화면 구도 확보 실패 시 고정 속도의 Local 경로를 사용했습니다. 이제 Local에도 가속을 전달하고, 최종0.08초가 부동소수점 보간 오차로 최소값 아래로 내려가 Local로 바뀌지 않게 끝점을 보존합니다. 일반 적 스킬의 기본값·전조/방어 성공창·타격 후 반응 대기는 변경하지 않았습니다.

## 코드 구조

- `EnemyFollowupSkillPattern`/`BattleEnemyActionPatternState`: 행동 시작의 플래그를 캡처하고 정상 완료에만 횟수·사용 여부를 반영합니다. 준비된 후속 스킬은 다음 자기 행동에서 우선 선택하며 기존 순환 index를 추가 소비하지 않습니다.2페이즈를 유발한 이전 행동은 소급해 세지 않습니다. 중단된 선택만 취소하고, 모듈 전환 중 완료 사실/휴식 턴은 전투 안에서 유지합니다. 전투 폐기 시 정리하며 저장하지 않습니다.
- `BattleTurnQteModuleControllerService`: 기존 적 완료 callback에 연결해 정상 완료/C반격 완료에만 후속 소비·회복 턴을 확정합니다. 다음 자기 차례에서 회복 카운터를 한 번 소비하고 ‘탈진으로 한 턴 휴식’을 표시합니다. 기절/빙결/저항/CC면역을 사용하지 않습니다. `SkillData.RecoveryTurns`는 이 적 정상 행동 경로에 적용되며 Scenario의 직접 timeline 호출까지 확장하지 않았습니다.
- `Action_EnemyAssaultCombo`: 단계 목록과 보간을 소유합니다. 기존 DefenseWindow/Damage를 매번1회씩 호출하므로 별도 피해를 더하지 않습니다. 근접 scope는 공중 Entry만 올리고 공유 방어 시계의 Contact에서 착지합니다. 가드 통과/공중 높이의 기존 기본값은 false/0이라 다른 스킬의 접점 정지·지상 이동은 유지합니다. 이동에만 잔상, HUD와 고정 PP Lens는 유지합니다.
- `DefenseRequirement.CounterOnly=7`: 기존0~6의 의미/숫자를 보존한 추가값입니다. 판정·성공 결과·전조 핑·저작 안내가 같은 helper를 사용합니다. C전용에서 X성공창0과C창의최솟값을 취해 전조가0이 되는 오류도 방지했습니다. 잘못 누른 X가 뒤의 올바른 C를 막지 않습니다.
- `BattleSkillVfxLifetime`: 공격 애니메이션 시작에 검격을 재생해 C성공에도 빠지지 않습니다. 세대 토큰으로 AutoDespawn 뒤 재사용된 객체를 옛 lease가 반환하지 못하게 합니다. 정상 수명/취소/씬·모듈 종료/일시정지/반복 scale을 처리합니다. 지정 Zev프리팹의 자식PS Destroy stopAction1개만 None으로 바꿔 풀 재사용 시 자식 삭제를 막았습니다.

전투 전체 페이즈 전환은 기존 Scenario의 `lab.zev.chain_phase`가 계속 소유합니다. 새 AI 패턴은 이 상태에 반응할 뿐 HP·대사·씬을 판단하지 않습니다. Source/Runtime hash와 ActionLibrary 문법은 변경하지 않았으며, 별도 enemy skill.completed 이벤트 확장에도 의존하지 않습니다.

## 검증과 한계

연속 모드 후속 검증: 실제 생산 경로·루틴 관리형38사례210단언+QTE옵션 연결 소스계약4개 통과. 기본 모드3타 Ready3회/반응대기3회를 재현했고, 연속 모드는 Ready0회/반응대기1회·실제 접점 시계·늦은 유예 중 위치 진행·결과 시 되감기 없음·잔여 관통·0거리 진입·고정 배치·일시정지/취소·지연 플래그 복원·기존 C경로를 확인했습니다. Lab데이터223단언, 기존 방어/QTE144사례·패링 재준비479+8계약 통과. QTE 입력 스케줄러와 DOTween은 대역이며 실제 Unity 화면의 연속감은 아직 미검증입니다.

가속 후속 검증: 관리형 이동29사례158단언(실제 공유 시계의 첫·중·마지막 이동 속도, 프레이밍 없는 Local 가속 포함), 실제 Lab데이터222단언(20타 전체 관통/판정/준비 시간 비증가·관통7배 이상), 전체 스킬799단언·방어/QTE144사례·패링 재준비479+8계약 통과. 전체CLI Runtime482/Editor389 오류0/0. 아래 수치는 최초 구현 시점 기록이며, 실제 렌더·입력 체감은 여전히 Unity에서 확인해야 합니다.

전체CLI Runtime482/Editor389소스 오류0/0. 실제 생산 코드 기반 관리형 검사: 이동/방어/피해27사례143단언(실제20회 루프·20방어·20피해 이벤트 포함), 후속 상태11,068단언+12소스계약, VFX8사례1,023단언+3계약, 방어·아군 QTE144사례 통과. 기존 Z재준비479+8계약도 통과했습니다.

데이터160단언에서10/2/8/최종C·회복1·후속 연결·참조와 보호 원본11파일SHA256 동일을 확인했습니다.16Lab스킬122블록/RID·참조58개·128스킬번역은799/1,761단언, 전투 기록31키124번역은467단언 통과. 기존CSV접두50,258바이트/BOM을 보존하고 신규3키12번역만 추가했습니다. 기존 사슬50%6단계/SourceHash 검사178단언 통과, 메타1,739개32hex유일성을 확인했습니다.

관리형 검사는 Unity/TMP/Animator/DOTween/입력/풀·PS 경계에 대역을 사용합니다. **Unity Play/실제 렌더·착지 체감·입력 박자·파티클·음향·실기 성능은 미검증**입니다. Native NUnit/Refresh/씬 저장/실제 저장I/O도 실행하지 않았습니다. 실제 Game View에서 신규 스킬과VFX를 확인해야 합니다. 원본 적5스킬·본편DB·기존Scene/Prefab은 보존했으며 예외는 사용자가 지정한 검격VFX의 stopAction1필드입니다.

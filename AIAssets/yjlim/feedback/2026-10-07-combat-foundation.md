# 전투 기본 흐름 · 무엇이 바뀌었는가

전조·후열 선택·장비 계산·저장 경계를 정리했습니다. 기존 전투 규칙과 콘텐츠를 교체하지 않았고, 게임 전체의 완성이나 모든 버그 제거를 의미하지는 않습니다.

## 전조

기본 흐름은 **대상 표시 → 준비 자세 → 타격 신호/공격 모션 → 접촉/판정**입니다. 신호가 보이면 그 공격에 허용된 키의 성공 구간입니다. 원거리·특수공격의 흐린 선행 신호를 제거했지만 X의 넓은 판정 자체는 줄이지 않았습니다. 카메라 안정화/공격 국소 감속도 기존 유지입니다.

| 입력 | 유지한 규칙 |
| --- | --- |
| Z 유지 | 일반 방어, 기본 피해0.5배 |
| 새 Z | 근접 최소0.40초, 그 외 최소0.24초 보정. 저스트 성공 시 기존 AP/자원 보상 |
| X | 최소0.34초, Z보다 좁지 않음. 피해 회피/별도 보상 없음 |
| C | 반격 가능 공격에서만, 최소0.28초. 기존 반격/자원 처리 유지 |

구간은 전체 공격 길이를 넘지 않습니다. 새 입력의 늦은 유예0.06초, 잘못 선입력한 뒤 다시 시도 가능, 한 입력으로 다음 타격까지 막지 않는 규칙을 유지합니다. 시각적5연타를 반드시5번 입력으로 바꾸지는 않았습니다. 리듬 선행 예고 기능은 추가하지 않았습니다.

편집: QTEManager의 `기본 판정 구간`/`Z / X / C 방어`, 스킬 메이커의 방어 블록. 새 블록은 추가 예고를 끄고 `타격 직전 전조 프리팹`을 지정하세요. `공격 시작 → 타격 시간`은 실제 클립 타격 위치에 맞춥니다. 기존 개별 자산은 일괄 재작성하지 않았습니다.

## 전멸 후 선택

살아 있는 후열이 있을 때만 `계속 싸우기 / 포기하기`가 나옵니다. 기본은 계속 싸우기이며 취소는 선택만 되돌립니다. 기존 UI 입력을 사용하고 마우스 클릭은 없습니다.

- 계속: 전열0.5초 페이드 → 후열 왼쪽 화면 밖 진입 → Idle → 턴 재개.
- 포기: 후열을 투입하지 않고 게임오버. 실험실도 포기를 선택하면 연습 메뉴가 뒤에서 다시 열리지 않습니다.
- 중단/씬 이탈: 선택창, 방어 입력 잠금, 움직임과 투명도 정리.

별도 프리팹/씬 연결은 없습니다. 호스트에 선택 UI가 최초1회 생성되고 재사용됩니다.

## 장비·저항 입력법

장비 Inspector는 `기본 정보 → 장착 제한 → 능력치 보정`입니다. 스탯 이름과 저장 필드는 유지했습니다.

| 입력 장소 | 값의 의미 | 예 |
| --- | --- | --- |
| 캐릭터 기본 속성 피해 배율 | 최종 계산의 시작값 | 1=정상,0.5=절반,0=면역,1.5=약점 |
| 장비 StatBonuses | 기본값에 더할 값 | 화염 -0.25 → 기본1에서0.75배 |
| 상태 적용 배율 | 누적량 또는 기존 효과 부여 확률에 적용 | 누적 상태0.5 → 누적량 절반 |
| 장비의 상태 배율 보정 | 상태 기본값에 더할 값 | -1 → 기본1에서0, 면역 |

장비 보정에 실수로 `1`을 넣으면 기본1에 더해2가 됩니다. 슬롯이 틀리거나 캐릭터 제한을 위반한 장비는 미리보기/전투 모두 적용하지 않습니다. 장비 변경 후 씬을 옮겨도 프리팹 초기 장비로 덮지 않습니다.

예약 상태인 패시브 ID/장착 반응 대사 ID는 입력만으로 실행되지 않습니다. 이번 범위에서 새 패시브/대사 시스템은 만들지 않았습니다.

## 저장

전투·후열 선택·저장 복구 중에는 저장을 막습니다. 실패하면 저장 지점의 성공 효과와 자동 저장 완료 표시를 남기지 않습니다. 저장 좌표가 NaN/Infinity인 파일은 손상 후보로 판단해 기존 정상 백업 복구를 이용합니다. 저장 형식은 v4 그대로입니다.

## 사용자가 확인할 것

1. 토끼/ZEV 근접: 신호 시작에 새 Z → 저스트 판정. 너무 이른 입력 후 신호 안 재입력도 확인.
2. 원거리/C: 패링 불가한 흐린 신호가 먼저 안 나오는지, 기존 X/C 범위가 유지되는지.
3. 3+3 후열 실습: 선택창 전 후열 미활성 → 계속/포기 각각. 창 도중 F8/호스트 중단 후 재진입.
4. 장비 장착/해제 → 씬 재진입 → 능력치/HP·AP 상한 일치. 화염 피해/상태 누적 저항을 각각 확인.
5. 일반 저장/재시도, 전투 중 저장 차단. 기존 실제 저장 파일을 훼손하는 시험은 하지 마세요.

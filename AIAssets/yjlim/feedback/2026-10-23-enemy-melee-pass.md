# 적 참격: 준비 정지 → 베고 통과 → 복귀

## 적용한 곳

제브의 두 기존 스킬만 선택 적용했다.

| 스킬 | 데이터 | 기존 판정 창 |
| --- | --- | --- |
| 빙섬 | `Content/Skills/Enemy/ZEV/Skill_BlinkSlash.asset` | 0.40초 유지 |
| 개별 연쇄 참격 | `Content/Skills/Enemy/ZEV/Skill_ComboSlash.asset` | 대상별 0.42초 유지 |

실험실 제브 전투와 같은 SkillData를 쓰는 본편에 함께 반영된다. 토끼의 점프·찍기, 일반 제자리 공격, 투사체, 직접 광역, C 특수공격에는 자동 적용하지 않았다. 다른 적에게는 아래 옵션으로 선택 적용한다.

## 화면 흐름

1. 기존 접근·Windup 후 적 쪽에 무게를 둔 구도로 짧게 정리한다.
2. 공격 준비 자세를 유지한다. Windup이 이미 Ready를 표시했어도 모션을 재시작하지 않고, 카메라 진입을 끝낼 준비 시간만 보장한다(기본 최소 0.08초).
3. 기존 전조·입력 시계의 마지막 0.12초에 빠르게 접근한다. 기존 국소 감속도 같은 시계로 적용된다.
4. 무기가 닿는 위치에서 기존 방어 결과와 피해/VFX를 소비한다. 늦은 입력 유예 동안은 접촉 위치를 유지하며 피해를 먼저 주고 되돌리는 방식은 쓰지 않는다.
5. 실패·회피이면 아군 뒤 0.95 거리까지 0.09초에 통과한다. 가드·저스트가드는 접촉 지점에서 멈춘다. C는 기존 반격 연출을 그대로 쓴다.
6. 기존 전투 루트가 적과 방어자를 원래 자리로 복귀시킨다.

카메라는 준비 시 적 비중 68%, 진입 0.06초다. 실제 방어 구간은 고정한다. 결과 시 돌파 방향으로 0.35 이동/4% 줌을 0.06초 진입 → 0.04초 유지 → 0.13초 복귀로 낸다. 기본 HUD는 움직이지 않고, 전용 범위 동안 기존 일반 명중 컷을 중복 실행하지 않는다.

## 직접 조정하기

스킬 메이커 또는 SkillData Inspector에서 **방어 대응 → 근접 돌파 연출**:

| 항목 | 기본값 | 의미 |
| --- | --- | --- |
| 타격 후 아군 뒤로 돌파 | 꺼짐 | 해당 방어 블록만 선택 적용 |
| 타격 직전 대시 시간 | 0.12초 | 기존 판정 창 끝부분에서 이동 |
| 대상 뒤 통과 거리 | 0.95 | 처음 포착한 목표점 기준 거리 |
| 타격 후 통과 시간 | 0.09초 | 기존 피해 소비 후 이동 시간 |

공격 클립의 타격 프레임에 맞춰 **공격 시작 → 타격 시간**도 조정한다. 샘플은 0.12초다. 판정 창이나 피해량을 함께 바꿀 필요는 없다.

블록은 **접근/준비 → 방어 대응 → VFX/피해** 또는 **방어 대응 → 연쇄 근접**을 유지한다. 방어와 피해 사이에 별도의 이동/대기 블록을 끼우지 않는다. 연쇄 근접은 기존처럼 대상별 방어 결과를 각각 계산한다. C/투사체/직접 다중 대상에는 옵션이 켜져 있어도 적용하지 않는다.

카메라 리그의 CameraController **적 근접 · 추적 준비와 돌파 컷**에서 사용 여부·진입 시간·적 비중·이동 거리·줌을 조정한다. 카메라 진입 시간을 늘리면 그 시간만큼 판정창 전 준비 대기도 보장한다. 화면 흔들림 설정 0/기존 명중 컷 끄기/정적 카메라 모드에서는 전용 카메라도 생략한다. 이동 연출 옵션은 독립적이다.

## 구조·중단 처리

- `BattleEnemyMeleeDashPath`: 목표 스냅샷과 authored time을 접촉/통과 경로로 변환한다. 회피하는 아군을 쫓지 않고 원래 높이·깊이를 유지한다.
- `BattleEnemyMeleePresentationScope`: DOTween 두 개를 각 단계에 생성해 수동 진행한다. 접근은 QTE 시계, 후속 이동은 기존 피해 후 대기 경로만 사용한다. 전역 timeScale이나 새 MonoBehaviour Update는 없다.
- `SkillContext.EnemyMeleePresentation`: 스킬 실행 하나가 범위를 소유한다. 새 범위 전 이전 범위를 정리한다. 실제 피해 블록은 변경하지 않고 기존 `WaitForPendingDefenseReaction`에서 후속 이동을 소비한다.
- 취소는 자기 Tween·잔상만 종료하고 현재 범위일 때 준비 위치를 복구한다. 연쇄 근접 취소는 이 범위를 먼저 해제한 뒤 블록 진입 위치를 복구하여 복구 순서 충돌을 막는다. 이미 파괴/사망한 공격자나 더 새 범위를 건드리지 않는다.
- 카메라는 기존 명령 토큰을 따른다. 방어 고정/새 명령/Timeline/C 반격/모달/씬 종료가 우선한다. 막힌 타격 컷을 나중에 재생하지 않는다.
- 저장 형식·HP/AP·피해/속성·타깃 추첨·전조·QTE 보상은 변경하지 않았다. 새 GPU 패스/RT/화면 캡처도 없다.

## 검증

- 전체 CLI: Runtime 444 / Editor 368 소스, 오류 0, 경고 225 / 0(기존 수준).
- 실제 경로 코드를 링크한 관리형 검사 871건 통과. 스킬 데이터 41건 검사 및 다른 적 방어 블록 23개 기본 해제 확인.
- 기존 피격 수명 201, HP/상태 16,398, 명중음 236 관리형 단언 재통과.
- 새 Editor 회귀 소스는 컴파일만 했다. 경로/소유권·가드/파괴/교체와 카메라 우선권 검사는 Unity에서 실행하지 않았다.
- Unity Play/Refresh/Reimport/열린 씬 저장, 실제 저장 파일 쓰기, 커밋/푸시는 하지 않았다. 픽셀 화면·애니메이션 타격 프레임·기기 성능·체감은 엔진 확인 전 미검증이다.

# Sequence Maker 전면 개편 설계

## 결론

현재 Sequence Maker는 안전한 YAML 동기화와 기본 액션 편집을 검증한 1차 도구다. 다음 단계에서는 기존 창에 버튼을 추가하는 방식이 아니라, 일반인이 실제로 시퀀스를 제작하고 테스트할 수 있는 공식 작업공간으로 재구성한다.

## 확정된 사용 흐름

- AI는 읽기 쉬운 YAML로 시퀀스와 라이브러리를 만든다.
- 사람은 Unity Sequence Maker에서 Runtime Asset을 블록으로 직접 다듬는다.
- 변경은 Runtime Asset에 즉시 보이고, `저장` 또는 `Ctrl+S` 때 검증된 YAML로 반영된다.
- 외부 YAML과 사람의 미저장 수정이 충돌하면 자동 덮어쓰지 않는다.
- Action Library와 Trigger Library도 카테고리별 YAML을 원본으로 사용한다.

## 화면

- 상단: 현재 대상, 저장 상태, 검증, 안전 미리보기, 실제 실행, 재생 제어
- 왼쪽: 전투 흐름과 일반 시퀀스 통합 탐색, 검색, 최근 작업, 사용 위치
- 가운데: 위에서 아래로 읽는 블록 흐름
- 오른쪽: 선택한 블록의 설명과 전체 파라미터
- 하단: 문제, 실행 로그, YAML, 고급 진단

## 블록 편집

- 블록에는 액션 이름, 자연어 요약, 핵심값, 오류, 미리보기 상태를 표시한다.
- 전체 값은 오른쪽 설정에서 자료형에 맞는 입력기로 편집한다.
- 순서 변경, 정확한 위치 삽입, 다중 선택, 복사, 복제, 비활성, 삭제, Undo/Redo를 지원한다.
- 병렬, 조건, 선택, 다른 시퀀스 호출은 중첩 블록으로 표현한다.
- 모든 블록은 순서를 바꿔도 유지되는 고유 Block ID를 가진다.

## 재생

- `안전 미리보기`와 `Play Mode 실제 실행`을 분리한다.
- 선택 블록부터 재생하면 앞 블록을 준비 실행해 필요한 상태를 빠르게 만든다.
- 이동, 카메라, 페이드는 최종 상태를 즉시 적용하고 대기와 일반 대사는 건너뛴다.
- 선택지 대사는 기본 미리보기 값이 없으면 멈춰 직접 선택하게 한다.
- 저장, 보상, 씬 이동은 안전 미리보기에서 실제 상태를 바꾸지 않는다.

## 유연한 조건과 재사용

- 고정 `BattleEventType` 대신 Event ID와 Condition 블록으로 `when`을 구성한다.
- 첫 만남, HP 변화, 모듈 결과, 플래그, 저장 기억 등을 조합할 수 있다.
- 시퀀스는 타입이 있는 입력값을 받아 여러 대상과 상황에서 재사용할 수 있다.
- 시퀀스는 유한한 진행과 연출을 조율하고, 계속 실행되는 게임 규칙은 Game Module이 맡는다.

## 기존 도구 처리

- UI Toolkit Sequence Maker가 공식 도구가 된다.
- Odin 시퀀스 에디터 기능은 공식 도구로 흡수한 뒤 개발용으로 숨기거나 제거한다.
- 기존 QTE, ZEV 복제 전투, 오버월드 지하철 시퀀스는 마이그레이션 중에도 계속 작동해야 한다.

6. UIManager PPC Safe Area Pillarbox Calculation Fix

UIManager / Overworld UI
  • 문제: 이전 계산은 640x480의 단순 4:3 비율을 Canvas 안에 맞추는 방식이었습니다.
  • 하지만 URP PixelPerfectCamera의 Pillarbox는 zoom = min(Screen.width/refX, Screen.height/refY) 정수 배율을 구한 뒤 refX * zoom을 실제 출력 폭으로 사용합니다.
  • 1920x1080 기준 단순 4:3 폭은 1440px이지만, PPC pillarbox 실제 출력 폭은 640 * 2 = 1280px입니다.
  • UIPixelPerfectSafeAreaFitter가 PixelPerfectCamera.cropFrame을 읽어 Pillarbox, Letterbox, Windowbox, StretchFill별 실제 출력 pixel size를 계산하도록 수정했습니다.
  • 계산된 pixel size는 Canvas.scaleFactor로 나눠 overlay Canvas UI 단위로 변환합니다.
  • 검증: dotnet build .\HubToHome.sln --no-restore, git diff --check -- Assets/_Game/Core/Scripts/UIManager.cs 통과.

5. UIManager OverWorldPanel PPC Safe Area

UIManager / Overworld UI
  • 문제: OverworldMenuUI는 overlay Canvas 전체 폭을 기준으로 stretch되고 있었지만, 실제 게임 카메라 PPC는 640x480 기준 4:3 안전 영역을 사용합니다.
  • 16:9/4K 같은 넓은 화면에서는 UI가 PPC 안전 영역 밖까지 벌어져 좌우 UI가 잘릴 수 있었습니다.
  • UIManager에 패널별 opt-in PPC safe area 구조를 추가했습니다.
  • 현재 적용 대상은 OverWorldPanel만이며, Battle UI와 기타 fullscreen UI는 변경하지 않았습니다.
  • 런타임에 [PPC Safe Area] RectTransform을 만들고, opted-in 패널의 직접 자식 UI를 그 아래로 이동시켜 stretch 기준을 4:3 중앙 영역으로 제한합니다.
  • 활성 PixelPerfectCamera 중 이름이 PPC인 카메라의 reference resolution을 우선 사용하고, 없으면 640x480 fallback을 사용합니다.
  • 씬 파일은 수정하지 않았습니다. 검증: dotnet build .\HubToHome.sln --no-restore, git diff --check -- Assets/_Game/Core/Scripts/UIManager.cs 통과.

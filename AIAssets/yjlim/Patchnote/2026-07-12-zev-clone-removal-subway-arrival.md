# ZEV 복제 전투 제거 및 지하철 도착 개선

## ZEV 복제 전투

- 개발 검증용으로 만들었던 ZEV 아키텍처 복제 전투 세트 제거.
- 전용 시나리오, 적 데이터, 프리팹, 대사, 카탈로그, 테스트 씬과 테스트 코드 제거.
- 원본 ZEV와 실제 QTE 전투 시스템은 유지.
- 던전 입구 샘플에서는 복제 적과 복제 전투 마커만 제거하고 나머지 맵 구성 유지.

## 지하철 도착

- Overworld 진입 화면은 검은 상태에서 1초 동안 밝아짐.
- 화면이 완전히 밝아진 뒤 0.75초 대기.
- 지하철이 화면 왼쪽 바깥 X -30에서 오른쪽 X 24까지 8초 동안 이동.
- 지하철 중심이 화면 중앙에 접근하는 4.45초 시점부터 카메라가 이동과 줌인을 시작.
- CameraRail Y를 Sprite 실제 중심인 3.75에 맞춤.
- CameraRail을 기차 중심보다 X 2 unit 왼쪽에 배치하고 기차와 정확히 같은 속도로 이동.
- 지하철 Shot의 position damping을 0으로 적용해 추적 중 미세 떨림 완화.
- 시작 구도는 Orthographic Size 10, 추적 종료 구도는 7로 조정.
- 샷 종료 뒤 0.35초 유지하고 1초 동안 검게 페이드.
- Stage 시작과 완전히 어두워진 뒤의 카메라 복귀는 2초 기본 블렌드를 무시하고 즉시 전환.
- 완전히 어두워진 화면을 2초 유지한 뒤 기본 카메라로 복귀.
- 시네마틱 카메라를 해제한 뒤 원래 오버월드를 0.9초 동안 공개.

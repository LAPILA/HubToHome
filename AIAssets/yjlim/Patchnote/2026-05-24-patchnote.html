HubToHome 패치노트

2026-05-24 작업 통합본. 기존 여러 HTML 패치노트를 이 파일 하나로 합쳤습니다.

1. 타이틀~배틀 UI 해상도 대응

Resolution UI

완료

타이틀부터 배틀씬까지 UI 관련 해상도 대응은 현재 기준으로 완료되었습니다. 배틀씬 쪽 UI 문제도 모두 해결된 것으로 기록합니다.

Canvas Scaler

DialogueCanvas의 CanvasScaler Match Width Or Height가 height 기준이라 640x480에서 가로 UI가 좁게 잡히던 원인을 확인했습니다. width 기준인 0으로 바꾸면 가로 대응이 자연스럽게 동작합니다.

보류

스킬창 UI 위치는 약간 애매해 보이나, 배치 의도와 최종 디자인 기준을 알 수 없어 이번 작업에서는 그대로 둡니다.

2. 입력/QTE/전투 UI 안정화

Battle Input
  • QTE 입력 판정을 한 곳으로 통일해 연타, Z/X/C, 방향키 동시 입력 시 판정 꼬임 가능성을 줄였습니다.
  • BattleSubMenu는 절대 Y 좌표 대신 씬에 배치된 초기 위치를 기준으로 열림 위치를 계산하게 했습니다.
  • 서브메뉴 표시 위치는 초기 숨김 위치 + _showOffsetY이며 기본 offset은 130입니다.
  • 옵션 패널 쪽 마스크는 불필요해 보여 사용자 수동으로 비활성화했습니다.

3. BattleScene 전환/페이드

Scene Reveal

원인

기존 SceneLoader는 씬 활성화 직후 페이드를 걷었지만, 전용 BattleScene에서는 플레이어 생성, 위치 배치, 몬스터 생성, UI 갱신, 카메라 리셋이 뒤따랐습니다.

수정

ISceneRevealGate 구조를 추가해 BattleManager가 준비 완료 신호를 열기 전까지 페이드가 유지되도록 했습니다.

수동 수정

사용자가 FadePanel 크기 불일치를 수정했습니다. 이후 전투 진입/종료 페이드 확인 시 수정 완료 기준으로 봅니다.

4. 오버월드 배경 전투 재조우 방지

Encounter
  • 전투 종료 직후 플레이어가 같은 적 trigger 안에 남아 이미 이긴 적과 즉시 재전투하는 문제를 보완했습니다.
  • IEncounterSource와 EncounterCollisionGuard를 추가했습니다.
  • 플레이어를 적 collider 밖으로 살짝 밀어내고, trigger exit 전까지 해당 적 조우를 막고, 짧은 grace time 동안 조우를 무시합니다.
  • collider를 끄는 방식은 사용하지 않았습니다.

5. 대화/말풍선 UI

Dialogue UI

BattleNarration

BattleNarrationUI가 Backg RectTransform을 찾아 TMP preferred size 기준으로 말풍선과 텍스트 영역을 함께 조정하게 했습니다. 최대 가로폭은 캔버스의 50%입니다.

CinematicPanel

사용자가 DialogueManager > CinematicPanel > DialogueText TMP Margin을 일괄 10으로 정리했습니다.

OverworldPanel

OverworldPanel과 Backg는 부모 패널과 캔버스 스케일을 따라 해상도에 맞춰 변하는 구조로 확인했습니다.

6. DOTween 예외 완화

DOTween

타이틀 씬에서 발생하던 DOTween IndexOutOfRangeException 원인 후보로 런타임 중 전역 tween capacity를 재설정하는 코드가 확인되었습니다. CameraController에서 DOTween.SetTweensCapacity(...) 호출을 제거했습니다.

7. UI 아트/레이아웃 작업

UI Art
  • SettingPanel.png를 UI Sliced 이미지로 쓰기 위해 Sprite Border를 6,6,6,6으로 설정했습니다.
  • BattleSubMenu 하위 구조를 UpperPanel과 DownPanel로 분리한 작업 기록을 남겼습니다.
  • PartySlot_Prefab 반응형 앵커 조정 시도는 사용자 요청에 따라 롤백했습니다.

8. 에디터 디버그/기록 방식

Workflow
  • 에디터 전용 치트 매니저를 추가했고, 일반 빌드에는 포함되지 않도록 UNITY_EDITOR 조건으로 제한했습니다.
  • Kill All Enemies와 Instant Victory가 기존 승리 종료 루틴을 타도록 연결했습니다.
  • 타이틀 씬 빠른 실행 단축키 Alt + Shift + P를 추가했습니다.
  • 앞으로 작업 기록은 AIAssets/YYYY-MM-DD-update.md와 날짜별 사람용 HTML 문서에 남깁니다.

QA

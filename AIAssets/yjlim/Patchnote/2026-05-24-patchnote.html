HubToHome 패치노트

2026-05-24 작업 통합본. 기존 여러 HTML 패치노트를 이 파일 하나로 합쳤습니다.

1. 타이틀~배틀 UI 해상도 대응

Resolution UI

완료

타이틀부터 배틀씬까지 UI 관련 해상도 대응은 현재 기준으로 완료되었습니다. 배틀씬 쪽 UI 문제도 모두 해결된 것으로 기록합니다.

Canvas Scaler

DialogueCanvas의 CanvasScaler Match Width Or Height가 height 기준이라 640x480에서 가로 UI가 좁게 잡히던 원인을 확인했습니다. width 기준인 0으로 바꾸면 가로 대응이 자연스럽게 동작합니다.

보류

스킬창 UI 위치는 약간 애매해 보이나, 배치 의도와 최종 디자인 기준을 알 수 없어 이번 작업에서는 그대로 둡니다.

2. 입력/QTE/전투 UI 안정화

Battle Input
  • QTE 입력 판정을 한 곳으로 통일해 연타, Z/X/C, 방향키 동시 입력 시 판정 꼬임 가능성을 줄였습니다.
  • BattleSubMenu는 절대 Y 좌표 대신 씬에 배치된 초기 위치를 기준으로 열림 위치를 계산하게 했습니다.
  • 서브메뉴 표시 위치는 초기 숨김 위치 + _showOffsetY이며 기본 offset은 130입니다.
  • 옵션 패널 쪽 마스크는 불필요해 보여 사용자 수동으로 비활성화했습니다.

3. BattleScene 전환/페이드

Scene Reveal

원인

기존 SceneLoader는 씬 활성화 직후 페이드를 걷었지만, 전용 BattleScene에서는 플레이어 생성, 위치 배치, 몬스터 생성, UI 갱신, 카메라 리셋이 뒤따랐습니다.

수정

ISceneRevealGate 구조를 추가해 BattleManager가 준비 완료 신호를 열기 전까지 페이드가 유지되도록 했습니다.

수동 수정

사용자가 FadePanel 크기 불일치를 수정했습니다. 이후 전투 진입/종료 페이드 확인 시 수정 완료 기준으로 봅니다.

4. 오버월드 배경 전투 재조우 방지

Encounter
  • 전투 종료 직후 플레이어가 같은 적 trigger 안에 남아 이미 이긴 적과 즉시 재전투하는 문제를 보완했습니다.
  • IEncounterSource와 EncounterCollisionGuard를 추가했습니다.
  • 플레이어를 적 collider 밖으로 살짝 밀어내고, trigger exit 전까지 해당 적 조우를 막고, 짧은 grace time 동안 조우를 무시합니다.
  • collider를 끄는 방식은 사용하지 않았습니다.

5. 대화/말풍선 UI

Dialogue UI

BattleNarration

BattleNarrationUI가 Backg RectTransform을 찾아 TMP preferred size 기준으로 말풍선과 텍스트 영역을 함께 조정하게 했습니다. 최대 가로폭은 캔버스의 50%입니다.

CinematicPanel

사용자가 DialogueManager > CinematicPanel > DialogueText TMP Margin을 일괄 10으로 정리했습니다.

OverworldPanel

OverworldPanel과 Backg는 부모 패널과 캔버스 스케일을 따라 해상도에 맞춰 변하는 구조로 확인했습니다.

BattleSpeechBubble

BattleSpeechBubbleDirection을 추가해 Up, Left, Right 방향을 rule 또는 호출부에서 지정할 수 있게 했습니다. 표시 시 방향별 스프라이트를 적용하고 Image Type = Sliced로 세팅합니다. BattleSpeechBubble_Enemy와 BattleSpeechBubble_Player 프리팹에도 세 방향 스프라이트 참조를 연결했습니다.

6. DOTween 예외 완화

DOTween

타이틀 씬에서 발생하던 DOTween IndexOutOfRangeException 원인 후보로 런타임 중 전역 tween capacity를 재설정하는 코드가 확인되었습니다. CameraController에서 DOTween.SetTweensCapacity(...) 호출을 제거했습니다.

14. Console Pro Imported

Debug Tool
  • 사용자가 Unity 에디터에 Console Pro를 임포트했습니다. 루트 경로는 Assets/ConsolePro입니다.
  • 주요 파일은 ConsolePro.Editor.dll, Editor Console Pro Documentation.pdf, ConsoleProDebug.cs, RemoteServer.zip입니다.
  • Console Pro는 기본 Console보다 검색, 필터링, 그룹화가 편해서 BattleSpeechBubble 호출 여부와 룰 조건 통과 여부를 추적할 때 유용합니다.
  • 코드에서는 FlyingWormConsole3.ConsoleProDebug를 사용할 수 있습니다.
  • 특정 필터 로그: ConsoleProDebug.LogToFilter("message", "BattleSpeech");
  • 값 추적: ConsoleProDebug.Watch("BattleSpeech Trigger", trigger.ToString());
  • 검색 요청: ConsoleProDebug.Search("BattleSpeech");
  • 임시 디버그 로그는 검증 후 제거하거나 UNITY_EDITOR 조건으로 제한하는 것을 권장합니다.

15. Dialogue Console Pro Logs

Debug Tool

  • PlayNode 로그로 현재 다이얼로그 이름, 노드 인덱스, speaker, localization key, event id를 확인할 수 있습니다.

16. BattleSpeechConfig Assets

Battle Speech

  • 신규 스크립트: Assets/_Game/Features/Dialogue/Scripts/BattleSpeechConfig.cs
  • 신규 데이터 폴더: Assets/_Game/Features/Dialogue/Data/BattleSpeech

  • Unity MCP 기준 두 config asset은 BattleSpeechConfig 타입으로 인식되며, 말풍선 프리팹과 캐릭터 nested prefab 연결도 유지됩니다.

20. Battle Speech Pivot Positioning

Battle Speech

22. SmartTextWrapper 공용 줄바꿈 시스템

Shared UI
  • 한국어/짧은 전투 대사에서 마지막 단어 조각만 다음 줄로 떨어지는 문제를 줄이기 위해 SmartTextWrapper를 추가했습니다.
  • 위치: Assets/_Game/Shared/Scripts/Text/SmartTextWrapper.cs.
  • 사용법: TMP UI에서는 SmartTextWrapper.Wrap(tmpText, rawText, maxTextWidth)를 호출하면 됩니다.
  • 테스트나 TMP 외부 시스템에서는 SmartTextWrapper.Wrap(rawText, maxTextWidth, measureWidth) overload를 사용할 수 있습니다.
  • 공백 기준 토큰을 greedy 방식으로 배치하고, 같은 토큰 폭은 호출 중 캐시합니다. 한 토큰 자체가 너무 길 때만 문자 단위로 fallback합니다.
  • SmartTextWrapOptions로 기능 on/off, 기존 줄바꿈 보존, 공백 정리 여부를 조정할 수 있습니다.
  • 1차 적용 대상은 BattleSpeechBubble과 BattleNarrationUI입니다. QTE, HP/MP, 메뉴 버튼, 옵션 값 같은 짧은 UI 라벨에는 적용하지 않았습니다.
  • SmartWrap 적용 대상 TMP는 런타임에 TextWrappingModes.NoWrap으로 자동 wrapping을 끕니다. 그래야 TMP가 SmartWrap 이후에 있어.를 있/어.처럼 다시 쪼개지 않습니다.
  • 테스트 파일: Assets/_Game/Shared/Tests/Editor/SmartTextWrapperTests.cs.
  • C# LSP 진단, Unity script validation, Unity Console error 0건, dotnet build .\HubToHome.sln --no-restore 통과. EditMode Test Runner는 에디터가 Play Mode 상태라 시작하지 못했습니다.

# HUBTOHOME-90 설정 저장 및 시각 접근성

## 변경 사항

- 설정 로드값을 공용 정책으로 정규화해 손상된 PlayerPrefs 값이 런타임에 전파되지 않도록 했다.
- 창 크기를 640×480 기준 1배/2배로 선택하고 저장할 수 있게 했다.
- 점멸 강도를 0~100%로 조절하고 저장할 수 있게 했다.
- FPS와 VSync 변경 시 해상도·언어 설정까지 다시 적용하던 경로를 분리했다.
- 전투 시나리오 UI 흔들림과 화면 플래시에 접근성 배율을 적용했다.
- 설정 패널에 창 크기와 점멸 강도 행, 흔들림·점멸 미리보기를 추가했다.
- 설정 목록이 화면보다 짧을 때 스크롤 정규화 값이 NaN이 되는 경우를 차단했다.
- `GameConfigManager` 파괴 시 싱글톤 참조를 해제한다.

## 제작자의 다음 한 바퀴

다음은 우선순위나 새 기능 제안이 아니라 **한 기능을 통과시키는 통합 확인 순서**입니다. 실제로 확인하기 전에는 체크하지 않습니다.

- [ ] 일반 필드에서 실제 동료2명을 기존 영입 이벤트로 합류시키고, 저장 후 다시 불러와 동료 목록을 확인합니다.
- [ ] 위젤 외형은 그대로 사용해 ㄱ자 통로·좁은 문·대각선·Shift 달리기를 확인합니다. 동료는 충돌/문/전투를 직접 발동시키면 안 됩니다.
- [ ] 시퀀스 메이커에서 고정 → 리더 이동 → 추종 재개, 숨김/표시, 경유점 이동을 확인합니다. Move의 좌표는 월드 좌표입니다.
- [ ] 경로 밖 재합류를 의도적으로 요청해 명확한 실패/Hold가 되는지 확인합니다. 벽을 가로지르는 자동 복귀가 없어야 합니다.
- [ ] 암전 중 Gather와 같은 좌표로의 Room 이동을 확인합니다. 도착 후 이동하면서 동료 줄이 펴지는지 봅니다.
- [ ] 대화·메뉴·심리스 전투 왕복 중 동료 중복, 옛 Tween 재생, 카메라 대상 변경이 없는지 확인합니다.
- [ ] 동료 외형/방 구성이 정해진 뒤 목표 기기에서 Animator·입자·조명을 포함한 프레임/메모리/발열을 측정합니다. 관리형 계산0B와 기기 성능을 혼동하지 않습니다.

## 학습실에 함께 둘 설명

**기록 경로를 택한 이유** → **순환 버퍼와 누적 거리** → **Follow/Hold/Detached** → **명령 취소와 Epoch** → **맵·전투 경계** 순서로 [심화 문서](study/deep/10-overworld-party-follow.md)를 읽습니다. 이번 구현은 델타룬의 내부 코드를 복제했다는 주장이 아니라, 유사한 이동 목적을 기존 프로젝트 구조에 맞게 구현한 것입니다.

포트폴리오에는 코드량 대신 모서리 직선 통과 방지, 오래된 경로 거부, 동일 DB 동료의 개체 구분, 늦은 콜백 무효화, 본인이 직접 확인한 Unity 결과를 제시합니다. AI 생성 여부를 감추는 설명이나 미실행 검증을 완료로 기재하지 않습니다.

2026-10-23 후속 확인: 각 root 아래 가져오기 묶음과 그 아래 실제3본문을 확인했습니다. 코드 학습의 실제 C#4발췌, 제작 사용법의 YAML3예시·명령4개 표, 운영 문서의 상태표·검증표·미실행8항목과 기존 일정·역할을 확인했습니다. 실제 본문을 끝까지 스크롤하여 제목·섹션·표·체크리스트·원본 경로의 렌더링과 학습실/운영실/Google Docs3개 외부 링크의 href를 검사했으며, 전체 블록의 바이트 동일성 검사는 아닙니다.

기존 자료의 삭제·대체, 원격 문서 편집·이름 변경, 설정·계정·공유권한 변경은 하지 않았습니다. 가져오기 묶음의 기본 긴 제목은 유지했습니다. API404와 사용자 로그인 문제를 동일시해 재로그인·재연결을 반복 요청하지 않으며, 이번 게시에 사용자 추가 행동은 필요하지 않습니다. ZIP 재가져오기는 갱신이 아니라 중복 생성입니다. Unity Play·엔진 NUnit·실기기 검증은 위 확인표대로 미실행입니다.

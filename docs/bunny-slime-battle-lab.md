# 토끼 슬라임 전투 실험실

## 최신 변경: 투사체와 1인 반격

- 기존 Lab 씬을 열어 **가드·회피**를 선택하면 근접 공격과 **단발탄 / 엇박자 2연발 / X 전용 과압력탄**을 순환합니다. 종합 전투에도 같은 패턴이 연결되어 있습니다.
- **연계 반격**에서는 적이 먼저 접근·전조를 보입니다. C 성공 시 공격받은 1명만 적 앞에 가서 **패링 → 공격 → 양쪽 동시 복귀**합니다. 다른 아군은 이동하거나 공격하지 않습니다.
- 기본 최소 입력 여유는 타격 전 **Z 0.24초 / X 0.34초 / C 0.28초**, 타격 후 **0.06초 미만**입니다. 기존 데이터가 더 넓으면 유지합니다. 타격 전에 성공 입력을 받았으면 원래 타격 시각에 즉시 처리합니다. 그 외에는 짧게 충돌 포즈를 유지하고 피해를 한 번만 확정하므로 HP를 되돌리는 방식이 아닙니다.
- 연타해도 진행 중인 회피를 처음부터 다시 시작하지 않습니다. 전조 전 입력을 했더라도 유효 구간의 새 입력은 받으며, 확정된 대응·피격·C 반격은 새 미리보기가 덮지 않습니다.
- 새 샘플 파일은 `Data/Skills/enemy_shot.asset`, `enemy_double_shot.asset`, `enemy_dodge_shot.asset`입니다. 스킬 메이커에서 비행 시간·피해 배율을 바꿀 수 있습니다. **방어 대응 → 투사체**의 인접 순서는 유지하세요.
- 전조는 `Telegraph.aseprite`의 START 애니메이션과 프리팹에 지정한 핑 음원을 사용합니다. 음원은 `Telegraph.prefab > BattleTelegraphCue > Ping Clip`에서 교체합니다.

검증: 독립 C# 정책 검사 108건, 런타임/에디터 컴파일 오류 0, 자산 GUID/방어·투사체 순서/패턴 연결 검사 통과. Unity Play/Edit 테스트는 하지 않았으므로 실제 모션 연결과 입력 체감은 Play에서 확인해야 합니다. 씬 재생성은 필요 없습니다.

## 바로 실행하기

1. Unity에서 Play를 종료합니다.
2. 상단 **Hub To Home → 테스트 → 토끼 슬라임 종합 전투 열기**를 누릅니다. 첫 실행에서만 필요한 샘플 자산과 씬을 생성합니다. 다른 씬에 저장하지 않은 작업이 있으면 먼저 저장/취소를 선택합니다.
3. 열린 `BunnySlimeBattleLab` 씬에서 **Play**를 누릅니다.
4. **↑↓ 선택 → Z 시작**. 전투 중 **F8**로 중단하고 메뉴로 돌아옵니다. 마우스 클릭은 사용하지 않습니다.

생성기가 기존 자산을 덮어쓰지 않으므로, 이후 같은 메뉴는 만들어 둔 실험실을 다시 엽니다. 기존 TestMap과 공격하지 않는 원본 토끼 슬라임은 변경하지 않습니다.

2026-09-13 후속 수정: 생성된 토끼에 대기 AI가 중복으로 남던 문제를 바로잡았습니다. 기존 샘플 프리팹도 수정했으므로 삭제·재생성할 필요 없이 같은 Lab 씬을 새로 Play하면 됩니다. 이후 생성과 진입 시에는 `BunnySlimeShowcaseEnemy`가 정확히 하나인지 검사합니다.

> 기존 실험실 자산에 직접 연결했으므로 삭제·재생성하지 않아도 됩니다. 이번에는 Unity Play/Edit 테스트나 강제 Refresh를 실행하지 않았습니다.

| 종합 전투 | 오프닝, HP 66%/33% 단계, 스킬/상태, 승리 대화와 보상 | 처음에는 Z 가드로 관찰하고 아이템도 사용 |
| 가드·회피 | 근접 + 단발탄 / 엇박자 2연발 / X 전용탄 반복 | 일반 공격에서 Z 유지/정확한 Z/X를 비교 |

| 3+3 후열 확인 | 전열 HP 1, 후열은 정상 HP | 첫 광역 공격을 막지 않고 후열 등장 확인 |

공통으로 전투 종료·패배·F8 중단 후 메뉴로 돌아가며 HP/AP/소모품을 다시 준비합니다. 도주는 회색 비활성 상태입니다. 패배해도 일반 게임오버/세이브 로드로 넘어가지 않습니다. 메뉴 결과에는 가드·저스트·회피·반격 횟수와 후열 등장 여부가 표시됩니다.

## 종합 전투의 흐름

“말랑한 공방 안전시험”에 참가한 위젤 일행이 토끼 슬라임 시험관의 과도하게 실용적인 안전교육을 받습니다.

| 단계 | 조건 | 공격과 연출 |
| --- | --- | --- |
| 접수 | 전투 시작 | 대사, 레터박스, 카메라 집중, 피해 없는 고무 도장 시범 |
| 기본 시험 | HP 66% 초과 | 내려찍기 → 단발탄 → X 전용 근접 → 엇박자 2연발 → 근접 3연타 |
| 누출 사고 | HP 66% 이하 | 대사/BGM 전환. 젖음 → 독 시약 → 광역 대청소 → X 전용 과압력탄이 새로 등장. 이전 패턴도 유지 |
| 협업 시험 | HP 33% 이하 | 짧은 흰색 점멸, 대사/BGM 전환. C 연계 반격 공격 우선 등장 후 전체 패턴 순환 |
| 합격 | 격파 | 합격 대화 → 기존 전투 결과/보상 → 실험 메뉴 |

적 공격에는 QTE 패널이 뜨지 않습니다. 공격 준비 자세를 한 번 보여준 뒤 방어 결과가 확정되는 프레임에 적 공격 모션과 피해가 함께 시작됩니다. Z는 유지 시 피해 감소, 타격 직전 정확히 누르면 저스트 가드와 AP 보상입니다. X는 무피해 회피지만 추가 보상은 없습니다. C는 반격 표시가 있는 특수공격에만 사용합니다. 이 공격은 Z로 막을 수 없고 X로 회피할 수 있습니다. C 반격은 공격받은 전열 1명만 수행하고 나머지 아군은 자리를 유지합니다.

플레이어 스킬의 QTE는 별도 규칙입니다. 스킬이 이동·애니메이션을 재생하는 동안 실시간으로 입력하고, 피해·상태 적용 시점에서만 결과를 소비합니다. 따라서 스킬의 모든 버튼을 누를 때까지 모션 전체가 멈추지 않습니다.

젖음/독 시약은 피해 공격에 몰래 붙은 부가 효과가 아니라 **별도의 상태 부여 행동**입니다. 이 두 행동에는 방어 판정이 없습니다. 대미지와 상태 부여의 조건부 연동은 이번 샘플에서 새로 구현하지 않았습니다.

## 파티와 제작 예제

6명 모두 기존 위젤 외형을 쓰는 실습 역할입니다. 서로 다른 신규 동료 아트가 아닙니다. 이름·전투 색상·고유 ID·스킬 구성을 분리했습니다. 수동 교대 없이 전열 전원이 쓰러져야 후열이 나옵니다.

| 역할 | 스킬 4개 |
| --- | --- |
| 전열 · 압력 | 압력 베기 / 쌍압 절단 / 증기 찌르기 / 역류 참격 |
| 전열 · 지원 | 냉각 보호막 / 분무 노즐 / 과출력 시동 / 증기 횡단 |
| 전열 · 돌격 | 터빈 연격 / 과열 강하 / 보일러 파열 / 임계압 돌파 |
| 후열 · 열기 | 휴대 화염 노즐 / 불씨 실험 / 날붙이 실험 / 압력 해방 |
| 후열 · 냉각 | 냉각탄 발사 / 냉각 실험 / 고정 장치 / 충격 시험 |
| 후열 · 방전 | 휴대 방전기 / 부식액 발사 / 부식 시약 / 압력 베기 |

포함 범위:

- 기존 위젤 샘플 스킬 10개, 새 속성 투사체 4개, 기존 상태 ID 9종의 부여 스킬.
- 물리·화염·빙결·전기·부식 피해. 젖음 다음 전기 공격, 보호막 전후 피해 차이를 비교할 수 있습니다.
- 기존 7종 회복 아이템 각 5개. 일부 AP 아이템의 회복량이 작으므로 설명을 확인하세요.
- 압력검(공격 +4), 작업복(방어 +2), 밸브(최대 AP +20)를 각 파티원에게 장착.
- 이동, 대기, 애니메이션, 플레이어 스킬 QTE, VFX, 일반 피해, 연쇄 근접, 투사체, 적 전용 실시간 방어창, 상태 부여 블록.
- 슬라임 원본 Idle 프레임을 재사용한 찌그러짐/팽창 애니메이션. 단타·광역은 0.85초, 연타는 0.65초 타격 키와 방어창 종료를 맞춘 전용 클립.

새 장비 패시브, 적 자기버프 타깃 지원, 소환/새 전투 모듈, 미구현 적 스킬 완료 이벤트, 새로운 동료 스프라이트는 포함하지 않습니다. 기존 모든 적의 스킬을 한 전투에 몰아 넣은 샘플도 아닙니다.

## 안전·검증 범위

### 타격 직전 전조 · Telegraph (2026-09-26 갱신)

토끼 실험실 및 공용 QTEManager는 `Assets/_Game/Presentation/Custom_VFX/Prefabs/Telegraph.prefab`을 사용합니다. **실제 대응 성공 구간이 열릴 때** `Telegraph.aseprite`에서 가져온 `START` 클립을 처음부터 한 번 재생합니다. 현재 원본은 5프레임(20/55/70/55/35ms, 합계 0.235초)입니다. 대응 구간이 더 짧으면 재생만 압축하며 판정 시간은 늘리지 않습니다. 적의 찌그러짐/뒤집기를 상속하지 않고 Center 피벗의 위치만 따라갑니다. 원거리·연속타의 전조 호출 횟수는 바꾸지 않았습니다.

- **소리 넣기:** 프리팹의 `Ping Clip`에 지정돼 있던 `SFX_Vefects_Magic_Impact_02.wav`를 유지했습니다. `Volume`으로 음량을 조절합니다. AudioManager의 SFX 경로로 실제 START 재생 시 한 번만 출력하며, 예열/준비/풀 활성화에서는 울리지 않습니다. 전용 AudioSource는 불필요합니다.
- **표시 시간:** X가 가능한 준비 구간에는 첫 프레임을 흐리게 유지하고, 정밀 대응 구간에 START와 핑을 함께 시작합니다. QTEManager의 남은 타격 시간으로 프레임을 평가하므로 설정창/일시정지에서도 판정과 함께 멈춥니다. 실시간 적 대응의 기본 최소 구간은 Z 저스트가드 `0.24초`, X 회피 `0.34초`, C 반격 `0.28초`입니다. 기존 자산이 더 후한 값이면 보존하고, 아주 짧은 공격은 전체 길이로 제한합니다. 일반 공격 핑은 Z 구간, 회피 전용은 X 구간, 특수공격은 X/C 공통 구간입니다. `ImpactCueLeadTime`은 저장 호환용 숨김 필드입니다.
- **입력 규칙:** 각 키의 성공 구간 전 입력은 시도를 잠그지 않습니다. X는 흐린 준비 표시부터 성공할 수 있고 Z/C는 강한 핑 구간에서 새로 누릅니다. 먼저 유지한 Z는 일반 방어입니다. 인정된 입력은 같은 타격에서 다시 바꿀 수 없고 다음 타격에 재사용하지 않습니다. 입력 이벤트의 실제 시각으로 판정하며, 특수공격의 Z 금지 등 공격별 제한과 보상은 유지합니다.
- **다른 스킬에 쓰기:** SeamlessBattleHost의 QTEManager에 기본 Telegraph가 연결되어 있습니다. 스킬에서 별도 프리팹을 넣으면 그것을 우선 사용합니다. 기본/실험실 스킬의 피벗은 Center입니다. C 대응은 청록색으로 구별하되 새 아트를 45도 회전시키지 않습니다. 렌더 순서는 공격자와 같은 Sorting Layer / Order - 1입니다.
- **모양 바꾸기:** Aseprite의 START 프레임을 수정하면 같은 Animator Controller의 클립을 읽습니다. 태그 이름을 바꾸면 프리팹 `재생 클립`도 맞추세요. 현재 크기는 `(3,3,3)`으로 복원했고 `중심 위치 보정`은 0입니다. 크기는 Transform Scale에서 조정합니다. 구형 스케일/점멸 옵션은 현재 프리팹에 불필요해 Inspector에서 숨겼습니다. 전투에서는 클립을 방어 시계에 맞춰 직접 평가하며, 단독 프리팹 확인 때에는 원래 Animator가 재생합니다.
- **정리:** 타격 결과가 나오는 순간 제거하며, 스킬 취소 시에도 풀에 반환합니다. 설정창/일시정지에서는 판정과 전조 연출이 함께 멈춥니다. 극심한 프레임 지연으로 타격 시각을 이미 지났으면 늦은 전조·효과음을 재생하지 않습니다.

### 모션의 타격 시각

스킬 메이커의 **방어 대응 → 공격 모션 시작 → 타격 시간**에는 클립 시작부터 실제로 때리는 프레임까지의 초를 넣습니다. 이 값은 판정 시간 이하여야 합니다. 토끼 단타·광역은 `0.85`, 연타는 `0.65`입니다. 이제 모션을 먼저 재생하고 이 시간이 지난 프레임에 방어 결과를 확정합니다. 기존 자산은 기본값 `0`으로 기존 동작을 유지합니다.

위젤의 Attack/Hurt/Parry 진입은 즉시 전환하며, Hurt는 클립 종료 후 Idle로 돌아갑니다. C 반격은 공격받은 1명만 접근 → 패링 → 준비 → 제자리 공격을 수행하고 적과 동시에 복귀합니다. 실험실 씬을 다시 생성하거나 Inspector 참조를 다시 연결할 필요는 없습니다.

### 고정 구도와 짧은 감속

- 일반 공격에는 자동 카메라 추적·줌·흔들림·전역 히트스톱을 넣지 않습니다. 기존 Pixel Perfect의 32 PPU / 640×480 설정은 그대로입니다. 시나리오에서 명시한 카메라 연출은 계속 가능합니다.
- 공격받을 아군은 아이템 사용처럼 **오른쪽 1유닛(32픽셀)을 0.20초에 전진**합니다. 그 위치에서 Z 방어, X 회피(왼쪽 약 12픽셀), 피격(최대 약 6픽셀)을 처리하고 공격 종료 후 원래 파티 자리로 돌아옵니다. 전진해도 원래 슬롯 데이터는 바뀌지 않습니다. 광역기는 기존 대표 대응자만 전진하고 나머지는 자리를 유지합니다.
- C 궁극기는 **적이 전투 중앙으로 이동 → 전조 → C 성공 → 대상 아군이 적 앞으로 접근 → 패링 → 공격 → 양쪽 원위치 동시 복귀**입니다. 일반 방어 위치를 한 번 더 거치지 않습니다. 중앙 이동은 CenterPos의 X를 사용하며 바닥 Y/Z는 보존합니다.
- 아군 기본 공격 후 복귀는 점프 없는 지상 이동입니다. 토끼의 근접 접근은 높이 `0.25`, C 중앙 접근은 `0.45`의 짧은 DOTween 상하 이동입니다. 스킬 메이커 **이동 → 적 이동 높이**를 `0`으로 바꾸면 지상 이동이며, 이 값은 아군에게는 적용하지 않습니다. 타격 시각/입력 여유/카메라 설정은 그대로입니다.
- 적의 방어 대응 구간에는 공격자 Animator만 **실제 0.10초 동안 0.5배속**으로 진행합니다. 투사체도 같은 시계로 감속합니다. UI·입력·BGM과 `Time.timeScale`은 바꾸지 않습니다. 보통 타격 시각이 원래보다 0.05초 늦어지며 모션과 판정을 함께 늦춥니다.
- 적 스킬 기본 순서는 **접근 → 방어 대응 → 피해**입니다. 방어 대응 안에서 준비 자세·클립 시작·전조·타격을 조율합니다. 타격 뒤 정리 대기만 `DelayAfter`로 처리합니다.
- 투사체는 **방어 대응 → 투사체**를 붙여 놓습니다. 대응을 먼저 끝내지 않고 비행 중에 함께 진행하며, 실제 도착 시 판정·피해를 확정합니다. 비행 시간은 투사체 블록을 사용합니다.
- **방어 대응 → 연쇄 근접**도 붙여 놓으면 대상마다 접근 후 준비·대응·타격을 반복합니다. 한 번의 방어로 모든 타격을 처리하지 않습니다. 사이에 활성 대기/다른 블록을 넣으면 자동 동기화 대상으로 취급하지 않습니다.
- 피해 블록만 있는 구형 적 스킬에 타격 시점을 자동 추정하지 않습니다. 반드시 방어 대응 블록과 해당 클립의 타격 선행 시간을 설정하세요. 아군 공격 QTE 규칙은 이번 변경에 포함하지 않았습니다.
- 메뉴 정지/실행 취소/공격자 파괴 시 방어 시계·전조·공격자 감속을 정리합니다. 다음 전투에 감속이 남지 않도록 실행 소유권으로 복구합니다.

실험실은 기존 게임 세션에 추가로 로드해서 사용하지 않습니다. Edit Mode에서 이 씬 하나만 열고 새로운 Play를 시작해야 합니다. 저장 파일을 읽거나 쓰는 경로는 연결하지 않았습니다. 생성 메뉴는 샘플을 공식 ID 로더로 찾도록 콘텐츠 카탈로그에 추가하지만 기존 항목을 교체하지 않습니다.

실기 확인 순서: 종합 오프닝 → Z/X → F8 → C → F8 → 후열 등장 → 패배/승리 복귀. UI 실제 화면, 음원 조합, 손맛과 난이도는 사용자 Play 확인 후 조정해야 합니다.

## 조명·색감 샘플 (2026-09-26)

Hierarchy의 **Lab Lighting - Neon** 아래에서 조절합니다. 배경·캐릭터 아트는 그대로 두고, 남청색 기본광 + 아군 쪽 호박색 + 적 쪽 청록색 + 배경 보라색 포인트를 배치했습니다.

- 전체 밝기: `Lab Global Light > Intensity` (현재 0.62).
- 좌우 조명: `Warm Key - Amber`, `Cool Fill - Cyan`의 Color / Intensity / Outer Radius.
- 빛 번짐·색감: `Lab Color Grade - Volume`의 Profile. Bloom 0.18, Vignette 0.16. Weight 0으로 색 보정만 끄고 비교할 수 있습니다.
- 공용 PC/Mobile 렌더러는 유지하며, **실험실 카메라만 Renderer [1]**을 사용합니다. 일반 3D Directional Light가 아니라 **Light 2D**를 추가하세요. 새 배경도 Sprite-Lit 재질이어야 빛을 받습니다.
- 별도 `Global Volume`이 있다면 Priority를 확인하세요. 이번 전용 프로필은 Priority 10입니다. 이번 색감은 전용 프로필에서 수정하세요.
- Play 중 변경값은 종료하면 되돌아갑니다. 유지하려면 Edit Mode에서 조절하세요.

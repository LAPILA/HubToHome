# 콘텐츠 메이커 사용법

시작 메뉴: **Hub To Home → 제작 → 콘텐츠 메이커**

왼쪽에서 챕터와 방을 고르고 오른쪽에서 편집합니다. **챕터 (지역)**는 기존 `Regions/Chapter01` 같은 지역 폴더입니다. **방**은 실내만 뜻하지 않으며 마을·들판·던전도 같은 기본 방으로 만듭니다. 대사는 프리팹 안에 쓰지 않고 별도 대화 데이터를 NPC에 연결합니다.

## 정리된 메뉴

| 메뉴 | 하는 일 |
| --- | --- |
| 제작 → 콘텐츠 메이커 | 맵·마커·NPC·대사 만들기와 편집 |
| 제작 → 스킬 메이커 | 기존 스킬·실행 블록 편집, ID·카탈로그 연결 확인 |
| 검사 → 콘텐츠 검사 | 프로젝트 데이터 검사. 수정 명령은 접힌 **고급 유지보수** 안에 있음 |
| 검사 → 맵·마커 검사 | 현재 열린 씬 또는 프리팹의 방·마커 검색과 오류 위치 확인 |
| 도구 → 성장 밸런스 | 성장 수치 분석 |
| 도구 → 저장 데이터 진단 | 저장 슬롯 확인 및 명시적 초기화 |
| 도구 → 공용 전투 프리팹 열기 | 공용 전투 구성 확인 |

모두 `Hub To Home` 아래입니다. **시나리오 메뉴는 그대로**입니다. 쇼케이스·마을·던전·스타터팩 재생성 메뉴와 중복 마커 생성 메뉴는 제거했습니다. 기존 샘플 파일은 삭제하지 않았습니다. 계층에서 바로 배치하려면 `GameObject → Hub To Home → 마커`를 사용할 수 있습니다. 맵 시스템의 구성과 참조는 [Room 맵 시스템](game-design/room-map-system.md)을 참고하세요.

## 편집창 읽는 법

- 상단 세 탭: **챕터 · 방 / 마커 · NPC / 대사 · 화자**. 선택한 탭과 중요한 작업 버튼은 청록색으로 구분합니다.
- 왼쪽 위: **챕터 목록**. 아래에는 맵·마커 탭이면 **방 목록**, 대사 탭이면 **대화 목록**이 나옵니다. 검색은 선택한 챕터의 방·대화를 대상으로 합니다.
- 챕터·방 목록 옆 **+ 추가 / 삭제**: 오른쪽에 생성 또는 삭제 확인 화면을 엽니다. 삭제 버튼을 누르는 것만으로 파일이 없어지지 않습니다.
- 오른쪽: 선택한 작업 하나의 편집 화면입니다. 맵은 **방 설정 / 복제 / 씬 관리**, 대사는 **대사 / 화자·표정 / 조건·NPC / CSV·번역 / 문서** 중 하나를 선택합니다. 고급 이벤트·CSV 서식 도움말만 필요할 때 펼칩니다.
- 아래: **방 검사 결과**와 최근 작업 상태. 긴 경로나 상태 문구 위에 마우스를 올리면 전체 내용을 볼 수 있습니다.
- 창은 최소 880×600 기준입니다. 목록과 본문은 각각 스크롤하며 탭을 바꾸면 본문 상단부터 표시합니다. Unity의 밝은/어두운 테마를 따릅니다.

처음 스크립트가 임포트될 때 스타일 안내가 표시되면 Unity 자산 처리가 끝난 뒤 **화면 다시 불러오기**를 누르세요. 데이터를 다시 만드는 버튼이 아닙니다.

## 지금 Windmill에서 NPC 하나 넣기

1. 왼쪽 챕터 목록에서 `Chapter01`, 방 목록에서 `WindmillExterior` 데이터를 선택합니다.
2. `대사 · 화자` 탭 → 대화 목록 옆 **+ 추가**를 누릅니다. 새 대화 이름을 입력하고 **대화 만들기**를 누릅니다.
3. 화자·표정·본문을 입력합니다. 다음 줄은 **+ 대사**, 순서 변경은 **위로 이동 / 아래로 이동**을 사용합니다.
4. **이 대화 저장**을 누릅니다.
5. `마커 · NPC` 탭에서 **선택한 방 열기**를 누릅니다.
6. 종류를 **일반 대화 NPC**로 고릅니다. 이름과 위치를 입력하고 Sprite 또는 외형 전용 Prefab을 연결합니다.
7. **대사 탭에서 선택한 대화 연결**을 누르고, **선택한 방에 배치**를 누릅니다.
8. 씬 뷰에서 실제 위치와 상호작용 범위를 조절합니다. 상단 **방 검사**를 확인한 뒤 프리팹 편집 모드에서 저장합니다.

NPC Prefab 저장을 켜면 지역의 `Prefabs/NPCs`에 자동 생성됩니다. 배치 Undo는 Room 안의 배치를 되돌리지만 생성한 Prefab 파일은 남겨 둡니다.

## 맵을 새로 만들기

1. Prefab Mode 안이라면 편집을 저장하고 왼쪽 위 돌아가기 버튼으로 나옵니다.
2. `챕터 · 방` 탭에서 챕터를 선택합니다. 새 챕터라면 챕터 목록 옆 **+ 추가**를 누르고 이름을 입력해 만듭니다.
3. 방 목록 옆 **+ 추가**에서 장소 이름과 기본 크기를 입력한 뒤 **방 만들기**를 누릅니다. 마을·던전·실내를 따로 고를 필요는 없습니다.
4. **지형 배치하기**로 열어 임시 바닥을 그림·타일로 교체하고 이동 충돌벽을 배치합니다. 카메라 경계와 기본 시작점은 이미 들어 있습니다.
5. `마커 · NPC`에서 문·NPC·아이템 등을 배치하고 검사·저장합니다.
6. 새 지역이라면 프리팹 편집 모드를 나온 뒤 방을 선택 → **씬 관리**에서 새 씬을 만듭니다.
7. 기존 지역에 방을 추가했다면 **씬 관리**의 기존 씬 등록 작업을 선택하고 해당 지역 씬과 반영 내용을 확인합니다.

기존 Scene 등록은 시작 Room과 기존 목록을 유지하며 새 Room을 합칩니다. 저장하지 않은 변경이 있는 Scene에는 적용하지 않습니다. Scene에 지역 진입 관리자가 없을 때는 유효한 RoomContainer·Player가 각각 하나인 경우에만 기존 초기 Room 설정을 이어받아 연결합니다.

씬은 빌드 목록에 자동 등록하지 않습니다. 실제 빌드에 넣을 때는 Unity의 Build Profiles/Scene List에서 추가합니다. 기존 Room 또는 새 Scene에 전투 호스트가 있어야 심리스 전투가 가능합니다. 양쪽에 중복 배치하지 마세요.

### 폴더는 자동 분류됩니다

| 내용 | 저장 위치 |
| --- | --- |
| 지역 Scene | `Maps/Regions/<지역>/Scenes` |
| Room Prefab | `Maps/Regions/<지역>/Prefabs/Rooms` |
| NPC Prefab | `Maps/Regions/<지역>/Prefabs/NPCs` |
| Room·Area 데이터 | `Maps/Regions/<지역>/Data/Rooms` |
| 지역 대화 | `Maps/Regions/<지역>/Data/Dialogue` |
| 공용 화자·표정 설정 | `Dialogue/Data/Speakers` |

위 경로는 모두 `Assets/_Game/Content` 아래입니다. 기존 파일을 자동으로 이동하거나 덮어쓰지 않습니다.

## 챕터·방 삭제하기

1. 목록에서 삭제할 챕터 또는 방을 선택하고 해당 목록 옆 **삭제**를 누릅니다.
2. 오른쪽에서 삭제 예정 파일과 막힌 연결을 확인합니다. 편집 후라면 다시 검사합니다.
3. 다른 방의 문·씬·데이터에서 사용하는 항목은 먼저 그 연결을 수정하고 저장해야 합니다. 열린 편집 상태나 빌드 씬 등록이 삭제를 막을 수도 있습니다. 창이 표시하는 이유를 확인하세요.
4. 차단 항목이 없을 때만 최종 확인 후 휴지통으로 보냅니다. 삭제 직전 대상과 연결을 다시 검사합니다.

**방 삭제**는 현재 지역의 방 데이터와 전용 지형·구역 데이터만 대상으로 합니다. 연결된 대화·공용 그림·음악까지 따라가서 삭제하지 않습니다. **챕터 삭제**는 선택한 지역 폴더 전체이므로 그 안의 씬·방·대화·메모도 포함됩니다. 미리보기 목록을 확인하세요.

삭제는 일반 필드 편집처럼 Ctrl+Z로 복구하는 기능이 아닙니다. 필요하면 운영체제 휴지통에서 파일과 `.meta`를 함께 복원하거나 버전 관리에서 복구합니다. 다른 파일을 자동 수정해 참조를 끊거나 강제로 삭제하지 않습니다.

검사는 Unity 자산 참조와 프로젝트 원문의 ID·경로 문자열을 확인합니다. 실행 중 조합되는 문자열이나 기존 세이브 파일까지 검증하지는 못하므로 이미 배포한 방·챕터를 삭제할 때는 저장 데이터 호환성도 별도로 검토해야 합니다.

## 문과 시작점 연결하기

1. 도착할 Room에 **도착 시작점**을 배치하고 저장합니다.
2. 출발 방을 열고 다른 방으로 가는 문을 선택합니다.
3. 도착 방과 도착 시작점을 목록에서 선택합니다. 문 사용 방식과 영역을 정해 배치합니다.
4. 왕복하려면 반대편 Room에도 같은 방식으로 문을 만듭니다. 반대편 문은 자동 생성되지 않습니다.

이미 만든 문은 목록에서 선택하여 목적지와 시작점을 다시 고를 수 있습니다. Room을 복제하면 개체 ID는 바뀌지만 원본의 외부 문 연결·조건/완료 플래그·공유 대화는 유지하므로 반드시 검토하세요.

## 대사·화자·선택지 편집하기

처음에는 **대화 문서 만들기 → 대사·화자·표정 입력 → 이 대화 저장 → 마커 · NPC에서 연결**만 진행하면 됩니다. 대화를 선택하지 않았을 때 창에도 같은 3단계 안내가 나옵니다. 엑셀 기능은 나중에 긴 대본을 한 번에 수정할 때 사용해도 됩니다.

- 한 대화 안에서 **+ 대사**, 이동·복제·삭제를 사용할 수 있습니다. 긴 본문은 여러 줄로 입력합니다.
- 화자가 없는 대사는 내레이션으로 사용할 수 있습니다.
- **화자·표정**에서 기존 화자를 선택하거나 새 화자를 만듭니다. 표정 이미지와 말소리를 편집하고 **화자 저장 → 현재 대사에 연결**을 누릅니다. 화면에 표시된 대화 이름·줄 번호가 연결 대상입니다. 다른 줄에 연결하려면 **대사**에서 그 줄을 먼저 선택합니다.
- 선택지에서는 표시 문구, 다음 대화, 진행 플래그, 전투 시작을 지정합니다. 다음 대화가 없고 전투도 아니면 대화가 끝납니다.
- **이 대화 연결 확인**에서 빈 본문·없는 초상화·분기 문제 등을 확인합니다.
- **번역 키 / 고급 이벤트**는 기존 시스템용 설정입니다. 임의 이벤트 문자열을 적는 것만으로 새로운 연출이 생기지는 않습니다. 현재 선택지 문구는 번역 키가 아니라 입력한 문자열을 그대로 표시합니다.

공용 화자나 대화를 수정하면 그것을 참조하는 다른 NPC에도 반영됩니다. 독립 대사가 필요하면 **문서 → 현재 지역에 복제**한 뒤 연결합니다. 이름 변경·대화창 종류도 **문서**에서 편집합니다. 시나리오에서 이름/경로로 참조하는 대화는 이름 변경을 차단합니다. 시나리오 원문을 자동 수정하지 않습니다.

### 진행 상태에 따라 다른 대화 연결하기

1. 기본 대화와 진행 후 대화를 각각 만듭니다. 왼쪽에서 기본 대화를 선택합니다.
2. **조건·NPC**에서 새 조건 문서 이름을 입력해 만듭니다. 선택한 챕터의 `Data/Dialogue`에 저장되며 현재 대화가 기본 대화로 연결됩니다.
3. **+ 조건 추가**를 누르고 플래그 키·비교 방법·비교 값·우선순위·재생할 대화를 입력합니다. 예: `ch01.zev.defeated`, 같음, `1`, 우선순위 `10`, 전투 후 대화.
4. **조건 문서 저장**을 누릅니다. 유효하지 않은 키/대화는 경고합니다.
5. **마커 · NPC**에서 연결할 방을 선택하고 프리팹 편집 모드로 엽니다. Hierarchy에서 해당 일반 NPC 본체를 선택합니다.
6. **대사 · 화자 → 조건·NPC**로 돌아와 **이 조건 문서를 선택한 NPC에 연결**을 누릅니다. 기존 연결이 있다면 교체 확인이 나옵니다.
7. 편집 중인 **방 프리팹도 저장**합니다. 다른 NPC나 다른 방은 자동 수정하지 않습니다.

조건은 GlobalDataManager가 저장한 정수 플래그를 읽습니다. 조건 문서에 키를 적는 것만으로 게임 진행 값이 바뀌지는 않습니다. 선택지의 완료 플래그나 해당 사건의 실행 코드가 값을 변경해야 합니다.

여러 조건이 맞으면 우선순위 숫자가 가장 큰 항목을 쓰고, 동점이면 위쪽 항목을 씁니다. 조건 하나는 플래그 하나의 비교이며 AND/OR 묶음·NPC 위치/출현 일정·메인 연출 실행까지 다루는 문서는 아닙니다.

기존 문서는 **챕터의 조건 목록 / 편집할 조건 문서**에서 선택합니다. NPC에 이미 연결돼 있다면 **이 NPC의 조건 문서 가져오기**를 사용할 수 있습니다. 이 연결 기능은 `NPCMarker` 전용이며 제브 같은 `DialogueBattleNPC`는 기존 이벤트 설정을 사용합니다.

### 대화 후 전투 NPC

종류 **대화 선택지로 전투하는 NPC**를 선택하고 대화와 EnemyData를 연결합니다. 연결된 대사의 선택지에 **전투 시작**이 있어야 합니다. 없으면 창이 경고합니다.

이 유형은 선택지 전투입니다. 제브처럼 자동으로 접근하고 공격한 다음 전투하는 연출을 자동 생성하는 기능은 아닙니다. 복잡한 흐름은 기존 시퀀스 메이커/기존 전투 NPC의 연출 설정을 사용합니다.

외형에는 Sprite 또는 외형 전용 Prefab을 사용합니다. 이미 플레이어·적 제어 스크립트나 Collider가 붙은 전투 Prefab을 외형으로 중첩하면 상호작용이 겹칠 수 있어 차단합니다. 원본 Prefab은 수정하지 않습니다.

## 엑셀로 대사 편집하기

대화만 복제하거나 한 줄을 복제해도 **번역 키는 그대로 공유**합니다. 복제 완료 안내와 본문 아래 경고를 확인하세요. 본문을 고쳤는데 게임에서 기존 문장이 나오면 번역표가 같은 키로 기존 문장을 제공하는지 먼저 확인합니다.

1. 편집할 대화를 선택합니다.
2. **CSV·번역 → 대본 CSV → 현재 대화 내보내기**를 누릅니다.
3. Excel에서 **데이터 → 텍스트/CSV에서 가져오기**로 열고 열 형식을 **텍스트**로 지정합니다. 더블클릭으로 열면 `0012`, 날짜 같은 문장, 긴 숫자가 자동 변환될 수 있습니다.
4. 본문 등 필요한 내용을 수정한 뒤 **CSV UTF-8(쉼표로 분리)**로 저장합니다.
5. 제작창에서 **CSV 검사 / 미리보기**를 누릅니다. 대상 대화, 기존/새 대사 개수, 경고와 내용을 확인하고 **이 대화에 적용**을 누릅니다.

한 파일은 한 DialogueData입니다. **추가 병합이 아니라 선택한 대화 전체를 교체**합니다. 여러 줄 셀·쉼표·따옴표·한글을 지원하며, 잘못된 형식이나 찾을 수 없는 참조는 반영 전에 차단합니다. 미리보기 이후 대상 대사를 수정했다면 다시 검사해야 합니다. 반영 후에는 Undo가 가능합니다.

CSV의 열 제목과 `schema=1`은 유지하세요. `document` 행은 대화창 종류, `node` 행은 대사, 바로 뒤 `choice` 행은 해당 대사의 선택지입니다. 행을 추가하거나 이동했다면 `node`와 `choice` 번호를 0부터 연속 순서로 맞춰야 합니다. 구조 변경은 Unity 창에서 한 뒤 내보내는 방법이 간편합니다.

화자와 다음 대화 참조는 GUID와 자산 경로를 사용합니다. 단순 본문 편집에서는 이 열을 건드리지 마세요. 새 연결은 Unity에서 고르는 것이 안전합니다. **CSV 작성 방법 / 서식 예시**에서 한 줄+선택지 샘플 파일도 받을 수 있습니다.

지원 형식은 Excel에서 편집할 수 있는 CSV입니다. `.xlsx` 직접 읽기나 자동 양방향 동기화는 하지 않습니다.

## 본문 번역 준비하기

1. **CSV·번역 → 번역 준비**에서 지원 범위를 확인합니다.
2. **빈 본문 키만 생성**을 누르면 키가 없는 줄에 고유 키를 넣습니다. 기존 키와 번역표는 바꾸지 않습니다. 생성 후 대화를 저장합니다.
3. **대사 → 번역 키 / 고급 이벤트**에서 해당 줄의 키를 확인하고 복사합니다.
4. **번역표 위치 찾기**로 `Assets/Resources/LocalizationTable.csv`를 찾습니다. `Key`에 동일한 키를, `KR / EN / JP / CN`에 언어별 본문을 작성합니다.
5. 실제 플레이에서 언어 변경·긴 문장·텍스트 태그·빈 번역을 확인합니다.

대본 CSV와 번역표는 별도 파일입니다. 현재는 **본문만 번역 키를 사용**하고 선택지 문구·화자 표시 이름은 원문 그대로입니다. 번역표 로더는 물리적인 줄 단위로 읽으므로 따옴표 안 실제 줄바꿈이 있는 번역 셀을 아직 지원하지 않습니다. 대본 CSV의 여러 줄 셀 지원과 혼동하지 마세요.

생성한 키는 줄 순서·파일명을 바꿔도 유지됩니다. 대사나 문서를 복제하면 번역 키도 공유되므로, 내용이 달라지는 복제본은 키를 비운 뒤 새로 생성하거나 별도 키를 지정해야 합니다. 키 생성만으로 번역 내용이 자동 작성되지는 않습니다.

## 스킬 연결 확인하기

`Hub To Home → 제작 → 스킬 메이커`에서 스킬을 선택하고 **검사 · 시간축**을 봅니다. **ID · 저장 복원용 카탈로그**에서 중복·잘못된 ID와 카탈로그 누락을 기존 콘텐츠 검사 규칙으로 확인합니다. 블록 검사와 별개이므로 둘 다 확인하세요.

**참조 목록 다시 검사**는 현재 파일 목록을 다시 읽고, **프로젝트 콘텐츠 검사 열기**는 전체 검사 창을 엽니다. 검사는 읽기 전용입니다. 새 스킬은 캐릭터의 초기 스킬/스킬 트리에 연결하고 콘텐츠 카탈로그에도 등록해야 저장한 장착 상태를 복원할 수 있습니다. 기존 ID를 바꾸면 이미 저장된 데이터의 호환성도 검토하세요.

## 상점 연결하기

1. 기존 `ShopDefinition`을 복제하고 상점 ID·이름·상품·대화·회복 서비스를 수정합니다.
2. 기본 전체 상점 이미지·BGM을 지정합니다. 대화 주제별 이미지, 이벤트별 이미지 교체·흔들림은 같은 데이터에서 선택적으로 설정합니다.
3. 방을 열고 **마커 · NPC → 상점 연결**에 해당 데이터를 연결합니다. 실제 화면은 기존 ShopSession/ShopUI를 사용합니다.
4. **콘텐츠 검사**에서 `shop.purchase_counter.shared` 경고를 확인합니다. 복제한 상품의 **구매 카운터 Flag**가 원본과 같으면 구매 횟수·한정 재고를 공유합니다. 의도한 공용 재고가 아니면 새 키를 지정하세요. 경고는 자동으로 키를 바꾸거나 저장을 막지 않습니다.

짧은 대사는 상점 데이터의 기본 문구, 긴 대사·분기는 기존 `DialogueData`를 연결합니다. 전체 상점 그림과 `SpeakerData`의 얼굴 초상은 별개입니다. 상세 설정은 [이안 상점 제작 안내](../AIAssets/yjlim/Patchnote/2026-09-08-ian-shop.md)를 참고하세요.

## 저장과 확인

- 방 데이터: **방 설정 저장**. 그림·마커 배치는 **프리팹 편집 모드 저장**.
- 대사: **이 대화 저장**. 공용 화자: **화자 저장**. 조건: **조건 문서 저장**. NPC 연결: **방 프리팹 저장**.
- 상단 **방 검사**는 구성 검사이며 실제 플레이 테스트가 아닙니다. 오류의 **위치** 버튼으로 편집 위치를 엽니다.
- 퍼즐·상점·지름길·별도 공간 마커는 기존 실행 시스템의 참조가 필요합니다. 생성 후 **상세 설정**의 필수값을 채우세요.
- 기존 자료의 자동 이동·삭제·전체 자산 저장·Build Settings 변경은 하지 않습니다. 삭제는 별도의 미리보기/확인 뒤 휴지통 이동이며, Scene 등록과 CSV 반영도 지정한 대상에만 명시적으로 수행합니다.

이번 구현은 정적 C# 컴파일과 코드 검토까지 확인했습니다. 창의 실제 배치, Unity Undo/Prefab 저장 동작, 게임 플레이는 Unity에서 확인해야 합니다.

코드 구조를 공부하려면 [프로젝트 학습 자료 목차](learning/README.md)를 보세요. 자료구조·알고리즘·Unity 실행 흐름·전투·시나리오·에디터·디자인 패턴·실습을 실제 코드에 연결했습니다.

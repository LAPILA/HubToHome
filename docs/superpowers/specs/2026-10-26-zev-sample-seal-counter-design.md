# ZEV 단독 샘플 · 임시 스킬 잠금 · C 반격 연출

상태: 사용자 승인. 2페이즈 직후부터 무작위 3스킬 잠금, 위젤의 정상 행동 2회마다 새 3스킬로 교체하며 전투 종료까지 반복한다.

## 목표와 범위

- BunnySlimeBattleLab에서 토끼 입구 UI만 잠시 숨기고 ZEV 입구만 표시한다. 토끼 데이터·기존 스킬·시나리오는 삭제하지 않는다.
- 기본 위젤 1명과 ZEV 전투를 유지한다. 기존 적 공격·연속 공격·사슬·피해·방어 보상은 변경하지 않는다.
- 개전과 2페이즈 대사만 교체한다. 기존 DialogueData와 한국어·영어·일본어·중국어 번역 키를 사용한다.
- 2페이즈가 시작되면 위젤이 보유한 서로 다른 스킬 중 최대 3개를 무작위로 잠근다. 일반 공격·아이템·Z/X/C 대응은 잠그지 않는다.
- C 성공 연출은 크게 뒤로 밀림 → 위젤 정수배 확대·포커스 → 1초 대기 → 적 앞 접근·공격 → 적 뒤로 돌파 → 기존 양측 복귀로 바꾼다. 반격 피해·자원 보상은 기존 경로에서 한 번만 처리한다.

## 결정과 대안

권장 방식은 기존 세션 flag와 수명 범위를 재사용하는 선택적 잠금 프로필이다. ZEV나 스킬 이름을 공통 전투 코드에 하드코딩하지 않는다. 원본 SkillData/저장 스킬 목록을 삭제하는 방식은 복구와 저장 오염 위험 때문에 사용하지 않는다. 새 Scenario Action을 추가하는 방식은 이번 한 가지 효과에 문법·카탈로그를 확장하므로 사용하지 않는다.

## 소유 경계

### 실험실 진입

`BattleLabEncounterEntry`에 기본 false인 메뉴 숨김 설정을 추가한다. Session의 표시 인덱스와 실제 Encounter 인덱스를 분리해 토끼 항목을 숨겨도 ZEV를 실행한다. 항목 순서·ID·참조는 유지한다. 다른 실험실/본편 진입은 변경하지 않는다.

예상 변경: `Battle/Development/BunnySlimeBattleLabData.cs`, `BunnySlimeBattleLabSession.cs`, `BunnySlimeBattleLabSession.View.cs`, 해당 LabData 자산.

### 임시 스킬 잠금

선택적 프로필은 phase flag, 스킬 수, 대상, 해제 행동 수를 지정한다. 기존 `lab.zev.chain_phase` flag를 관찰하는 전투 수명 범위가 발동과 정리를 맡는다. 잠금 상태는 실제 배우의 전투 중 상태이며 SkillData·장비·저장 스킬 목록을 수정하지 않는다.

확정 정책: 2페이즈 즉시 첫 추첨, 위젤이 실제 행동 2회를 완료하면 새 3개로 교체한다. 이전 3개를 누적하지 않으며 선택 결과가 우연히 같을 수는 있다. 취소/실패/대상 선택·방어 반격만으로는 교체 횟수를 소비하지 않는다. 종료/F8/비활성/씬 이탈에서는 무조건 해제한다. 재진입은 새로 추첨하며 같은 phase flag 통지로 중복 발동하지 않는다.

`BattleMenuEntryPresentation.CanUse`가 회색 표시와 사용 가능 여부를 함께 판단한다. 메뉴 확정·대상 확정·AP 소모 직전에도 차단해 입력 경로 차이와 도중 상태 변경에 대응한다. 잠긴 행은 탐색 가능하며 키보드 확인/포인터 시도에 빨강 좌우 흔들림과 현지화된 '사용 불가'를 표시한다. 원래 색과 위치는 연출 종료/취소/재바인딩 시 복원한다. 실패 시 턴/AP/대상 선택을 소비하지 않는다.

### C 성공 반격

`BattleLinkCounterService`가 연출 전체의 유일한 소유자다. `PositionManager`의 C 전용 수치에 후퇴 거리·포커스 대기·돌파 거리를 노출한다. 기존 취소 세대·자기 Tween 정리·원위치 복구·전경 복구를 유지한다. 1초 대기도 전투 pause와 취소를 따르는 소유 Tween으로 처리한다.

카메라는 기존 `CameraController`를 사용한다. 일반 전투 Lens 고정 규칙은 유지하고 C 성공의 명시적 포커스 범위에만 정수 2배 확대를 허용한다. 임의 연속 Lens나 PixelPerfect 컴포넌트 비활성화는 사용하지 않는다. HUD 배율은 바꾸지 않는다. 범위 종료/취소가 더 최신 카메라 명령을 덮어쓰면 안 된다.

## 검증

- 숨겨진 토끼 항목을 건너뛰어 선택/시작/F8 복귀가 ZEV를 가리키는지 확인한다.
- Source/Runtime ID·hash와 기존 스킬 데이터는 보존한다. 대사 노드/화자/번역 키는 정확히 연결한다.
- 스킬 수가 0~2개일 때 안전하게 처리하고, 같은 스킬은 중복 추첨하지 않는다.
- 잠긴 스킬의 표시·입력 거부·실행 거부·무료 정리와 행동 완료 기반 해제를 관리형 검사로 검증한다.
- C 성공 시 피해/보상 1회, 대기 중 취소·파괴·pause, 돌파 후 복귀, 픽셀 규칙·카메라 소유권을 검사한다.
- 전체 C# CLI 컴파일과 기존 방어·QTE 회귀를 수행한다. 실제 Unity 화면/입력 체감은 별도 검증으로 구분한다.
- 사용자 승인 없이 커밋·푸시·강제 재임포트·Play Mode 전환·씬 재저장은 하지 않는다.

# 공격 준비와 타격의 컷감

사용자 승인: 앞서 제안한 기법 중 기존 코드·아트로 가능한 항목을 적용한다. 카메라는 타격 직전 잠깐 구도를 잡았다가 타격 순간 빠르게 전환되는 느낌이다. 캐릭터만 멈추는 이전 기본 피격 정지는 약화/해제하고 카메라와 음향·정보 표시로 강약을 전달한다.

## 적용

1. 현재 Cinemachine battle shot/token 안에서 준비 구도 hold → 빠른 미세 줌/이동 → 짧은 유지/복귀. 새 게임플레이 대기를 넣지 않는다. 활성 방어창·Timeline·모달은 카메라보다 우선하고 늦은 타격 컷을 큐에 쌓지 않는다. 반복 입력·전체 공격은 카메라 반응만 제한한다.
2. 직접 피격의 Animator 정지는 기본 해제하고 즉시 Hurt/VFX/백색 표시를 유지한다. 옵션 시간은 기존 한글 Odin 필드로 다시 조정할 수 있다. 공격 방향의 짧은 수평 반동을 사용하고 적이 매번 위로 튀는 반동은 제거한다. 처치 시 기존 사망 흐름에 짧은 백색 마무리만 추가한다.
3. HP 숫자/실제 바는 즉시 갱신, 잃은 구간만 잔여 바가 뒤따른다. 연타가 잔여 바 종료를 무한 연장하지 않는다.
4. 상태 부여/해제/빙결 전환의 국소 표시만 보강한다. 단순 상태 틱·동일 Refresh마다 튀지 않는다. 기존 대상 청록 테두리와 현재 행동 노랑 표시는 재사용한다.
5. 기존 타격음을 고정 상한 보이스로 재사용, 같은 순간 중복 소리 제한·작은 음색 변주·처치 강조를 준다. 메뉴·전조·음성·BGM과 내장 패링/가드 소리는 건드리지 않는다.

## 보존·제외

HP/AP/보상·방어 판정/QTE·전조 시계·실제 타수·저장·턴 계산을 변경하지 않는다. HUD는 화면 공간 고정이다. 스킬의 준비/가속/후속 동작은 기존 데이터/클립 소유권을 보존하며 임의로 전체 타임라인을 재작성하지 않는다. 새 스미어/그림자 아트·무기별 신규 녹음·기기 진동과 새 설정 화면은 이번에 만들지 않는다. 새 그림이 필요한 부분은 기존 아트를 늘이거나 AI 이미지로 대체하지 않는다. 입력 예약은 기존 판정/소모 계약을 유지한다.

Unity Play/Refresh/Reimport/열린 씬 저장·실제 save I/O·커밋/push 없이 CLI 컴파일/관리형 검사/소유권 리뷰로 검증한다. 실제 체감은 이 검사로 확정할 수 없음을 남긴다.

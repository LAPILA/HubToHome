# 콘텐츠 메이커

## 승인 범위

사용자는 맵·마커·NPC·대사를 초보자도 만들고 관리하는 통합 제작창과 폴더 자동화를 요청했다. 대사 입력 방식 질문에는 창 내부 편집과 엑셀용 CSV 가져오기·내보내기를 모두 포함하고 세부 판단을 위임했다. 별도 승인 질문, 커밋, Play Mode 실행은 하지 않는다.

## 방향

`Hub To Home/제작/콘텐츠 메이커`를 지역 중심의 단일 진입점으로 제공한다. 단순 샘플 메뉴 모음은 덮어쓰기 위험 때문에 제외하고, 새 런타임/타일맵 에디터는 중복이므로 만들지 않는다. 기존 Room Prefab/RoomDefinition/AreaDefinition, NPCMarker/DialogueBattleNPC, DialogueData/SpeakerData를 편집한다. 복잡한 연출은 기존 시퀀스 메이커에서 계속 작성한다.

## 제작 흐름

1. 지역 선택 또는 생성. 현재 Chapter01 구조를 기본값으로 사용한다.
2. Room 신규 생성/복제: Prefab, Definition, Area와 폴더를 자동 생성한다. 시작점·카메라 Bounds 포함. 지역 씬 생성/Room 목록 등록은 명시적 대상과 버튼으로 실행하며 기존 씬을 자동 교체하거나 Build Settings를 수정하지 않는다. 기존 목록과 시작 Room은 보존하며 대상 씬이 dirty하거나 구성이 모호하면 등록을 차단한다.
3. Room을 Prefab Mode에서 열어 지형을 꾸민다. 제작창에서는 시작점·문·NPC 등 실제 컴포넌트를 배치하고 수정한다.
4. NPC 외형과 실제 DialogueData 참조를 연결한다. 일반 대화와 대화 후 전투 유형을 구분한다. 외형 공용 Prefab은 수정하지 않는다.
5. 대사는 화자/표정/여러 줄 본문/선택지/다음 대화를 창 안에서 편집한다. 공용 화자·초상화를 선택/생성/편집한다.
6. CSV는 엑셀에서 수정할 수 있는 명시적 가져오기/내보내기다. `.xlsx` 자동 동기화는 아니다. 한 대화 문서를 순서대로 교체하는 방식이며 행 단위 자동 병합을 하지 않는다. CSV 전체 검증과 변경 미리보기 후 한 번에 적용하고 실패하면 기존 데이터를 보존한다. 따옴표·쉼표·셀 내부 줄바꿈·한글을 보존한다.
7. 기존 RoomMapValidationScanner를 재사용해 오류 목록과 선택/포커스를 제공한다.

## 관리·안전

- 새 자산은 `Regions/<지역>/Scenes`, `Prefabs/Rooms`, `Prefabs/NPCs`, `Data/Rooms`, `Data/Dialogue`로 분류한다. 공용 화자는 기존 `Content/Dialogue/Data/Speakers`에 둔다.
- 이름 변경은 AssetDatabase API를 사용하며 Room ID/참조는 보존한다. 기존 자산을 자동으로 이동·삭제하지 않는다.
- 복제 Room은 새 Room/Area/Marker/NPC ID를 부여하며 공유 대화·캐릭터 참조는 유지한다. 문 연결은 새 문서 기준으로 검토하게 한다.
- 생성 경로 충돌은 차단/고유 경로로 해결한다. 기존 샘플 재생성 메뉴는 호출하지 않는다.
- 배치는 현재 선택한 Room의 편집 컨텍스트에만 허용한다. 다른 Prefab/Scene을 암묵적으로 수정하지 않는다.
- 필드 편집과 배치에 Undo를 지원한다. Asset 저장은 대상 한정이며 전체 SaveAssets/Refresh를 호출하지 않는다.
- 런타임 구조와 공개/직렬화 필드는 유지한다. 새 코드는 Editor 폴더에 한정한다.
- Prefab Mode에서는 새 Room/지역 Scene 생성과 기존 Scene 등록을 차단한다. 먼저 해당 편집을 마친 뒤 Main Stage에서 생성한다. 현재 Room 마커 편집과 안전한 Prefab 복제는 별도 작업이다.
- 시나리오의 대화 매핑에 이름/경로로 쓰이는 DialogueData는 이름 변경을 차단한다. Runtime/Scenario Source를 자동 갱신하지 않는다.

## 검증

정적 C# 컴파일, CSV round-trip/오류/참조 검증 및 경로 정책의 테스트 코드 검토, diff 점검을 수행한다. Unity Editor 실행/자동 Play Mode/자동 씬 저장은 하지 않는다. 사용자 확인 경로는 제작창 내부 도움말과 짧은 가이드에 남긴다.

## 후속 요청 — 메뉴 정리·한글화

사용자가 시나리오를 제외한 도구 취합과 불필요한 장소별 생성 기능 정리를 요청했다. 기존의 세부 판단 위임에 따라 별도 승인 질문 없이 범위를 좁혀 적용한다.

- 단순 분류명 변경만으로는 중복 생성기가 남고, 생성기 코드 자체 삭제는 기존 개발 도구/테스트 호출을 끊는다. 따라서 제작 진입점은 콘텐츠 메이커로 통합하고 레거시 샘플 생성기의 메뉴 등록만 제거한다.
- 상단 메뉴는 제작(콘텐츠 메이커), 검사(콘텐츠 검사, 현재 편집 범위 맵·마커 검사), 도구(성장 밸런스, 저장 진단), 공용 전투 프리팹 열기 중심으로 정리한다. 시나리오 메뉴와 내부 구현은 변경하지 않는다.
- 기본 방 생성은 장소 이름과 크기만 받는다. 마을·던전·실내는 동일한 방의 지형을 꾸며 제작하며 별도 샘플 생성 옵션을 노출하지 않는다.
- 검사와 자동 수정은 계속 구분한다. 유지보수 버튼은 콘텐츠 검사 창의 기본 접힌 영역에 모으며 기능을 실행하지 않는다.
- 기존 마커 작업창은 전체 로드 씬/프리팹 검사 범위가 있어 보존하고 검사 메뉴로 이동한다. 계층 우클릭 마커 생성은 다른 작업 위치의 단축 동작이므로 한글화하여 유지한다.
- 한글화는 화면 문자열과 메뉴 경로에 한정한다. 파일명, GUID, 직렬화 필드, ID, CSV 계약, 기존 자산 및 런타임 동작을 바꾸지 않는다. 자산 생성 메뉴도 시나리오를 제외하고 Hub To Home으로 통일한다.
- 기존 메타데이터 오류 교훈을 반영해 검증은 정적 C# 컴파일과 실제 Unity 입력/메타 검사를 구분한다. 강제 Refresh, Play Mode, 커밋/푸시는 하지 않는다.

## 최종 화면 정돈

사용자는 기존 콘텐츠 메이커를 예쁘게 정돈하고 마감하도록 요청했다. 이미 위임한 기능/메뉴 범위를 유지하며 추가 승인 질문이나 별도 웹 시안 없이 실제 Unity 편집창을 수정한다.

- 기존 스타일의 간격만 조정하는 것보다 탐색/편집/보조작업의 위계를 분리한다. 전체 UI Toolkit 전환은 기존 IMGUI/Odin 편집 동작을 바꿀 위험이 있어 이번에는 하지 않는다.
- UI Toolkit 외곽은 테마 대응 배경, 제목과 보조 동작, 청록색 선택 탭, 목록 개수/빈 상태, 구분된 편집 영역과 하단 상태를 제공한다. 경로는 툴팁을 포함한 보조 정보로 표시한다.
- IMGUI는 공용 카드/제목/본문/버튼 스타일을 사용한다. 생성/배치/저장은 강조하고 파일 관리/고급 설정은 접는다. 기존 캡션과 데이터 변경·검증 계약은 유지한다.
- 880×600 최소 창에서 목록/본문이 독립적으로 스크롤되고 고정 폭 라벨이 입력란을 밀어내지 않게 한다. 긴 이름/경로는 말줄임 또는 줄바꿈으로 처리한다.
- 공용 스타일은 메이커 범위로 제한하고 다른 Unity 창의 전역 GUI 스타일을 바꾸지 않는다. GUI 상태는 IDisposable로 복원하며 스타일/텍스처를 매 프레임 새로 만들지 않는다.
- 시나리오와 런타임/자산 데이터는 변경하지 않는다. Unity 창 캡처/실제 UI 조작은 현재 도구에서 하지 않으며 정적 컴파일·메타·레이아웃/수명주기 코드 리뷰를 검증 범위로 명시한다.

## 후속 요청 — 목록 기반 추가·삭제

- 챕터는 새 데이터 형식이 아니라 기존 `Regions/<지역>` 폴더를 가리키는 화면 명칭이다. 챕터 목록과 현재 탭의 방/대화 목록을 나누고 선택한 항목의 편집 화면만 표시한다.
- 챕터/방 목록의 추가·삭제 버튼은 오른쪽 작업 화면을 연다. 방 설정·복제·씬 관리도 접기/펴기 대신 선택 전환하며 기존 생성·저장 기능은 보존한다.
- 삭제는 명시적 미리보기와 확인 후 휴지통 이동만 허용한다. 챕터 루트 경계, 방 전용 자산, 외부 참조, 열린 편집 상태 및 빌드 등록을 검사하고 실행 직전 재검사한다. 연결 자동 해제나 공유 대화/아트의 연쇄 삭제는 하지 않는다.
- 대사 탭은 대화 문서 생성 → 대사/화자/표정 편집 → NPC 연결의 시작 안내를 정돈한다. CSV와 런타임 계약은 변경하지 않는다.
- 구현 과정에서는 실제 콘텐츠를 생성·삭제하지 않는다. 자동 Unity 테스트와 Play Mode 없이 정적 컴파일/메타 및 경로·선택·삭제 흐름 리뷰로 확인한다.

# 적 근접 참격 · 돌파 연출

## 합의한 범위

- 적 중심 구도 → 짧은 준비 정지 → 빠른 접근 → 타격 지점에서 기존 피해 적용 → 아군 뒤로 짧게 통과 → 기존 복귀.
- 제브의 빙섬·연쇄 참격 두 스킬에만 먼저 적용한다. 원거리·광역·C 반격은 기존 연출을 유지한다.
- 사용자는 돌파 거리와 화면 연출의 세부 판단을 위임했다. 전투 규칙, 전조, 입력 창, 피해/상태 계산은 변경하지 않는다.

## 기존 소유권을 따르는 구현

- 기존 `Action_DefenseWindow`의 선택 옵션이다. 별도 Scenario Action ID나 전역 시간 조절을 추가하지 않는다.
- 접근 DOTween은 기존 QTE의 authored attack time으로만 이동한다. 회피 중인 대상을 추적하지 않고 최초 목표 지점을 보존한다.
- 결과 시점에 접촉 지점을 고정한다. 실제 피해 소비자가 실행된 뒤 기존 `WaitForPendingDefenseReaction`에서 0.09초 후속 이동을 소비한다.
- 가드/저스트가드 성공은 접촉 지점에서 멈춘다. 실패·회피만 통과한다. C는 선택 옵션과 무관하게 제외한다.
- `SkillContext`가 이동·잔상·전용 카메라 범위를 소유한다. 취소·교체는 자신의 Tween만 종료하고, 현재 범위일 때만 준비 위치를 복구한다.
- 카메라 범위는 기존 명령 토큰을 사용한다. 실제 방어 입력 구간에서는 고정, 이후 짧은 방향 이동/줌 후 기존 교전 구도로 복귀한다. HUD는 움직이지 않는다.
- 기존 Windup이 Ready를 이미 표시했어도 해당 카메라의 진입 시간만큼 판정창 전 준비를 보장한다. 준비 모션은 다시 재생하지 않는다. 판정 창 길이는 바꾸지 않는다.

## 검증과 제한

- 순수 이동 경로·시계·유한 입력·역방향을 관리 코드로 검사하고 전체 Runtime/Editor를 CLI 컴파일한다.
- 기존 두 스킬 외 방어 블록은 기본 해제를 확인한다.
- Unity Play/Refresh/Reimport/씬 저장은 하지 않는다. 실제 화면 속도감·프레임은 엔진 확인 전까지 미검증이다.

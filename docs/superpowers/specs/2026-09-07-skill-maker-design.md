# 스킬 메이커 편집 화면

## 승인된 범위

사용자는 전용 창의 ‘왼쪽 검색·스킬 목록 / 오른쪽 기본 정보·블록 편집·검사 결과’를 선택했다. 기존 SkillData와 SerializeReference ActionTimeline을 직접 편집한다. 다른 데이터 모델이나 런타임 실행기를 만들지 않는다.

## 화면과 조작

- 메뉴: Hub To Home / 제작 / 스킬 메이커. 기존 Create 메뉴는 보존한다.
- 콘텐츠 메이커의 회색·청록 테마, 밝은 테마, 목록/버튼 스타일을 재사용한다.
- 왼쪽: 이름·ID·경로 검색, 전체/아군/적/공용 필터, 선택 가능한 스킬 목록.
- 오른쪽: 선택 스킬 요약/경로, 기본 정보·실행 블록·검사 탭. 접기 목록 대신 실행 블록을 선택해 세부값을 편집한다.
- 새 스킬/스킬 복제는 저장 경로를 사용자가 선택할 때만 실행한다. 기존 데이터의 경로·ID를 자동 변경하지 않는다. 복제본에는 중복되지 않는 ID를 준다.
- 블록 추가/복제/삭제/순서 이동은 Undo 가능해야 한다. 중첩 데이터 복제는 원본과 참조를 공유하지 않는다.
- 저장 버튼은 선택 자산만 저장한다. 자산 선택 변경이나 창 닫기로 수정 내용이 조용히 사라지지 않도록 실제 자산을 편집하고 dirty 상태를 표시한다. Unity Undo를 사용하며 전체 프로젝트 SaveAssets를 호출하지 않는다.
- 기존 EnemyAttackAuthoringAnalyzer 결과와 시간축을 읽기 전용으로 보여 준다. 편집기는 시간축의 고정/가변/미지원 의미를 구분한다. 기존 검사에서 탐지하지 않는 게임 규칙 문제를 해결했다고 주장하지 않는다.
- 빈 목록/필터 결과 없음/누락 블록/외부 삭제/Undo와 프로젝트 변경을 안전하게 처리한다. Play Mode에서는 편집을 잠근다.

## 소유권·성능

Window는 탐색/레이아웃, AssetUtility는 명시적 생성/복제, BlockEditor는 Odin 기반 직렬화/Undo/블록 목록 편집을 맡는다. 스타일은 USS로 분리한다. 모든 새 코드는 Editor 경로에 위치한다. 자산 스캔과 검사 결과는 변경 이벤트에서 갱신하고 OnGUI마다 전체 검색하지 않는다. PropertyTree는 선택 대상별로 캐시하고 Dispose한다.

## 제외 및 검증

전투 규칙/피해/방어 수치, 기존 SkillData·프리팹·씬·카탈로그는 자동 수정하지 않는다. 실제 전투 미리보기/자동 Play/강제 Refresh/테스트 실행/커밋·푸시는 하지 않는다. 회귀 테스트 소스, 정적 Runtime+Editor 컴파일, UTF-8 및 diff 검사를 수행한다. 실제 Unity 창의 시각 확인은 미실행으로 명시한다.

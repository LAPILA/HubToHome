# 공통 명중 피드백

후속 사용자 승인으로 기본 피격 정지 수치는 [준비–명중 카메라 컷 설계](2026-10-23-battle-impact-cuts-design.md)로 대체한다. 이 문서는 초기 설계 기록이다.

사용자 승인: 모든 공격의 실제 피해 확정 순간에 쾌감을 강화하고 바로 적용한다. 앞서 설명한 짧은 정지·백색 표시·후속 반동을 기존 구현에 통합한다.

- 직접 명중: HP/숫자/효과음은 즉시, 백색 실루엣과 기존 Hit VFX도 즉시 표시한다. 대상 Animator만 기본 0.045초, 최대 HP 10% 이상 피해는 0.065초 멈춘 뒤 Hurt/반동으로 풀린다.
- 0.12초 안의 재명중은 0.016초 정지와 짧은 점멸로 제한한다. 동일 갱신 사이의 여러 명중은 남은 정지를 연장하지 않는다. 피해 횟수·합계는 병합하지 않는다.
- 상태 피해는 새 정지를 만들지 않는다. 진행 중인 직접 피격 표시를 취소하지 않고 실제 HP/상태 피해 이벤트만 처리한다. 사망은 기존 정리를 우선한다.
- 실제 양수 피해만 반응한다. 순수 피해 0/음수는 HP·피격 이벤트를 바꾸지 않는다.
- 공격자 이동/공격 시계, 전조/방어/QTE, 전역 Time.timeScale, 음악/HUD/카메라는 변경하지 않는다. 새로운 관리자를 추가하지 않는다.
- 기존 개별 재질 재사용, 접근성 설정, Tween/Animator 소유권 및 disable/destroy/새 모션 취소 계약을 유지한다. 수치는 CharacterHitFeedback의 한글 Odin 필드로 조정 가능하게 한다.

검증: Unity를 실행하지 않는 전체 C# 컴파일, 생산 수명 코드의 관리형 검사, Editor 회귀 테스트 소스 보강과 독립 검토. 실제 타격 체감/GPU/기기는 이 검증으로 확정하지 않는다.

# 제브 사슬 난무 설계

사용자 승인(2026-10-26): 실험실 제브2페이즈 첫 정상 공격 뒤 다음 자기 행동에1회, **가속 왕복10회→공중2회→가속/공중 무작위8타→최종C전용 대검격**. 완료 뒤 C성패와 무관하게 다음 자기 턴1회 탈진. 최초 제안10초는 타수 증가에 따라 늘어나며 판정 신호의 읽기 가능성을 우선한다.

## 범위와 기존 계약

Lab 전용 `Zev_ChainFrenzy.asset`/ID `lab.showcase.zev.chain_frenzy`를 만들고 기존 원본5스킬/본편DB는 보존한다.2페이즈는 기존 Scenario의 `lab.zev.chain_phase` 플래그가 소유한다. 새 EnemyData 선택적 후속패턴은 플래그에 반응하는 로컬AI 정책일 뿐 HP/시나리오 전환을 판단하지 않는다. Source 문법/ActionLibrary 재생성은 하지 않는다.

## 선택·완료·탈진

EnemyData.FollowupPatterns는 RequiredBattleFlag/RequiredFlagValue/NormalActionsBefore/Skill/OncePerBattle를 선언한다. 실제 행동 시작의 플래그를 캡처하고 정상 완료된 일반 공격만 누적한다. 제브의 Lab패턴은 chain_phase=true 이후1회 완료에서 준비되고 다음 자기 행동에 발동한다. 기존 순환 스킬 index는 추가로 소비하지 않는다. 취소/도주/씬 종료/선택 실패는 완료나 사용으로 기록하지 않는다.

SkillData.RecoveryTurns 기본0/새 스킬1. 정상 완료와 C성공에 의한 정상 반격 중단 모두 후속 회복턴을 예약한다. 다음 자기 턴을 정확1회 건너뛰며 상태이상 저항/면역과 무관하다. 기존 기절/빙결과 혼동하지 않고‘탈진으로 휴식’기록을 표시한다. 전투 밖 저장에는 기록하지 않는다.

## 재사용 연속 공격 블록

EnemyOnly `Action_EnemyAssaultCombo`가 단계 목록을 소유한다. GroundRush/AerialDive/Mixed, 타수, 시작/끝 판정시간·관통시간·진입시간·준비시간, 타격배율, 공중높이, 무작위 비율을 데이터로 편집한다. Lab단계 타수10/2/8. 매 타격은 기존 Action_DefenseWindow와 기존 Action_Damage를 실행해 단일 피해/전조/후한 입력 판정·가드65%/AP보상/상태를 유지한다. 적QTE는 없다.

기존 적 근접 표시 scope에 선택적인 공중 진입 높이와 가드 후에도 관통하는 연출 옵션을 추가한다(기본0/false로 기존 스킬 유지). DOTween/실제 방어 시계를 공유하고 임의로 전역시간을 바꾸지 않는다. 이동 중에만 잔상, 원본 크기 실루엣/실제명중점멸, 고정PP카메라/HUD 유지. 취소·사망은 자기 이동/잔상/카메라·방어만 정리한다.

후속 가속 수정: 지상/공중/혼합의 관통 시간을 `.60→.16 / .16→.13 / .13→.08초`로 연결해 단계 경계에서 역감속하지 않는다. 같은 폭의 처음/마지막 속도 비율은7.5배다. 판정·준비 시간도 단계 경계에서 늘리지 않으며, 공중 진입만 별도 상승 시간을 둔다. 프레이밍 실패 시 Local에도 가속값을 전달하고, 보간 끝점의 최소값 오차로 ScreenWide가 fallback되지 않게 한다. 전조/방어 판정 규칙과 반응 완료 대기는 유지한다.

## 끊김 없는 연속 이동

후속 무정지 수정: Combo의 선택적 `ContinuousMotion`(기본false/Labtrue)은 매타 준비/감속/접점 고정을 반복하지 않는다. 이동 접점에서 기존 방어를 열고 늦은 입력 유예 중에도 관통하며, 결과에 맞춰 과거 접점으로 되감지 않는다. 반응 완료는 전체 난무 끝으로 지연하고 취소 시 복원한다. 마지막C는 이 모드 밖에서 기존 읽기 시간을 유지한다. 일반 모드의 판정/준비 수치는 연속 모드에서는 대기로 사용하지 않는다.

## 최종 대검격

DefenseRequirement.CounterOnly=7을 append하고 기존0..6 의미는 바꾸지 않는다. 일반 Counterable6의 X/C는 유지하며 새7만C전용이다. 신호/힌트/판정/반격서비스를 같은 규칙으로 갱신한다. 충분히 읽을 수 있는 최종 예고 뒤 충돌시키고 성공하면 기존 한 명 C 반격을 실행한다.

`Assets/_Game/Content/Characters/Prefabs/Enemy/Zev.prefab`는 캐릭터가 아닌 검격 ParticleSystem VFX이다. 최종 공격의 애니메이션 시작/충돌 수명에 연결해 C성공에도 누락되지 않게 한다. 정상 AutoDespawn과 풀 반환을 사용하고 취소·씬 전환에서는 소유 효과를 정리한다. 프리팹의 ParticleSystem Destroy stopAction은 풀 수명과 충돌하지 않도록 좁게 정리할 수 있다. 새 텍스처/RT/카메라/외부플러그인 수정은 없다.

# 동료 간격·재출발과 관람 가시성 후속 설계

사용자 승인: 2026-10-27 ‘넓은 간격 + 차례로 출발’. 기존 동행 설계의 소규모 후속이다. 첨부 Reddit 글은 과거 좌표를 뒤에서 재생하는 아이디어 참고이며 델타룬 내부 구현의 확인 자료로 취급하지 않는다.

## 결정

- 기본 간격을48원본픽셀(1.5unit)로 넓힌다. 기존 `_spacing` 직렬화 값을 보존하므로 직접 지정한 값은 덮지 않는다.
- 정상 Follow 동료는 앞 동료의 경로 커서를 기준으로 간격을 유지한다. 정지 후에는 목표가16픽셀(0.5unit) 이상 앞서야 출발한다. 임계값은 Inspector에서 변경하며0이면 기존 즉시 출발이다.
- 이동 중에는 임계값을 다시 적용하지 않는다. 남은 거리에 비례해 기존 따라잡기 상한(1.5배) 안에서 속도를 조절하여 급격한 상한 전환을 없앤다.
- 재출발 의도는 표시용 IsMoving과 분리한다. 메뉴/대화 중 StopFollowingAnimation이나0 delta는 진행 중 추종을 취소하지 않는다. Hold/Detached→Follow 명시 복귀는 작은 잔여거리도 소진하며, 실제 목표에서 자연 정지한 뒤에만 임계값을 다시 적용한다.
- 앞 동료가 Hold/Detached/연출 이동이면 기존 리더 기준 슬롯 목표를 사용한다. 실제 파티 재정렬/자동 길찾기/벽을 가로지르는 위치 보간/시간 기반 입력 복사는 추가하지 않는다. 정수 픽셀 간격과 float 오차 보정은 유지한다.
- 관람은 기존 정상 기능을 유지하되 Exhibition 출발 영역을 양쪽 입구와 통행 영역을 포함하도록 넓힌다. 입장 후 탐색이 허용되면 두 동료가 안전 경유점으로 이동한다. 두 영역은 하나의 Room 안에만 유효하며 다른 방·저장·진행 플래그에는 영향이 없다.
- 최종 관람 도착 검사는 IsHolding만 보지 않고 빈 LastError·최종 위치·상호작용 가능 상태를 함께 확인한다. 안내 문구의 ‘중앙’ 조건도 실제 입장 동작과 일치시킨다.

## 검증

실제 생산 Controller/Actor의48px간격·순차 시작·정지/재출발·Hold 건너뛰기·코너 경로·0할당 회귀, 관람의 좌/우 입장·우회/정지·최종 위치·오류 확인, 전체 Runtime/Editor 컴파일을 수행한다. 사용자 열린 씬을 저장하거나 강제 Play/Refresh하지 않는다. 실제 화면 검증과 수치/관리형 검사는 구분한다.

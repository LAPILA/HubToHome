# 필드 메뉴: 소형 배치와 통일된 조작

## 승인된 범위

사용자의 2026-10-19 승인에 따른다. 기존 640×480 출력 안에서 메뉴를 592×416 전후로 재배치하며 글자까지 비정수 배율로 축소하지 않는다. 하단 여백을 확보하고 긴 본문·목록·트리는 스크롤한다. 기존 한국어·영어·일본어·중국어 현지화 경로를 유지한다.

## 입력과 소유권

- 방향키·확인·취소만으로 탭, 분류, 동료, 목록, 능력치 편집, 적용, 초기화, 설정에 도달한다. Q/E/C/R은 선택 단축키다.
- 표시 중 유효한 조작을 메뉴 내부 포커스로 추적한다. 표시 순서·게임 규칙·저장 소유자는 변경하지 않는다.
- 설정은 메뉴 위 모달로 열고 닫으면 원래 포커스와 미확정 배분을 유지한다. 설정 입력은 기존 ConfigPanelUI에 위임한다.
- 마우스·터치는 메뉴와 설정 한정 포인터 브리지를 사용한다. 공용 EventSystem의 다른 화면 클릭은 켜지 않는다. 모달·닫기 애니메이션·숫자 편집의 입력 중복을 방지한다.

## 표시와 자원

메뉴를 그리기 전 한 번 저해상도로 캡처한 배경만 흐리게 하고 어두운 막을 겹친다. 추가 카메라·상시 후처리·매 프레임 캡처는 사용하지 않는다. 캡처 실패·셰이더 누락·비활성화 시 어두운 막으로 대체하고 소유한 Texture/Material만 해제한다. UI와 글자는 흐리게 하지 않는다.

안전 영역과 OS 숫자 키보드 영역은 구분한다. 숫자 편집 중 필드가 키보드 위로 드러나도록 일시 배치하며 편집이 끝나면 원래 위치로 복구한다. 확정 전 능력치는 기존 초안만 변경한다.

## 정리와 검증

메뉴 전용 코드와 meta만 UI/Runtime/FieldMenu로 모은다. 타입명·GUID·직렬화 필드를 유지하고 공통 입력/viewport/설정 코드와 플러그인은 이동하지 않는다. 출처 기록이나 Git 이력은 지우지 않고 임시·본편 구분을 명확히 한다.

CLI 컴파일과 방향 탐색·종료/모달·배치 경계를 검사한다. Unity Play/Refresh/씬 저장은 하지 않으므로 실기기 터치·OS 키보드·최종 화면은 미검증으로 보고한다. 커밋/푸시는 하지 않는다.

# 설정 저장과 진행도 저장 및 장비 일관성

사용자가 승인한 기본 흐름은 저장 오브젝트 상호작용 수동 저장과 지정 이벤트 자동 저장이다. 환경 설정은 진행도 슬롯과 무관하다. 기존 데이터 ID, 슬롯 번호, 스키마 v4, 씬/프리팹 연결을 유지한다.

## 설정

변경은 즉시 반영하고 마지막 변경 0.5초 뒤 PlayerPrefs를 기록한다. 닫기, 앱 일시 중지, 종료 때 남은 변경을 기록한다. X는 뒤로가기이며 변경 취소가 아니다. 창 크기 적용은 데스크톱 전용이다. 모달 입력/시간 복구는 해당 설정창 소유 상태에만 적용한다.

## 진행도

- 수동 슬롯 0~2: SavePoint 또는 SavePointMarker 상호작용에서 기존 대화 선택창으로 칸을 고른다. 자동 슬롯은 수동 목록에 넣지 않는다.
- 자동 슬롯 99: ProgressSaveTrigger의 명시적 요청만 처리한다. 전투/보상/대화/설정/씬 이동이 끝나고 탐색 상태가 두 프레임 유지될 때 필드 좌표를 캡처한다.
- 자동 요청 중복은 합친다. 새 게임/로드/전역 데이터 파괴 시 취소한다. 로드가 자동 저장을 유발하지 않는다.
- 필드 저장은 복사본에 현재 좌표와 씬을 넣고 이전 입구 ID를 비운다. 저장 실패가 원본 메타데이터·장비·HP/AP를 변경하지 않는다.
- 본 파일 → 백업 → 임시 파일 복구 순서 유지. 미래 버전 본 파일의 덮어쓰기를 거절한다. 백업은 원자 교체 전에 삭제하지 않는다.
- 타이틀 기본 이어하기에는 최근/수동/자동 선택을 연결한다. 기존 고정 슬롯 설정은 유지한다. 타이틀에 대화 패널이 없으면 기존 최근 기록 로드로 호환한다.

## 장비

조회는 저장 데이터를 정규화하지 않는다. 장착 명령은 소속 파티, 카탈로그 등록, 슬롯, 제한 캐릭터, 수량을 검사한다. 전투 중 변경은 거절한다. 인벤토리는 장착분을 포함한 총수량이며 제거할 때 장착 수량을 보호한다. 변경 시 현재 HP/AP는 유지하되 낮아진 상한까지만 자른다. 자동 회복/부활은 없다. 기존 6슬롯과 저항 배율 계산은 유지한다.

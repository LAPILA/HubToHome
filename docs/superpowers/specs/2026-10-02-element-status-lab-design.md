# 토끼 슬라임 속성 실험실

사용자 승인: BunnySlime BattleLab에 위젤 3명(원본·청록·보라), 각 6스킬, 다섯 누적 상태·소비·정화·연타 테스트를 구현한다. 3+3 전멸 실습, 기존 일반 버프, 기존 전투·입력·시나리오를 유지한다. 저장 파일 I/O와 본편 위젤 변경은 제외한다. 첨부 2026-10-02 텍스트가 이전 피드백보다 우선하며 Frozen은 턴과 실시간 방어 모두 차단한다.

## 구현 경계

- CharacterBase가 소유하는 ElementalStatusState에 다섯 값과 소수 축적, Frozen, CC 재적용 제한을 둔다. 기존 N턴 StatusEffect는 유지한다. 기존 Burn/Freeze/Bleed/Poison 샘플은 호환 경로이며 새 실험실은 새로운 누적 상태만 부여한다.
- ElementalStatusProfile 데이터가 SDU/계수/상한을 정의한다. CharacterData와 EnemyData가 프로필을 참조한다. 공유 ScriptableObject에 현재 수치를 저장하지 않는다.
- 기본 SDU=3, 화상99/냉기10/감전999/출혈99/중독99. null 프로필도 이 기본값을 사용한다. Configure는 프로필만 교체하며 진행 중 누적값을 초기화하지 않는다.
- Direct Hit는 CharacterBase.TakeDamage의 기존 피해 경로를 유지하고 냉기 취약/파쇄 및 감전을 추가한다. 상태 피해는 별도 경로로 DEF/속성 저항/회피 무적을 우회하고 재귀/파쇄를 유발하지 않는다.
- SkillData의 상태 부여 목록은 OncePerSkill(대상마다 한 번) 또는 PerHit. SkillContext가 성공한 타격에만 부여한다. 일반 방어는 부여량 0.5, 완전 방어는 0. 직접 피해 뒤 기존 감전 반응, 그 뒤 신규 상태를 적용한다. 50타는 명시적 발동 계수 0.1을 사용한다.
- 화상: 대상 턴 종료 Value×SDU 후 -1. 출혈: 실제 공격/스킬 완료 Value×SDU×1.2 후 -1. 중독: 턴 종료 floor(Value×SDU×0.2) 후 +3. 냉기: 직접 피해 +1%/Value, 10에서 Frozen; 다음 직접타격 ×1.5 파쇄 또는 자기 턴 1회 스킵. 감전: floor(Value×SDU×0.02×Proc), 소수 피해 누적, 매 Hit ceil(Value×0.01) 방전. 감전으로 감전 재발동 금지.
- Frozen 해제 뒤 실제 행동 1회 완료 전 재빙결 금지(냉기 9 한도). Frozen 중 축적하지 않음, 초과량 버림. 정화는 값·소수·빙결 제거. 전투 종료는 전부 초기화. 예고는 라이브 상태를 Tick하지 않는다.
- 빙결 생성 시 냉기=0. 다음 Hit만 파쇄하며 상태 피해는 제외한다. CC 회복 잠금은 실제 아이템 행동으로도 끝나지만 아이템은 신규 출혈을 발동하지 않는다. 감전 타격 발동 계수는 감전 추가 피해 전용; 50타 예제의 상태 부여는 별도 0.2/타이다.
- 설명은 TMP 색 태그 + 한국어 키워드, HUD는 상태명 약자/색/수치 하나. 색만으로 식별하지 않는다. 별도 상세창 없음.
- 기본 실험실은 기존 6명 중 앞 3명을 사용하고 후열 실습만 6명을 사용한다. 시작 메뉴 및 전투에서 식별할 수 있는 색을 적용한다. 시나리오 YAML/대화/카메라 흐름은 수정하지 않는다.

## 검증

순수 수치/Editor 검사 및 C# 컴파일, 참조/GUID 검사. 사용자가 수행할 Unity Play를 자동 실행하지 않는다. 저항 0/0.5, 파쇄 단일 발동, 50타, 완전 방어 상태 0, DOT 무적 우회, CC 스킵, 정화, 재시작/파티 복구를 검사한다. 테스트 수치는 제품 밸런스 확정값이 아니다.

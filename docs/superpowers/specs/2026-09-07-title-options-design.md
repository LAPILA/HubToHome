# 타이틀 · 옵션 화면 정리

## 범위

사용자는 00_TitleScene의 Options 겹침/배치 문제 수정과 시각 정리를 요청했다. 기존 타이틀 이미지, 새 게임/이어하기/옵션/종료 기능, 설정값 저장·키보드 조작을 유지한다. 이전의 바로 구현/Unity 실기 테스트 금지 요청을 따른다.

## 선택한 방향

전체 타이틀 재제작이나 새 설정 시스템 대신 기존 Scene/UIManager 설정 Prefab을 정돈한다. 이미지와 독립된 작은 짙은 메뉴 카드, 일관된 행 간격, 옅은 청록색 선택 표시를 사용한다. 1.4배 버튼 확대는 없앤다. 640×480 게임 영역 안에서 고정된 메뉴 크기를 유지한다.

옵션은 타이틀보다 높은 Canvas 순서와 배경 가림을 갖는다. 설정이 열려 있는 동안 타이틀 메뉴는 CanvasGroup으로 표시/입력을 잠그고, 닫힌 뒤 이전 선택을 복원한다. 저장이 없을 때 이어하기는 회색으로 비활성화해 메뉴 위치가 바뀌지 않게 한다.

공용 설정은 기존 카테고리/상세/스크롤 열을 보존하되 색·여백·구분을 정리한다. 선택 표시로 글자 영역을 확대하지 않는다. 공용 UIViewportService와 카메라, 타이틀 이미지는 수정하지 않는다.

## 근거와 검증 경계

두 Canvas의 sortingOrder가 모두 0이며 옵션 열기 경로에 타이틀 표시/입력 차단이 없다. 타이틀은 stretch 메뉴·가변 자식 분배·1.4배 확대를 사용한다. 설정은 scale 0을 Awake에서 보정하며, timeScale 0에서 scaled 선택 tween을 사용한다. 실제 화면 재현은 하지 않았으므로 소스상 결함/위험과 사용자 증상을 구분한다.

씬/Prefab의 정렬·정상 scale·배치 범위 및 선택 소유권을 소스로 검증하고 정적 Runtime+Editor 컴파일을 수행한다. 테스트 소스는 작성 가능하지만 Unity Play/Refresh/테스트 실행은 하지 않는다. 코드 경로·자산 참조·저장 데이터와 기존 dirty 작업을 보존한다. 커밋/푸시 없음.

## 후속 확정: 단순 설정과 비포인터 조작

사용자가 수직동기화/목표 FPS 항목 삭제와 마우스 클릭 금지를 요청했다. 설정 UI에서 두 행만 제거하고 GameConfigManager의 저장/API/기기별 내부 프레임 정책은 보존한다. 기존 RowType 값의 순서는 바꾸지 않는다.

개별 버튼 이벤트 삭제나 매 프레임 입력 감시 대신 공용 UIManager 프리팹의 InputSystemUIInputModule에서 Point/Click/Scroll/Tracked 포인터 참조를 비운다. ActionsAsset과 Move/Submit/Cancel은 유지하므로 키보드·패드 내비게이션과 기본 액션 재할당 방지 조건이 유지된다. 배경 클릭으로 선택을 해제하지 않는다. 기존 GameInput은 포인터를 사용하지 않는다.

이 설정은 공용 EventSystem을 쓰는 게임 UI 전체에 적용된다. 직접 터치/펜/XR 포인터도 이 모듈에서는 사용하지 않으며, 추후 모바일 가상 버튼은 별도 명시적 입력 경로로 연결한다. Unity Editor 자체의 마우스는 차단하지 않는다. 추가 런타임 관리자/Update/패키지 변경은 없다.

## 후속 확정: 설정창 현지화와 플랫폼 안내

한국어/영어/일본어/중국어 설정 문구는 기존 LocalizationTable.csv를 사용한다. 설정 제목·카테고리·항목·상태·입력 대기/충돌·미리보기·플랫폼 안내를 채우고 언어 값은 자칭 이름으로 표시한다. 번역 표의 비설정 대사는 변경하지 않는다. 키 이름은 짧은 키캡 표기와 번역 키로 처리하며 언어 변경 때 현재 UI와 미리보기를 갱신한다.

설정창 안에서 데스크톱용 전체화면/창 크기는 모바일/콘솔에서 회색 비활성으로 표시한다. 키보드가 없는 기기에서 키 변경 대기 상태로 들어가지 않으며 기기 관리/기본 조작 안내를 번역해 보여준다. 입력키 설정은 키보드용임을 명시하고 닌텐도 A/B 등 확인되지 않은 패드 표기를 하드코딩하지 않는다. 입력 시스템·모바일 가상 패드·Nintendo SDK 및 전역 화면 적용 정책의 변경은 이번 설정 현지화 범위가 아니다.

현재 설정의 Silver 폰트 원본에서 4개 언어 글리프 지원을 정적으로 확인한다. 새 폰트나 전역 fallback을 도입하지 않으며 다른 화면의 폰트/문구는 건드리지 않는다. 실제 기기·글리프 atlas 렌더·줄 넘침은 미검증임을 인계한다.

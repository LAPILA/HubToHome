# 동료 동행 Notion 문서 시각 정리

## 승인한 범위

사용자가 2026-10-23 추천 디자인으로 즉시 진행을 승인했다. 새로 게시한 제작 사용법·코드 학습·구현 및 검증 현황 3문서만 꾸민다. 상위 학습실·제작 운영실과 기존 문서 계층은 유지한다.

## 디자인

- 제작 사용법: 청록, 제작 매뉴얼의 명확한 단계 강조.
- 코드 학습: 보라, 학습 노트와 구현 원리 강조.
- 운영 현황: 금색, 구현과 미검증 항목 구분.
- Notion 기본 커버·아이콘·요약 배경·제목 색상·자동 목차를 사용한다. 과한 이미지나 장식은 추가하지 않는다.
- 날짜가 긴 페이지 제목은 읽기 쉬운 문서명으로 간결화할 수 있으나 본문 날짜와 근거는 보존한다.

## 보존·검증 계약

본문 의미, C# 발췌 4개, YAML 예시 3개, 표, 외부 링크, 미실행 체크리스트, 기존 일정·역할을 바꾸지 않는다. 새로고침 후 저장 여부와 본문 보존을 확인하고 실제 문서 스크린샷을 남긴다. Notion API 404가 지속되면 브라우저 UI만 사용하며 인증·공유 권한은 변경하지 않는다. Unity 검증과 문서 디자인 검증을 구분한다. 게임 코드·에셋·저장 데이터는 수정하지 않고 커밋·푸시하지 않는다.

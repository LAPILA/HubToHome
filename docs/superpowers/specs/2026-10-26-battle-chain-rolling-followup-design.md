# 사슬·제브 이동·상단 기록 후속 설계

2026-10-26 사용자 승인: 사슬 그림 자체2배·네 모서리 좌우/상하 대칭·SFX0.45 감쇠 유지, 제브 일반4종 화면 전체 이동, 상단 고정3줄/한 줄씩 출력/Z현재 줄 완성·다음 입력으로 다음 줄.

## 1. 사슬 표시

최종 위치 정정: 사용자 빨간선은 전체 화면 모서리의 인접한 두 변을 가로지른다. Lab만 배치ScreenCorners/전체640×480/중심거리64/정렬-50로 바꾸며각도는BL+45/TL-45/TR+45/BR-45다. 하단HUD까지사슬을보여주고주대화보다는뒤다. 다른프로필은기존PlayfieldCorners/-200 기본을보존한다. 아래초기의HUD마스크유지문구보다이정정을우선한다.

기존 BattlePhaseOverlayProfile/Policy/Presentation을 확장한다. 그림 배율 기본1을 추가하고 Lab 프로필만2로 지정한다. 폭32/길이256와 원본 높이×배율의 반복 주기를 함께 적용해 등비 확대한다. 네 모서리의 반전은 각각 데이터로 편집하며 좌하/좌상/우상/우하 순서에 맞춰 대칭 배치한다. 기존 프로필 기본 반전은 없음이다. 음량 범위0~1, Lab0.45/감쇠1.2초로 바꾼다. 공유 재질1개/샘플1회, 기존 HUD 마스크/SFX 믹서/BGM 불변/중단 수명을 유지한다.

## 2. 제브 일반4종

Lab 사본 BlinkSlash/PhantomArc/ComboSlash/Crash에 ScreenWide를 사용한다. 중복 AttackStaging 이동을 제거해 화면 끝 진입이 위치를 소유한다. 기존 피해/TimeWindow/전조/속성/회피 전용 규칙을 유지한다. 가드/저스트 성공은 접점 정지, 회피/실패는 관통이며 PolarJudgment C는 중앙 합을 유지한다. 본편 원본/시나리오/HP는 바꾸지 않는다.

## 3. 고정 상단 기록

사용자 외형 후속: 상단 기록 배경은 스프라이트 없는 Simple 검정 alpha0.5 사각형으로 바꾼다. 본문 가로 중앙 정렬은 TMP 프리팹 데이터가 소유하고 런타임은 세로Top만 고정한다. SettingPanel 원본과 다른 대화 배경은 보존한다.3줄 기준선과 스크롤은 유지한다.

기존 BattleNarrationUI가 표시만 소유하고 CombatLogPresenter의 HP/AP/상태 집계는 유지한다. 공통 표시 크기/줄수/타이핑/유지/스크롤 시간은 Inspector 데이터로 조절한다. 실제 DialogueCanvas의 기존 직렬화 값을 좁게 갱신한다. 자동 창 크기 변경과 전체 즉시 표시를 해제한다.

TMP 전체 rich text는 유지하고 실제 lineInfo의 문자 범위로 한 시각 줄씩 드러낸다. 최대3줄을 초과하면 오래된 줄이 위로 빠지도록 마스크 안의 본문을 올린다. 글 분량 때문에 창 크기/폰트가 커지지 않는다. Z는 타이핑 중 현재 줄만 완성하고, 완성 후 새 입력은 다음 줄을 시작한다. 자동 진행도 유지한다. 마지막 줄의 새 확인은 종료한다. 같은 입력을 다음 줄/다음 전투 단계에 재사용하지 않는다.

큐 종료/Clear/Disable/Destroy에서 본문 위치/가시 범위/Busy/입력을 정리한다. 이야기 대화·말풍선·피해 계산·턴·QTE·저장·카메라 정책은 유지한다. 한영일중/색 태그/이름 noparse/긴 문장의 자동 줄바꿈을 보존한다.

## 검증

실제 생산 코드 기반 관리형 회귀와 전체 Runtime/Editor CLI 컴파일, YAML 참조/메타 GUID/UTF8/diff검사를 수행한다. Unity Play/Refresh/씬 저장/실제 저장 I/O/커밋/푸시는 하지 않는다. 실제 렌더·사운드 믹싱·기기 성능은 수동 확인 대상으로 분리한다.

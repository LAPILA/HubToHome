# 심리스 일반 전투 진입

사용자 승인 범위: 심리스 전투에만 우선 적용. 전용 BattleScene 전환은 변경하지 않습니다.

## 화면 계약

GIF의 경고 → 줌 → 왼쪽에서 오른쪽 사선 절단 → 짧은 암전 → 중앙에서 상하 개방 → 하단 HUD 슬라이드를 사용합니다. 후속 요청에 따라 기본값은 경고 .20 / 줌 .50 / 절단 .20 / 암전 .35 / 개방 .55 / HUD 지연 .45·등장 .30초, 중첩 포함 2초입니다. 준비는 암전 최소 시간과 겹치며 오래 걸릴 때만 연장합니다. 기존 640×480 HUD와 PixelPerfectCamera는 보존합니다. 화면 캡처·RenderTexture·새 셰이더·지속 흔들림 없이 재사용 uGUI 패널과 DOTween으로 구현합니다.

## 소유권과 연결

- 암전 전에는 PlayerController.HoldForBattleEntry/Cutscene 잠금만 사용하고 필드 Follow/구도를 보존합니다. 검정 패널 배치 후 한 프레임을 양보하고 IsCovered를 확인해야 전투 모드, NPC 숨김(IEncounterPreparationSource), 참가자/UI/전투 카메라 준비를 시작합니다. 기존 전용 씬은 적용하지 않습니다.

- 공용 SeamlessBattleHost에 한국어 설정을 노출하고 런타임 프레젠터를 하나 재사용합니다. 경고는 플레이어 머리 위가 기본입니다. 색·줌 배율·시간·선택적 SFX를 조정합니다.
- BattleEncounterService의 기존 검증/상태 전환/실패 복구를 유지합니다. 조우별 끄기 인자를 추가하되 전용 씬 경로에서는 무시합니다.
- BattleManager는 짧은 진입 호출/준비/완료 경계만 연결합니다. 암전 아래에서 기존 참가자 준비와 QTE 예열을 하고 플레이어의 기존 0.5초 접근은 즉시 배치로 대체합니다. 비활성화 시 기존 진입을 그대로 사용합니다.
- BattleUIController의 기존 OnBattleStarted 갱신을 먼저 실행하고, 프레젠터가 하단 시각 요소만 잠시 숨김/슬라이드합니다. 실제 턴 모듈과 대화 시나리오는 개방 완료 뒤 시작합니다. 턴/스탯/대상 선택은 변경하지 않습니다.
- 카메라는 CameraController 명령 token을 사용합니다. 전역 timeScale은 건드리지 않으며 임시 연출은 unscaled time으로 진행합니다.
- 취소/Host 비활성/씬 종료 시 자신이 만든 Tween·overlay·HUD 위치/alpha만 복원합니다. 오래된 token으로 새 카메라 명령을 취소하지 않습니다. 기존 심리스 cleanup이 플레이어/입력/조우 문맥 복구를 담당합니다.

## 검증과 제외

편집기 검사로 기본 시간, 설정 경계, HUD 원위치 복원, 중복 시작과 정리, 전용 씬 비적용을 확인하고 CLI 컴파일을 수행합니다. Unity Play/자동 Refresh/씬 저장은 하지 않습니다. 모바일/콘솔 실제 성능과 화면 감각은 수동 확인 대상으로 명시합니다. 사용자 기존 dirty 자산은 수정하지 않습니다.

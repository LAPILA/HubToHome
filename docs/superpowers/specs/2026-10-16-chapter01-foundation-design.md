# 챕터 1 기반 규칙 확정 및 구현 경계

승인 근거: 2026-10-16 사용자가 기능별 답변과 함께 “구현시작”을 요청했다. 같은 결정을 재승인받지 않고 해당 규칙을 구현한다. 코드/데이터가 겹치는 기존 작업은 보존한다. 커밋·push와 Unity 재생/강제 임포트는 이번 승인에 포함하지 않는다.

## 구조 선택

기존 GlobalDataManager/SaveManager/전투 모듈/메뉴/제작 데이터에 좁은 서비스와 어댑터를 연결한다. 전체 저장·전투 시스템 교체나 동료별 임시 콘텐츠 하드코딩은 하지 않는다. 분리된 시스템을 동시에 변경하므로 파일 소유권을 나누고 통합 후 공통 컴파일로 확인한다.

## 확정 규칙

- 새 게임은 주인공 1명. 동료는 이벤트로 한 명씩 중복 없이 합류하고 저장된다. 필드에는 기존 위젤만 유지한다. 전열은 보유 인원이 3명 이상이면 3명이다. 기존 예비 파티 규칙은 유지하며 수동 교대나 새 디버그 합류 UI를 추가하지 않는다.
- 파티 공용 EXP/레벨(최대99), 캐릭터별 투자/스킬 구매. 레벨업은 포인트를 주지만 능력치를 자동 상승시키지 않는다. 스킬/능력치 초기화는 무료이고 반복 가능하다. 전투 도중 장비·성장 변경 차단 등 기존 안전 경계는 보존한다.
- 이전 개별 성장 저장은 최고 진행 멤버 기준으로 공용 성장을 초기화하며 EXP를 합산하지 않는다. 투자/해금/장비/현재 HP·AP는 보존한다. 합류 시 현재 파티 레벨과 이에 맞는 포인트를 받는 것을 변경 가능한 기본 정책으로 둔다.
- 챕터 목표 레벨15/30/45/60/75/99는 가이드이며 강제 레벨 잠금이나 자동 레벨업이 아니다. 동료별 기술·고유 자원·합동 스킬은 제작하지 않는다.
- 공격 QTE 성공은 정상 피해, 실패는 감소 피해이며 QTE 자체의 추가 AP/자원 보상은 없다. 저스트가드 보상과 스킬 고유 효과는 별개다. 기존 실패 배율을 가능한 범위에서 재사용한다.
- 일반 방어는 피해65% 감소(배율0.35), 저스트가드는 피해0+AP, 회피는 피해0·AP없음. 회피 전용 공격/Counterable/C 반격은 유지한다. 기본 타깃은 기존 최근 타깃 이력을 사용하는 공평한 가중 랜덤이다.
- 전투 후 HP/AP 유지, 모든 전투 상태 제거. 챕터1 소개 상태는 화상/감전이며 나머지 기존 상태 삭제·재설계는 하지 않는다.
- 적은 일반/엘리트/보스 등급과 사람/몬스터/백색체 종별을 데이터로 구분한다. 보스와 스토리 필수전투는 도주 불가. 실패한 도주는 현재 행동을 소비하며 속도 스케줄 자체는 바꾸지 않는다. 도주 직후 접촉 유예를 유지한다.
- 장비 슬롯 전체, 전용 무기, 중복 보유, 판매 금지 장비 지원. 상점/상자/보상에서 실제 장비 보관함으로 지급한다. 조건부 효과는 데이터 기반 실행 경로를 마련하되 실제 장비 밸런스/목록은 만들지 않는다.
- 아이템 최대99, 필드 사용 지원. 회복/피해/정화/부활이 기존 사용·대상 선택 경로와 연결된다. 고정 상품과 상점별 회복 서비스 유지.
- 수동 저장 성공 시에만 HP/AP 회복과 일반 적 재등장. 실패/취소는 회복·재등장하지 않는다. 저장할 복사본을 먼저 준비해 원자 저장한 뒤 런타임에 반영한다. 보스/엘리트·상자·이벤트 완료 사실은 초기화하지 않는다.
- 보스 승리/진행 이벤트 정상 완료는 자동저장 예약. 단순 NPC 잡담/확인창은 진행 이벤트로 간주하지 않는다. 저장은 기존 안정된 탐색 경계에서 수행한다.
- 일반 패배는 최근 저장, 보스/필수전투는 전투 직전의 메모리 스냅샷 재도전. 새 게임/일반 로드/완료 시 임시 스냅샷을 해제한다. 진행 중 전투를 디스크 저장하지 않는다.
- 일반 이벤트는 완료 플래그로1회, 훈련/일반대화는 작성 데이터에 따라 반복. 지역 상태는 기존 명명된 플래그를 재사용하며 GameObject tag를 저장 사실로 사용하지 않는다.
- 대화 건너뛰기는 선택지를 자동 결정하지 않고 선택지에서 멈춘다. 확정된 경로의 노드 이벤트와 보상은 실행하며 취소와 성공 완료를 구분한다. 모든 시네마틱을 임의 최종화하는 preview 코드를 재사용하지 않는다.
- 상태 도움말은 아이템-일지, 현재 목표와 능력치는 메뉴. 약점/저항은 표시하지 않는다. 메뉴는 전투 시간만 정지하고 음악 유지. 별도 퀘스트 보드·도감·튜토리얼 제작은 하지 않는다.
- KR/EN/JP/CN 문자열 경로, 화자/선택지 키, 입력 안내를 연결한다. 아직 작성하지 않은 본편 대사의 번역 완료를 주장하지 않는다.
- 모바일 가상 방향/행동 버튼은 GameInput을 통과하며 PC 마우스 조작을 켜지 않는다. 키보드/패드 안내 전환과 패드 해제 복구를 지원한다. 실제 콘솔 배포/인증은 별개다.

## 성능과 검증 경계

요청한 발열0/프레임저하0/순간 로딩은 모든 하드웨어에서 보장할 수 없다. 새로운 매프레임 검색·LINQ·불필요한 할당을 피하고 이벤트 갱신/캐시/풀링, 기존 암전 준비 경계를 사용한다. 목표 기기 측정 없이 성능 달성을 선언하지 않는다.

저장 마이그레이션, 중복 합류, 공용 EXP 중복 지급 방지, 무료 재투자, 수동 저장 실패 원복, 장비 지급/매각, 부활 대상, 입력 모달 누수에 회귀 테스트를 추가한다. Unity Play/씬 저장 없이 가능한 CLI 컴파일과 순수 검사만 실행한다.

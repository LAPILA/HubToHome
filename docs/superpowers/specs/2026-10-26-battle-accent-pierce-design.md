# 전투 강조·Z 재준비·화면 관통 수정

2026-10-26 사용자 승인: 컷인 전부 제거, 실루엣은 실제 캐릭터와 동일 크기, 점멸은 명중 순간, Z 연타 시 약0.18초 저스트가드 재준비/홀드 방어 유지/캐릭터 옆 준비 표시, 일부 스킬 화면 좌우 관통. 짧은 연속 공격에서는 재준비 간격을 제한하고 숨은 확률 실패를 넣지 않는다.

## 표시

- Lab15스킬의 CutIn 블록8개를 timeline/ref에서 제거한다. 공용 enum0은 저장 호환용 폐기값으로만 남고 표시/음향/대기 없이 종료한다. 제작 메뉴에는 새 컷인을 만들지 않는다.
- 실루엣은 재사용 월드 SpriteRenderer가 실제 배우 Renderer의 자식으로 현재 sprite/피벗/PPU/scale/flip/정렬을 따른다. 확대·별도 초상·전체 배경 암전은 없다. 활성 순간에만 동기화하며 원본 재질/Transform은 바꾸지 않는다.
- Flash는 대기 블록이 아니라 다음 유효 명중의 단발 표시 요청이다. SkillContext의 실제 ApplySkillHit 경계에서 발동하고 피해/방어/복귀를 지연하지 않는다. 50타 난무의 타격마다 화면을 번쩍이지 않는다. 취소/행동 경계에는 무효화한다.

## Z 입력

기존 넉넉한 첫 입력 구간/전조/늦은 유예/X/C/홀드 가드65% 감소/AP 보상은 유지한다. 유효 적 대응에서 반복된 Z는 약0.18초의 결정적인 재준비 규칙을 적용한다. 막힌 Z도 재준비를 갱신해 연타만으로 첫 유효 구간에 자동 진입하지 않게 한다. 짧은 공격에서는 요청 길이에 비례해 상한을 낮춘다. 일시정지·모달·행동 종료에는 입력이 누적되지 않으며 실제 대상별 소유 상태를 쓴다. 저스트 가능/재준비는 캐릭터 옆 작은 표시로 구분한다. 재준비 중 Z 유지는 일반 가드로만 유효하다. 유효 저스트를 이미 확정한 뒤의 재입력은 그 성공을 취소하지 않는다.

## 화면 관통

재사용 아군 전용 관통 블록을 추가한다. 전투 카메라의 현재 가시/안전 영역을 한 번 포착하고 배우 반폭+여백을 뺀 좌우 끝 사이로 DOTween 이동한다. 대상 X를 통과하는 실제 진행률에서 기존 피해/QTE/상태·명중 점멸을1회 소비한다. 짧은 준비→빠른 돌파→반대편 정지→평범한 복귀다. 이동 때만 잔상, 화면 밖 이동/전역 카메라 재설정/추가 RT는 없다. 관통 중에는 배우 이탈 때문에 카메라가 쫓아가거나 프레이밍이 변하지 않도록 자기 범위만 고정하고 취소 시 기존 제어권을 돌려준다.

Lab의 증기 찌르기/역류 참격/임계압 돌파3종에 단방향/왕복 변주로 연결한다. 제브의 대응창→피해/반격 계약은 변경하지 않는다. SkillID/GUID·DB/Catalog/Scenario 링크는 유지한다.

## 검증·제외

관리형 실제 정책/기하·실제 자산 검사와 전체 C# CLI를 수행한다. 원본15스킬·본편 DB·Scene/Prefab·저장·TMP의 기존 수정은 보존한다. Unity 강제 Refresh/Play/실기기/GPU/실제 저장 I/O/커밋·푸시는 수행하지 않고 한계를 명시한다.

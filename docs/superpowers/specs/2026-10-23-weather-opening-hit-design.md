# 날씨 샘플 · 고정 주인공 · 창가 시작 · 피격 표시

사용자 승인 범위: 교체 가능한 안개/비 샘플, 안개 안에서 플레이어 주변 원형 투명화, 기본 WIZZEL 고정/이름 입력 잔재 제거, 직접 피격의 순간 멈춤·완전 백색 표시, 저장 안정성 점검, 국가 설명 삭제. 추가 답변으로 **창가 위젤 애니메이션부터는 유지**한다. 새로운 기계 수리 씬/대본은 이번에 만들지 않는다.

## 1. 날씨 (방 수명의 표시)

- 재사용 WeatherSample prefab 하나에 안개/비 토글·영역·강도·Sprite/Texture 교체 슬롯. 샘플은 플레이어 참조 우선, 활성화 시 한 번 fallback 탐색·캐시. 나중에 임시 플레이어블로 바꾸면 명시적 SetTarget으로 교체할 수 있다. 매 프레임 전역탐색 금지.
- Foreground 월드 안개 전용 간단 셰이더: 월드 XY의 플레이어 주변 작은 원만 alpha를 줄이고 부드러운 경계로 연결. 플레이어가 영역 밖이면 구멍을 비활성화한다. 별도 RT·카메라·후처리·3D 볼륨 없음. UI는 영향받지 않는다.
- 비는 **2D 바닥 착지점 선결정**: P에서 끝나도록 spawn=P-velocity*lifetime. 중력/Noise/실제충돌 없이 고정속도, 종료 위치에 Death sub-emitter 물튀김. 카메라 앞뒤 층처럼 보이되 실제 Rigidbody3D·Ground mesh는 만들지 않는다. 빗줄기/물튀김 그림을 나중에 교체한다.
- 임시 도형/프로시저럴 미리보기는 최종 아트가 아니다. 자산이 null이어도 샘플을 확인할 수 있고 무한 per-frame 생성/삭제는 하지 않는다. 방 비활성화/파괴 시 particles·재질·참조 정리. 날씨는 저장 스키마에 추가하지 않는다.

## 2. 이름과 시작 흐름

- 이름 입력 화면/코드/참조 제거. 옛 RequestName enum/노드는 안전하게 건너뛰어 기존 대본 호환성을 지킨다.
- 기본 주인공의 정체성은 WIZZEL, 한국어 표시명 위젤/영문 WIZZEL은 기존 현지화 정책을 따른다. 동료/NPC 이름을 일괄 덮지 않는다. 저장된 임의 주인공 이름은 더 이상 표시 권한이 없으며 legacy SaveData 필드는 읽기 호환용으로 유지한다.
- Prologue_Opening에서 국가4컷과 '그리고 현재'만 제거하고 창가 한 페이지를 유지한다. IntroManager의 페이지 인덱스/음향을 함께 정리하여 Two empire 내레이션 BGM이 틀어지지 않게 한다. 창가 주행음→열차 객실→사고/후미 플래그 연결과 원본 그림/음원·범용StoryPlayer는 보존한다.

## 3. 피격

- HP/피해 확정은 즉시 유지하고, 직접 타격의 대상 캐릭터만 약0.035초 멈춤 뒤 흰 실루엣/기존 Hurt·반동을 출력한다. 곱셈 tint가 아니라 검은 픽셀도 흰색이 되며 원본 알파·프레임·flip을 따른다.
- 공유 원본 재질을 수정하지 않는다. 검토 중 overlay order+1이 기존 Y가림을 깨는 것을 확인하여, 개별 백색 Material의 참조를 잠시 소유·교체한 뒤 자신이 연결한 참조일 때만 원복하는 방식으로 확정했다. 추가 Renderer/Draw는 없고 원본 geometry/frame/flip/Y정렬을 그대로 사용한다. 평상시 원본 sprite material/lighting은 보존한다.
- 전역 timeScale은 변경하지 않는다. 상태이상 틱에는 순간 정지를 적용하지 않는다. 연타·사망·비활성화·취소·외부 모션 소유권을 안전하게 정리한다. 기존 Tween 반동은 직접 피격 정지 예산만큼 지연해 정지 중 움직이지 않게 한다. UI·음악은 그대로다.

## 4. 저장·검증

현재 수동3칸/자동99번/schema5/원자교체+백업/수동저장 성공후 휴식/자동저장 예약을 유지한다. 확인되지 않은 저장 버그를 가정해 재작성하지 않는다. 이름 고정과 옛 저장 호환, 날씨 비저장 경계를 회귀 검사한다. 사용자 저장 파일에 테스트 I/O하지 않는다.

검증은 Runtime/Editor CLI 및 실제 생산 수치/수명 코드의 대체형 검사, 자산 참조/인코딩/셰이더 분리 문법 검사까지. Unity Play/Refresh/Reimport/열린 씬 저장/커밋/push는 하지 않는다. 필요한 prefab 변경은 이름 UI 참조 제거와 새 날씨 샘플 생성에 한정한다.

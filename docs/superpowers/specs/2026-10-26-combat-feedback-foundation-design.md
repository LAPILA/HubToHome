# 전투 피드백 공통 기반 정리

사용자 승인 범위: 앞선 전투 피드백 조정안 중 평타·스킬 구성·전조/말풍선 기획은 제외하고 나머지를 구현한다. 특정 적 이름 분기 없이 공용 규칙·데이터를 사용한다.

## 제외 및 보존

- 평타 효과/AP회복, 스킬 개수·장착·비용·연출/QTE횟수·입력키 패턴은 변경하지 않는다.
- 전조 프리팹·위치·이동 중 표시와 말풍선/보스 시나리오 대사를 다시 설계하지 않는다. 표시 시계는 유지하고 저스트 성공 시계만 분리한다.
- 기존 공격·피해 계산/후열/저장/픽셀 카메라와 C 성공 반격 연출을 유지한다. 임의 보스 패턴이나 HP를 대량 생성하지 않는다.

## 1. 방어 규칙

- 기본 저스트는 명중 전 약0.12초, 늦은 유예는0.03초로 시작한다. 기존 .24/.40초 하한 강제는 폐기하고 기본 설정을 실제 성공 판정에 사용한다. 회피는 약0.22초로 저스트보다 넓다. C 약0.18초다. 수치는 편집 가능하고 전체 적 공통이다.
- 전조의 기존 예고 길이와 새 저스트 성공 길이를 분리해 표시를 갑자기 짧게 만들지 않는다. 일반 공격 이동은 멈추지 않는다.
- 타격의 예고 구간에서 첫 대응을 확정한다. 너무 이른/잘못된 대응을 무시하다 다음 키가 성공하는 탐색식 연타를 막는다. 이미 확정한 타격은 덮지 않는다. Z/X/C는 배우 소유 공통 재준비 시간 약0.18초를 사용하며 다음 타격 정상 대응을 해치지 않게 짧은 공격에서 상한을 둔다. 실패는 확률이 아니라 명시적 선택/시간 규칙이다.
- Z 홀드 일반 방어는 타격별 새 press 없이 계속 유지한다. 메뉴·대화 확인으로 소비된 홀드와 실제 방어 유지 입력을 분리한다. 일반 방어65%감소/저스트무피해/AP는 유지한다.
- C 전용 의미는 공통 가부에서 일관되게 처리한다. 구형 Counterable6은 숫자를 보존하되 실제 전투에서는 C전용으로 통일하고 UI/제작 설명도 맞춘다. 현재7 역시 C만 허용한다.

## 2. AP 수급

- 평타를 보류했으므로 자동 턴 회복을0으로 만들지 않는다. 공통 턴+2/저스트+2/적 행동당 기본 저스트 보상 최대6으로 시작한다. 기존 명시적 장비 보상은 별도다.
- 본편 캐릭터 최대 AP/성장/장비/저장은 그대로다. Lab만 장비 포함 최대40, 시작20으로 제한해 실험한다. 나머지 씬의 시작/전투 종료 AP 승계는 보존한다.
- 적 행동의 연타/여러 대상/중단/재진입에 보상 예산을 올바르게 닫고 C를 저스트로 중복 보상하지 않는다.

## 3. QTE 감상 보조

- 스킬 데이터의 타수/키/타이밍은 보류한다. 표시 위치는 공통 안전 영역 안의 일관된 위치로 정리해 시선 이동을 줄인다. 캐릭터·하단 HUD를 가리지 않는다.
- 공격 QTE 자동 입력 옵션을 설정에 추가한다. 성공 정상 피해만 제공하고 AP/고유자원을 새로 보상하지 않는다. 적 방어 Z/X/C는 절대 자동화하지 않는다. 공격 연출의 원래 시간과 비동기 실행은 유지한다.
- 설정은 기존 PlayerPrefs 지연 저장 경로를 사용하고 한/영/일/중 UI를 제공한다. 기본은 수동이다.

## 4. 누적 상태 강화

- 기존 누적값/저항/자연 감소·증가/빙결회복/소수 이월을 유지한다. 선형 피해에 데이터로 편집 가능한 단계별 보정과 최대 상한을 추가한다.
- 기본 단계는 누적10/25/50에서1.25/1.5/2배다. 화상/감전/출혈/중독의 실제 상태 피해에 동일 계산기를 사용한다. 냉기는 기존 취약/빙결 규칙을 유지한다.
- 현재 단계와 배율을 상태 설명에 표시하고 단계 상승만 기존 아이콘 강조로 알린다. 피해 숫자 텍스트를 다시 붙이지 않는다. 장기전에서 무한 지수 증가나 반복 임계 폭발은 넣지 않는다.

## 5. 아이템 연계

- 새 대형 제작 시스템 없이 기존 ItemData/ItemEffectService를 확장한다. 선택적 누적 상태 추가·소비 기반 피해를 데이터로 지정하고 기존 효과는 기본값에서 바뀌지 않는다.
- 전투에서 성공적으로 사용한 아이템 한 행동당 ItemUsed 장비 발동을1회 제공한다. enum은 뒤에 추가해 기존 숫자를 유지하고 AoE 대상 수만큼 중복 보상하지 않는다.
- 필드 사용은 지원하지 않는 전투 전용 누적 효과를 명확히 거부한다. 효과 없음/취소/무효 대상은 아이템·턴·장비 발동을 소비하지 않는다.
- 실험실에 누적 부여용/누적 소비용 공격 아이템과 ItemUsed 장비 효과 샘플을 두고 기존 아이템 ID/원본 자산은 보존한다.

## 6. 보스 진행 표시

- 보스 또는 명시적으로 표시를 켠 적에 남은 HP/비율과 선택적 체력 구간 마커를 표시한다. UI는 HP 이벤트만 관찰하고 시나리오 페이즈/무적/보상은 결정하지 않는다.
- 턴 큐 옆 예약 공간에 한 대상만 작게 표시해 기존 전투/대화/HUD를 가리지 않는다. 대상 변경/종료/비활성/파괴에 구독과 트윈을 정리한다.
- ZEV Lab에서 샘플을 연결한다. 보스별 패턴/목표 전투시간/실제 페이즈 연출은 후속 기획 데이터다.

## 검증

순수 판정·입력 조합·홀드·다중 타격·AP 예산·속성 수치·아이템 단일 소비·QTE 자동화 분리와 종료/재진입을 검사한다. 실제 DOTween DLL 계약과 native 엔진의 차이를 구분하며 전체 C# CLI 컴파일, meta32hex/유일성, SourceHash/원본 보존, UTF8을 확인한다. Unity 강제 Play/리임포트/씬 재저장은 하지 않는다. 커밋·푸시는 별도 요청 전에는 하지 않는다.

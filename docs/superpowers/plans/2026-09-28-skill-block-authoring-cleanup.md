# 스킬 블록 제작 화면 정리

**승인 범위:** 사용자의 1번 우선·빠른 구현 요청. 기존 화면/데이터/실행 구조 유지. Drive·Notion 작업은 이번 범위 밖.
**구조:** 기존 SkillMakerBlockEditor의 표시 이름/도움말, SkillMakerWindow의 메뉴/목록, SkillActionBlocks의 Odin 표시 특성만 수정. 직렬화 필드·열거값·실행 메서드는 유지.
**기술:** Unity Editor UI Toolkit + IMGUI/Odin, 기존 C# 검사.

- [x] 기존 블록 13종의 사용 대상·역할을 읽고 한국어 이름·분류·짧은 안내 추가. 사용자 정의 블록도 기존 등록 경로 유지.
- [x] 방어 블록의 기본 판정/모션/실패 연출/고급·구형 설정 분리. 시간은 초, 배율은 기준을 명시. C 안내를 피격자 1명 반격 규칙에 맞춤.
- [x] 추가 메뉴 분류, 목록 시간 단위·툴팁 정리. 필드/enum 숫자/실행 본문 보존 검사와 설명 회귀 검사 추가.
- [x] Editor CLI 컴파일·diff 확인, 사용법/당일 기록 갱신. Unity Play·강제 Refresh·커밋·푸시 없음.

별도 재설계/신규 메이커/불필요한 테스트 씬은 만들지 않음. 앞선 전조 코드 및 사용자 Aseprite 변경 보존.

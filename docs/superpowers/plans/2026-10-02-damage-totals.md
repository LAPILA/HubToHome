# 속성별 누적 피해 표시 구현 계획

**Goal:** 승인된 대상·속성·행동별 합산을 기존 피해 팝업 풀에 적용한다.

**Architecture:** 피해 계산/판정은 유지한다. 런타임 피해 표시 데이터에 속성·행동 ID를 전달하고, UI는 같은 키의 숫자만 갱신한다. 완료된 행동은 0.7초 유지 후 반환하며 상태 틱은 별도 표시 묶음이다.

**Tech Stack:** Unity C#, uGUI/TMP, DOTween, 기존 Editor 회귀 검사.

사용자 `코드시작` 승인으로 현재 세션에서 직접 구현한다. 추가 승인·서브에이전트·커밋·Unity Play/Refresh/씬 저장은 하지 않는다.

- [x] `BattleDamageFeedback`에 물리/화염/냉기/전기/중독/출혈 표시 분류와 행동 ID 전달. 기존 이벤트/피해량 유지.
- [x] `BattleDamageBatchTracker`와 기존 행동/스킬/반격/상태 틱 경계 연결. 중단·모듈 종료 시 남은 묶음 종료. 중첩/늦은 정리로 다른 행동을 닫지 않는다.
- [x] `BattleDamagePopupPresenter/View`에서 대상·타입별 재사용, 숫자 즉시 갱신/작은 반응, 세로 정렬, 완료 뒤 유지/페이드 구현. QTE 위치는 보존.
- [x] 회귀 검사: 연타 합계/다른 대상·속성·행동 분리/감전 중복 없음/정렬/종료·풀 재사용·파괴 안전성. 관리형 검사889 assertion 통과, Runtime/Editor 컴파일 수행. NUnit 실행 아님.
- [x] 인수인계 및 전투 규칙 갱신. 실제 Play 체감은 미검증으로 명시.

## 승인된 쥬스 후속

- [x] 기존 뷰만 확장:0.04초 확대→정점에서 최신 숫자 교체→0.12초 복귀. 확대 중 연타는 최신 합계만 병합하고 정점 시각을 미루지 않음.
- [x] Inspector 반응 설정과 대기 중 숫자의 폭/최대 확대 배율을 배치에 반영. HP/피해/행동 ID/씬은 유지.
- [x] View/Presenter 회귀 검사 갱신·컴파일 및 관리형 집계/배치889항목 재확인. Unity Play/NUnit 실행은 하지 않음.

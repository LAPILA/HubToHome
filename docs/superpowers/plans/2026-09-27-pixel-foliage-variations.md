# 픽셀 바람 바리에이션 정리

**목표:** 현재 UV 정수 픽셀 바람을 유지하면서 제작자가 시작값을 쉽게 선택하게 한다.

**구조:** 셰이더·머티리얼 종류를 늘리지 않고 PixelFoliageWind Inspector에 일회성 프리셋 적용을 제공한다. 기존 저장 필드/씬 값을 유지하고, 매달린 장식용 위쪽 고정만 공통 HLSL에 선택값으로 추가한다. 프리셋은 애니메이션 종류나 물리 시뮬레이션이 아니라 시작 수치다.

**도구:** Unity 6 / URP 2D / Odin. 매 프레임 C# 갱신 없음.

## 범위 및 대안

- 채택: 한 컴포넌트의 시작값 7개. 종류별 머티리얼 복제를 피하고 적용 후 개별 수치 편집 가능.
- 제외: 프리셋 ScriptableObject/별도 메이커. 현재 규모에 불필요한 자산·참조 추가.
- 제외: 물·불·접촉/충격파. 다른 시스템이므로 이번 최종 정리와 섞지 않음.

## 구현 순서

- [x] PixelFoliageWind에 잔디 3종/꽃/덤불/매달린 천/몽환 흔들림, 적용 버튼, 위상 변형 버튼을 추가. 기존 값은 자동 교체하지 않는다.
- [x] _PinFromTop 기본값 0을 공통 셰이더에 추가. 아래쪽 고정 결과가 기존과 같음을 수식 대조.
- [x] Undo/Redo 및 프리팹 오버라이드 기록 코드, 공용 머티리얼 미변경, CPU Update 미추가 확인. Undo UI의 실제 조작은 미검증.
- [x] README의 사용 순서/시작값/추천 아트 분리/제한사항을 정리하고 작업 기록 갱신.
- [x] C# CLI 빌드 오류 0·기존 경고 2, 수식·설정 정적 검사. Unity Play/강제 Refresh/씬 저장/커밋/푸시는 수행하지 않음.

변경 대상: PixelFoliageWind.cs, PixelFoliageLit.shader, PixelFoliageUV.hlsl, README.md와 AIAssets 기록. 씬/프리팹/타일/그림/기존 머티리얼 자산은 이번 단계에서 변경하지 않는다.

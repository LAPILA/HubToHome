# Z/X/C 방어 개편 — 승인된 구현 범위

**목표:** Z 유지 가드/저스트 가드, X 회피, C 연계 반격을 기존 턴제 전투에 연결한다.

**구조:** `DefenseJudgementPolicy`가 판정, `QTEManager`가 입력과 실행 수명, 기존 피해 블록이 피해 소비, `BattleLinkCounterService`가 생존 전열의 반격 연출/피해를 맡는다. 기존 enum 번호·필드·공격 QTE 입력은 보존한다.

## 승인 규칙

- Z를 누르는 동안 일반 가드(기본 피해 50%). 타격 직전 새 입력은 저스트 가드(무피해 + 기존 AP 보상).
- X는 저스트 가드보다 넓은 회피 구간, 무피해, 보상 없음. 실패를 Z 유지로 덮지 않는다.
- C는 명시적인 `Counterable` 특수공격에서만 허용한다. Z 불가, X 가능. 성공은 원래 공격과 남은 스킬 블록을 차단하고 살아 있는 전열 최대 3명이 반격한다.
- 반격은 단일 입력, 기본 공격 연출 재사용, 개인 ATK 기반 피해. 후열·전투불능은 제외하며 1명도 실행 가능하다. AP·추가 턴·출혈 틱을 주지 않는다.
- 공격별 첫 시도만 인정한다. 누르고 있던 Z는 가드일 뿐 저스트 가드가 아니다. 동시 입력은 무효다.
- 기존 점프 전용/회피 전용 데이터는 새 모드에서 회피 전용으로 해석하고 자동으로 C 공격으로 바꾸지 않는다.

## 2026-09-15 타이밍 보정

- 적 공격은 UI 없는 `StartBattleDefenseWindow`만 사용한다. `Action_QTE`는 플레이어 스킬에서만 실행되며 적 타임라인에서는 건너뛴다.
- 적 기본/광역 공격과 `Action_DefenseWindow`는 방어 결과 콜백을 단일 충돌 지점으로 사용한다. 준비 자세 이후 공격 트리거·VFX·피해가 같은 결과 프레임에 시작된다.
- 플레이어의 스킬 QTE는 이동·애니메이션과 병행되고, 피해/상태/충돌 소비 블록만 결과를 기다린다.
- 입력창 정리(`CloseDefenseInputWindow`)와 모션/앵커 복구(`ResetDefenseReactionLock`)를 분리했다. 회피·저스트가드가 자리 복귀 후 늦게 재생되거나 즉시 Idle로 잘리는 것을 막는다.
- 구형 ZEV Animator의 `CrossCutReady`와 방어창 없는 투사체/연쇄/애니메이션 적 스킬에도 준비 자세 폴백을 적용했다.

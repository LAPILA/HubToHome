# 자체 스크립트 정리

완료: 2026-10-09. C# 691개 정적 조사, 6개 및 소속 meta 삭제, C# 10개 수정. [결과와 검증](../../../AIAssets/2026-10-09-update.md).

## 범위와 원칙

- 구현 변경은 `Assets/_Game/Scripts`와 소속 `.meta`에 한정한다.
- 외부 플러그인, 패키지, 씬, 프리팹, 콘텐츠 자산은 수정하지 않는다.
- 기존 작업 변경분, 직렬화 필드, Unity 이벤트, 공개 API, 시나리오 호환 경로를 보존한다.
- 이름이 비슷한 클래스나 얇은 인터페이스를 단순히 중복으로 판단하지 않는다.
- Unity 재생·강제 새로고침 없이 소스 검증과 C# 컴파일로 확인한다. 커밋하지 않는다.

## 실행 순서

1. 자체 C# 전체를 정적으로 조사한다. 빈 파일, 동일 메서드, 호출과 GUID 참조를 함께 확인한다.
2. 실제 사용 경로를 읽고 안전한 삭제·중복 통합 대상을 선정한다. 동작 변경이나 자산 마이그레이션이 필요한 대상은 보류한다.
3. 확정한 코드만 수정하고 필요한 회귀 검증을 추가한다.
4. Runtime·Editor 컴파일, 삭제 GUID 참조, 변경 범위와 공백 오류를 검증한다.
5. 처리 항목과 유지한 호환 코드, 실행하지 않은 검증을 작업 기록에 남긴다.

## 완료 기준

- 제거한 파일에는 실제 코드·자산 참조가 없다.
- 통합한 구현은 기존 호출자의 의미와 값, 입력·취소·복구 계약을 유지한다.
- 이전 변경분과 외부 플러그인·콘텐츠 자산은 그대로다.
- 확인한 범위와 남은 실행 검증을 구분해 보고한다.

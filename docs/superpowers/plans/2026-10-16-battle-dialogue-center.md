# Battle Dialogue Center Implementation Plan

**Goal:** 사용자 두 번째 시안대로 파티/자원/턴 큐를 남기고 중앙 명령+상세 영역을 대화로 교체한다.

**Architecture:** DialogueManager/대본/말풍선은 유지한다. BattleMenuUI가 두 형제 메뉴의 이동 전 합집합과 DOTween 수명을 소유하고 BattleDialogueLayout은 그 고정 범위를 투영한다. BattleUIController는 시나리오 모드 중에도 도킹 대화의 HUD 장식만 표시하며 전투 상태는 바꾸지 않는다.

**Tech Stack:** 기존 uGUI/TMP, DOTween, Odin. 씬/프리팹 재저장·Unity Play·커밋 없음.

## 작업

- [x] 명령/상세 합집합, 이동 중 대사 위치 고정, 중단/재오픈 복원 회귀 사례 추가·컴파일.
- [x] 기존 BattleHudEntryMotion을 사용한 중앙 메뉴 퇴장/복귀, 입력 잠금과 트윈 해제.
- [x] 대사 도킹 범위 확대, 짧은 페이드, 시나리오 HUD 표시 범위 수정.
- [x] 중첩 Canvas 루트 정규화/앵커 보존 경로 정적 확인·회귀 사례 추가.
- [x] 전체 CLI 컴파일·정적 기하 검사, 사용법/도메인 계약 갱신. Unity 실행 검증은 미실행.

## 사용자 후속 수정

- 전환 기본시간0.3초, 하단 비율 차이 여백 검정 피복. 기존640×480 좌표 유지.
- 도킹 대화의 하단 레터박스만 안내줄20px 경계로 제한, 상단·시나리오 thickness 보존.
- Confirm→스킬/아이템 전달의 입력 잠금 자기차단 제거. 모달 차단/중복 확정/동기 복귀는 보존.

## 검증 범위

첨부 화면과 프리팹 좌표를 재현 근거로 사용한다. 현재 중앙 범위는 기준640×480에서 x177..539, y24..154이며 기존은 y24..128만 사용한다. 움직이는 메뉴를 대사가 따라가지 않아야 한다. 종료/취소/씬 해제 시 원래 좌표와 alpha/선택 상태로 복구한다. 기존 Play 금지에 따라 실제 DOTween·Unity UI 검사는 작성/컴파일과 수동 확인 항목으로 구분한다.

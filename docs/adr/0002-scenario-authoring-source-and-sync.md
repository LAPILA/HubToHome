# Scenario authoring uses YAML source with synchronized Unity runtime assets

HubToHome scenario flow will use human/AI-readable Scenario Source as the source of truth, synchronized into ScriptableObject Scenario Runtime Assets for Unity execution and shown through a Korean Sequence Maker for human review and light edits. We are choosing this hybrid over pure ScriptableObjects, raw Unity YAML, JSON, or XML because AI needs stable diffable text, humans need a clean editor, and Unity runtime systems need reliable object references without exposing managed-reference serialization as the scenario format.
